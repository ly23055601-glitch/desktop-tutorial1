这些限制按本批原范围执行，不扩成跨产品永久禁词。“同一种表达出现过多”另按语义、上下文和整批分布判断，不能当作禁提依据；不把这两种反馈互相替代。

用户在总结中列举白色外观、双焦段和中焦人像、机械增稳、慢动作、手势控制、FrameTap、D-log2、可调美肤等候选关注。它们在这里是本批用户提供的选材方向，**不是本文件已核验的Pocket4P能力清单**。写作时按实际型号、组件、模式、时序和对应产品资料分别核验，再选真正匹配达人内容的少数关注，不轮流分配所有功能。

用户以新品语境要求可以写看上、准备买、预订、送礼、想试、观望和外观偏爱，不能编成使用这款白色新品多年。真实上市、库存、售价、预订资格与交付时间另核；假想预订本身不能补证。高级、精致、有质感属于审美表达，不能据此杜撰材质、涂层、手感或性能。

用户的称呼示例保留为：`4p`、`4P`、`p4p`、`pocket4p`、`Pocket4P`；功能示例含`D-log2`以及自然的大小写变化。这些是用户说明“清楚称呼可以有变化”的例子，不是新增一份已核验命名表。正文仍按产品入口与上下文确认型号指向；大小写与简称变化不代替真正的观点差异。Pocket专属命名要求继续只作用于Pocket，不能扩给其他品线。
