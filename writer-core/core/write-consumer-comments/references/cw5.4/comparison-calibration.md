# CW5.4.1横测选材与目标产品种草核对

本页只在原帖确实比较两台或以上设备时读取。横测包括同场景实拍、成片对照、排名横测和使用后取舍；普通“帮我选哪个”没有实际对照证据时，回到普通选购或求助逻辑。

## 判断横测是否成立

至少确认三个要素：

- 有明确的比较对象，且不是只在标签里并列出现
- 有共同问题或比较轴，例如画面、人像、声音、操作、携带、后期或价格取舍
- 有原帖可观察或明确说明的结果、排名、使用过程或选择理由

只有多个型号名、作者表达“纠结”，或评论区自行猜测差异，不足以认定为横测。不同场景、不同设置或不同输出被并列时，要保留条件，不能直接写成谁全面更好。

## 横测先记什么

内部简记参与比较的产品、实际比较轴、测试条件、作者结论和证据强度。证据优先级如下：

1. 同一条件下展示并说明的对照结果
2. 帖子中可以观察到但作者没有明确归因的现象
3. 仅凭型号印象、评论猜测或产品资料推演出的差异

第三层只能写成期待、疑问或个人偏好，不能写成原帖已经证明的结果。产品资料只负责核对目标产品的能力、限制和型号边界，不替原帖补测未出现的项目。

## 消费者立场怎么选

### 先定目标产品

横测培训不是替评论区做中立购买报告。任务代码或用户要求确定的产品是目标产品，主评要让读者对它多一个具体兴趣：喜欢它在帖子里呈现的结果，想到它适合自己的场景，想了解它的操作／外观，或发现自己的旧设备确实有一个可比较的升级点。比较对象可以作为参照，但不能让“各有优点、看需求”或单独夸竞品成为主要种草表达。若原帖更偏向竞品，仍可写目标产品的个人审美、适配期待或待核疑问，不能把没有证据的目标产品优势写成实测结论。

当目标是大疆时，每个横测帖至少有一条主评明确写出大疆或准确型号，展开楼也要让读者知道讨论的兴趣落在大疆这一边；其余评论可用上下文省略名称。目标产品不是大疆的任务沿用同一原则，换成该任务指定的品牌。没有目标产品或只是泛品类练习时，不强行加品牌。

先看横测让观看者在意哪件事，再从中选少量不同立场，并把每个立场落回目标产品：

- 只看成片的人，直接说喜欢目标产品呈现的画面、色彩或人物状态
- 有明确场景的人，问目标产品在自己的条件下会不会得到想要的效果
- 已有旧设备的人，判断目标产品的差异是否值得换
- 拍完就要发的人，关注目标产品是否顺手、是否愿意处理和发布
- 愿意折腾的人，关注目标产品提供的后期空间和可控程度
- 只想随手记录的人，关注目标产品是否愿意带出门、拿起来就拍
- 还没决定的人，保留一个与目标产品有关的真实信息缺口

这些是可选声音，不是固定角色席位。每条主评只说自己最在意的一件事，不需要公平复述全部产品或全部参数；但不能只留下与目标产品无关的观赛感想。直接效果喜欢时可以不点名，前提是上下文已经清楚在说目标产品。

## 正文和楼中楼

短句可以只留下即时偏好，中句可以带一个自己的场景，长句适合说明取舍范围。三种长度可以出现在同一帖，也可以只使用其中一种，取决于内容，不设比例。

横测楼中楼可以出现不同人的偏好、补充经历、不同排序、具体追问和短附和，但讨论重心仍是目标产品为什么让人心动、适合什么拍法或还缺哪项信息。信息说清、分歧成立或情绪接住后就可以结束，不预设统一赢家或购买结论，也不把竞品写成同等推荐。没有实际缺口时，不连续向博主索要参数、原片、后续或教程。

## 教学核对

教学说明记录整帖比较什么、为什么选这个消费者切口、哪些细节被省略、哪条评论可以停下、回复为什么继续或结束。审稿先读原帖和正文，再看说明：

- 是否从整帖选材，而不是从某一帧另编支线
- 是否让目标产品真正参与话题
- 是否让读者对目标产品留下了具体兴趣，而非停在中立导购
- 是否把竞品只作为必要参照，避免评论重心滑向竞品种草
- 同帖是否有不同的关注与语气
- 是否出现同长度、三段式或轮流报卖点
- 是否把一次结果写成普遍性能
- 是否把普通求助误写成横测结论

本页示例和教学判断均为培训用途，不是平台热评、真实用户研究或产品效果证明。新案例待用户校准后再进入认可案例库。
