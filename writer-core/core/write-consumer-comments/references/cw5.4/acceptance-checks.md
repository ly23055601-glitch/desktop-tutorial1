## 人工验收标准

- 同一帖子里的主评可以分别表达画面偏好、场景适配、操作顺手、后期取舍或升级保留，不要求每条提及全部产品
- 短反应、中等场景联想和较长选择态度可以并存，不能用固定短中长顺序凑差异
- 回复可以出现不同偏好、补充经历、具体信息缺口或一句附和，也可以在观点说清后结束
- 多个产品名、标签或评论区猜测不能单独触发横测
- 未核验的竞品能力、未出现的设置和作者没有说过的结果不能写成事实
- 复核顺序始终是原帖整体 → 比较轴与证据 → 消费者切口 → 正文与回复

通过结构检查只说明格式和来源绑定正常；横测是否像真实消费者、是否留下具体产品兴趣，仍由语义审稿和用户校准决定。
