# 使用体验与表达材料

补充日期：2026-09-08。供五品线共用的材料收录与选材参考；写法、数量和交付仍依[当前入口](../SKILL.md)。优先补强方向帮助找材料，不限定各品线只能讲一种卖点。360／oq优先看空间视角、拍后选择及使用者的画面偏爱；Mic／dm优先看实际声音、佩戴连接和录制／处理过程，其他兴趣继续按作品取材。

## 四类值得保留的材料

**消费者随口说出的使用感受。** 保留语音、聊天或拍完后的原话，以及这句话是在看什么、做什么时说的。喜欢哪里、平时怎么用、什么情况下会想起拿出来，都可以成为线索。不先改成卖点文案，不补说话者没说过的动机。语音保留原文件和对应时间；转写另标“转写”，听不清处留缺，不用顺畅句子填补。

**完整原帖、主评和实际讨论。** 一起保留作品、说明、主评及回复的直接对象；谁接了哪一句、是否再次发言，应能看懂。只取得部分楼层就注明可见范围，不能称完整讨论。高赞不是收录门槛，短附和、不同偏好、聊两句结束和零回复主评也有价值。它们用于观察为什么接话、何时停下，不把现实短楼补写成假装采集到的长楼。

**不同使用阶段的表达。** 初次了解的人可能刚对一种画面感兴趣，挑选中可能在意已有设备能否满足，上手后可能注意具体操作，形成习惯后可能说何时会用或为什么不用。这些是检索提示，不是人群规律或规定台词。同一个人可以熟悉单镜头拍摄却刚接触全景后期；同时保留他的熟悉度、当前偏爱和打算，未知不推断。身份只有影响理解时才补。

**认可与不认可的原句对照。** 并排留原句、实际修改稿与用户明确评价，标注对应作品、句子或楼层和日期。区分保留、解释太多、消费者口吻成立等具体判断；没有修改稿不必制造一个。认可一句不等于认可整楼、整批或所有相似句式，产品专属判断不扩到五品线。助手建议、独立审稿与用户评价分开，沉默不算通过；既有认可范围见[反馈摘要](feedback.md)。

## 一份材料可以很轻

在常用[帖子类型](post-type-selection.md)下面放“一份完整作品＋必要的设备与处理说明＋几句原话或实际讨论”即可。沿用原类型定义和出处，不另立卖点分类，不为补库重标历史表。下列是可选备注，写自然文字即可，不新增必填表格或机器字段：

- 作品文件或原链接、关注片段的位置；当前是否缺音轨、上下文或部分回复。
- 已确认的准确型号，以及影响理解的模式、配件、处理软件和步骤；哪些仍未知。
- 使用者原话或讨论原记录、说话时看到的内容、直接回复关系。
- 已知的使用阶段和偏爱；用户明确评价指向哪一句、适用到哪里。

360材料可把同一段原始全景素材与不同取景的导出结果放在一起，说明实际做过的取景、跟随或剪辑处理，再保留使用者偏爱某一版的原话。缺原片、另一版导出或本人解释时就列待补，不由成片倒推原始设置，不替使用者解释选择。公开能力与条件由产品知识路径核验。

Mic材料可将带声音的完整口播、采访或边走边聊片段，与佩戴位置、实际连接宿主、录音来源和已知后期说明对应，再保留本人回听时的原话。对照要区分同一原音的不同处理与先后两次录制，未知条件留缺；字幕、抽帧或音频转写不等于实际听过。产品适配包或宿主提供的Mic体验资料可补充观察方向，现有候选不能算已完成声音评测。

实际读取新链接仍走[入口中的统一读取规则](../SKILL.md)，本页不另设采集办法。用户已提供的充分材料可直接整理；尚无材料时只在现有说明中列待补项，不创造消费者引语、评论关系或认可记录。

## 完整材料只为选准一句

先理解整帖和产品角色，再从材料里找此刻最值得说的一个兴趣：一种画面偏爱、一个使用习惯、一处操作感受，或一个有来由的期待。材料较多不意味着正文要逐项交代；不把背景、场景、卖点与总结拼成固定结构。有作用的细节可留，说清即可停，具体判断见[表达参考](writing-reference.md)。

用户提供原话、语音转写、编辑解释、假想训练稿和用户明确评价分别保留身份。编辑归纳不加引号冒充原话；合成命题与人物经历只进入训练稿，不回写为真实材料。真实短讨论可做局部教学，但不自动证明新稿满足完整交付；新稿数量、展开要求和检查仍以当前共享入口为准，不能借材料少或零回复样本规避。
