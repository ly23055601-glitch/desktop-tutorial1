      Osmo Mobile SE 的磁吸手机夹可以反复拆装使用吗？
      可以。
      Osmo Mobile SE 的磁吸吸力有多大？
      Osmo Mobile SE 的磁吸吸力可达 47.5 N，能吸住两瓶两升装汽水相当重量的物体。
      Osmo Mobile SE 的磁吸手机夹/云台端的外观是否容易磨损？
      Osmo Mobile SE 的磁吸手机夹表面采用了镜面抛光等一系列复杂处理工艺，令外观更精美。
      同时因为采用了更方便的快拆设计，反复拆装会对外观造成一定磨损，但在产品保修期内不影响云台的功能和性能。
      Osmo Mobile SE 的磁吸功能是否会对手机或其它物品造成干扰或影响？
      Osmo Mobile SE 采用特殊的磁路封闭设计，对手机性能不会造成影响，部分手机指南针因为角度原因，可能会出现“需要校准”的提示，只需按照手机提示进行校准即可正常使用。
      但所有的磁铁产品均含有磁性，请勿将 Osmo Mobile SE 与银行卡、心脏起搏器、RAM 芯片和硬盘等产品靠近。
      Osmo Mobile SE 的磁吸对位不准确，应怎么处理？
      请观察磁吸手机夹上的圆点以及云台横滚（Roll）轴电机上的圆点，并保证两者的圆点对齐。
      手机与云台进行磁吸连接后，请扭动横滚（Roll）轴电机，保证手机与云台连接牢固。
      Osmo Mobile SE 安装手机后，使用广角相机时云台是否会进入画面？如果云台进入画面，应怎么处理？
      部分手机因为手机广角镜头布局以及尺寸问题，使用广角镜头拍摄时画面中有可能出现云台（比如华为 P40、华为 Mate 20 Pro）。
      解决方案：调整磁吸手机夹位置，将其往远离镜头的方向移动，直至云台不再入镜（适用于华为 Mate 40 Pro+、华为 Mate 40 Pro、华为 P40、iPhone 11、iPhone 11 Pro、iPhone 12 Pro、小米 10 Pro、Vivo X70、三星 S10+ 等手机）。
      Osmo Mobile SE 是否需要调平？
      Osmo Mobile SE 采用了更大扭矩的电机，无需精准调平。
      如果使用磁吸手机夹，只需要粗略夹持在手机中间位置即可。
      Osmo Mobile SE 兼容哪些手机？

      Osmo Mobile SE 兼容市面上大部分主流手机，推荐搭配使用的手机宽度为 67 至 84 毫米、厚度为 6.9 至 10 毫米、重量为 170 至 290 克。
      在 DJI 官网可查看手机兼容列表。

      如何开启 Osmo Mobile SE 的手势控制功能？支持哪些手势动作？
      手机与云台进行磁吸连接后，打开 DJI Mimo app，在软件拍摄界面点击快门旁的【手势】图标，再点击【？】可查看具体手势的使用方式。
      如何使用 Osmo Mobile SE 的云台智能跟随功能？
      有三种方式：
      1. 按一次扳机键即可以进入智能跟随模式。
      2. 在 DJI Mimo app 拍摄界面，用手画框选中跟随目标即可开始跟随。
      3. 在 DJI Mimo app 内开启手势跟随功能，参照【？】中的手势，触发拍照/录像和跟随模式。
      如何切换 Osmo Mobile SE 的横竖方向？
      有两种方式：
      1. 在开机状态下，连按两次切换按键，即可在横竖方向之间切换。
      2. 在开机状态下，用手掰动云台，即可在横竖方向之间切换。
      如何使用 Osmo Mobile SE 的待机模式？
      在开机状态下，连按三次 M 按键，即可进入待机模式。
      进入待机模式后，按任意按键即可退出待机模式。
      如何锁定 Osmo Mobile SE 的云台？
      在开机状态下，长按扳机键可锁定云台。
      如何使 Osmo Mobile SE 云台回中？
      在开机状态下，快速短按两次扳机键可使云台回中。
      Osmo Mobile SE 如何切换前置及后置相机？
      有两种方式：
      1. 按一次切换按键。
      2. 在 DJI Mimo app 中可以切换前后置摄像头。
      相比 Wi-Fi 连接，Osmo Mobile SE 的蓝牙连接有什么优点？
      相比 Wi-Fi 连接，蓝牙连接的速度更快；初次匹配成功后，下次开机会自动重新连接；蓝牙连接更省电。
      Osmo Mobile SE 如何忽略已经连接过的设备？
      1. 在手机蓝牙设置菜单中选择忽略 Osmo Mobile SE。
      2. 同时按住拍摄按键、切换按键和扳机键 1 秒，可以清除设备的蓝牙配对信息。
      Osmo Mobile SE 和 DJI OM 4 SE 固件是否通用？
      不通用，DJI Mimo app 连接云台设备后，会推送对应云台设备的固件。
      Osmo Mobile SE 固件升级时，状态指示灯如何闪烁？
      通过 DJI Mimo app 升级固件：
      1. 正在升级时状态指示灯为红绿闪烁。
      2. 升级成功则为绿色常亮。
      3. 升级失败则红绿闪烁并在 DJI Mimo app 界面提示。
      若 Osmo Mobile SE 固件升级失败，应如何处理？
      1. 重启云台设备后再尝试一次。
      2. 如手机仍无法连接云台设备，请联系 DJI 官方售后服务。
      如何使用 Osmo Mobile SE 手柄控制手机相机变焦？
      上下推动手柄左侧的变焦滑杆即可控制相机变焦，变焦后的图像品质取决于手机镜头的拍摄性能。
      Osmo Mobile SE 防水吗？
      不防水。
      Osmo Mobile SE 启动后，拍摄画面出现歪斜，应如何处理？
      1. 请检查磁吸手机夹与云台磁吸位置的对位是否准确。
      2. 请检查磁吸手机夹是否夹持在手机中间位置。
      3. 如确认以上操作无误后仍然存在歪斜，请进行云台自动校准和云台水平微调。
      手机能否在佩戴保护壳的同时使用 Osmo Mobile SE？
      磁吸手机夹可以配合手机保护壳使用 Osmo Mobile SE。
      相比 DJI OM 4 SE，Osmo Mobile SE 有哪些提升？
      Osmo Mobile SE 主要有以下升级：
      1. 新增了状态显示面板，可通过 M 按键切换云台模式。
      2. 优化了摇杆，操控感更佳。
      3. 优化了磁吸手机夹，夹持大尺寸手机更牢固。
      4. 优化了智能跟随效果。
      5. 增加了拍摄指导功能。
      DJI Mimo App
      如何使用 Osmo Mobile SE 进行旋转拍摄？
      有两种方式：
      1. 通过 M 按键切换云台模式至旋转拍摄。
      2. 在拍照/录像/慢动作视频/运动延时模式下，在 DJI Mimo app 界面找到“设置 - 云台”菜单，在“跟随模式”中选择“旋转拍摄”，即可通过左右拨动摇杆使用旋转模式来拍摄。
      如何使用 Story 模式自定义模板？
      在 DJI Mimo app 拍摄界面进入“Story”，选择“自定义 Story”，即可开始使用自定义 Story 模式。
      如何使用动态变焦功能？
      在 DJI Mimo app 拍摄界面进入“动态变焦”模式，开始录制后稳步前行或后退即可。
      如何使用“分身全景”拍照功能？
      在全景拍照模式下选择“分身全景”，按下拍摄键后，手机每间隔 5 秒拍一张照片并横向移动云台，拍完三张照片后会自动进行全景拼接。
      智能跟随 8.0 有哪些提升？
      智能跟随 8.0 的功能有大幅升级：
      1. 构图优秀：基于默认位置（画面中心位置）或者用户自定义的构图方式，牢牢锁定跟随对象。
      2. 检测稳定：在多人场景下，即使跟随对象被其他人员遮挡，也不会跟丢。
      3. 跟随顺滑：无论是物体还是宠物（如猫、狗），只要其基本外观特征不变，就能实现顺滑跟随。
      4. 成片效果出色：在跟随过程中，支持变焦功能，且不会跟丢目标，成片效果自然流畅。
      5. 智能框选：在多目标场景下，DJI Mimo app 界面可智能显示多个目标框，点击目标框即可触发智能跟随；点击不同的目标框还可快速切换跟随对象。
      6. 在智能跟随 7.0 的基础上，优化了对单人现代舞、篮球场景、展会摄影场景的跟随效果。
      Osmo Mobile SE 在竖拍模式下可以使用 DJI Mimo app 智能跟随、延时摄影或全景拍摄功能吗？
      可以。
      手机的前、后置摄像头在使用 DJI Mimo app 智能跟随时，跟踪效果是否会有差异？
      使用 DJI Mimo app 智能跟随功能时，手机前/后置摄像头的跟随效果类似，且均支持跟随侧脸、回头等场景。
      静态延时摄影、轨迹延时摄影和运动延时摄影有什么区别？它们各自的应用场景是什么？
      1. 静态延时摄影模式需用手持三脚架固定云台设备进行拍摄，适合拍摄固定景别的光影变化。

      2. 轨迹延时摄影模式下，云台会在用户提前设置好的移动点间运动并进行拍摄，适合拍摄不同角度的风光变幻。

      3. 运动延时摄影模式适合手持拍摄，通过人的行走，记录沿途所见景象。搭配使用 DJI Mimo app 智能跟随功能，可以实现更丰富的玩法。
      DJI Mimo app 支持设定相机参数吗？
      1. iPhone：在软件界面上方设置栏选择【相机】图标，可调整感光度（ISO）、快门速度（S）和曝光补偿（EV）；需要先关闭 Auto 模式，才可调节白平衡（AWB）。
      2. Android 系统手机：支持在设置【···】中调节白平衡（AWB），但无法手动调节感光度（ISO）和快门速度（S）。
      DJI Mimo app 支持用户自行设定变焦速度吗？
      支持。
      DJI Mimo app 支持用户自行设定摇杆的控制速度吗？
      支持，DJI Mimo app 提供快、中、慢三挡控制速度。
      DJI Mimo app 支持设置录像分辨率吗？

      支持，但设置的规格和手机厂商接口的开放程度有关，和 DJI Mimo app 无关。
      请在 DJI 官网查看手机兼容列表，了解更多相关资讯。

      在 DJI Mimo app 中修改录像分辨率后，会影响手机本身的录像分辨率吗？
      在 DJI Mimo app 中修改录像分辨率后，不会改变手机自带相机功能或其他 app 的拍摄分辨率。
      在录制过程中， DJI Mimo app 能否显示手机当前的内存剩余容量？
      不能。
      DJI Mimo app 是否支持拍摄慢动作视频？

      iPhone 可以，其他操作系统的手机则取决于手机厂商接口的开放情况。
      请在 DJI 官网查看手机兼容列表，了解更多相关资讯。

      动态变焦视频合成速度为什么这么慢？
      增稳和变焦算法需要一定时间进行运算。
      拍摄轨迹延时视频时，可以使用手动测光、对焦及变焦功能吗？
      轨迹延时拍摄不支持变焦，但支持设置其他常规参数。
      拍摄轨迹延时视频时，可以设置多少个移动点？
      最少需设置 2 个，最多可设置 4 个。
      拍摄全景照片时，可以保存原始图片吗？
      可以。打开相机设置，选择“更多设置”，并点击“通用”，即可选择保存原始图片。
      拍照和拍视频是否均支持美颜功能？
      支持，美颜功能可在拍照（单拍和倒计时拍摄）和录制普通规格视频的情况下使用，部分手机支持在 1080p 或 720p 录像规格下开启美颜功能。
      前、后置摄像头是否均支持美颜功能？
      均支持。
      DJI Mimo app 是否支持直播功能？
      不支持。
      DJI Mimo app 录像时能否使用手机外接麦克风录音？
      可以。
      对于多镜头的手机，DJI Mimo app 能使用哪个镜头拍摄？
      iPhone：支持使用所有镜头镜头，用户可以根据需要自行选择。
      Android 系统手机：支持情况根据机型自身接口的开放情况而有所不同，但支持大多数手机的主摄像头及超广角摄像头。
      全景拍摄功能有哪几种模式？不同模式的拍摄逻辑是什么？
      全景拍摄功能目前共有 3 种模式，且均支持横竖屏拍摄：
      1. 3×3 全景：自动拍摄 9 张照片并合成。
      2. 1×7（240°）全景：自动拍摄 7 张照片并合成。
      3. 分身全景：自动拍摄 3 张照片并合成。
      针对 iOS 和 Android 系统的手机，Osmo Mobile SE 拍摄的素材会存储在哪里？
      iOS 系统：照片和视频存储在手机系统相册中。
      Android 系统：可选择存储在手机自带内存或外置存储卡中。
      能否设置 Osmo Mobile SE 的智能跟随参数和全景照片规格？
      不能。
      手表遥控
      DJI Mimo app 兼容哪些 Apple Watch 和 iPhone？
      Apple Watch 型号：Apple Watch Series 7/8/9、Apple Watch SE 2、Apple Watch Ultra 1/2，系统需为 9.0 以上。iPhone 型号无限制，系统需为 iOS 16.0 及以上，且手表遥控功能仅适用于 Osmo Mobile 6、Osmo Mobile SE。
      如何在 Apple Watch 上使用 DJI Mimo app？
      1. 请将 Apple Watch 与 iPhone 配对，并在 iPhone 上将 DJI Mimo app 更新到 2.0.4 及以上版本；
      2. 在 iPhone 上打开 DJI Mimo app，再在 Apple Watch 上打开 DJI Mimo app 即可。
      在 Apple Watch 上使用 DJI Mimo app 时，视频和照片清晰度如何？
      受到 Apple Watch 图传带宽限制，图传分辨率与原生相机有一定差异，不同 Apple Watch 型号之间也有所差异，但不影响构图操作和成片分辨率。
      DJI Mimo app 在 Apple Watch 上有哪些功能？
      拍照、录像、云台虚拟摇杆、智能跟随、横竖屏切换、云台回中功能。
      DJI Mimo app 在 Apple Watch 上，图传和遥控距离有多远？
      一般而言，在无遮挡的空旷环境下，有效距离是 8 米以内。
      DJI Mimo app 在 Apple Watch 上拍摄完成后，可以回看吗？
      可以预览最近一张图片，以及最近一个视频的首帧。
      如何让 DJI Mimo app 在 Apple Watch 上有更长的常亮时间？
      有，可按以下操作设置为 70 秒：在手表上打开“设置”app，然后依次轻点“显示与亮度”“唤醒时长”“唤醒 70 秒”。
      DJI Mimo app 在 Apple Watch 上使用时，是否会影响与 DJI Mic 2 或其他蓝牙设备的同时使用？
      由于 Apple 设备的蓝牙连接特性，不建议同时使用。
      畅片 App

      畅片 app 是 DJI 官方推荐的视频剪辑应用软件，拍剪功能更契合 DJI 用户使用场景，支持 AI 一键成片、海量专属视频模板、拍摄灵感教学等，助您轻松剪辑、快速成片，堪称 DJI 用户的随身拍剪策划师。

      Osmo Mobile 3 及以上设备（支持蓝牙连接）。
      Osmo Action 3、DJI Action 2、DJI Pocket 2（支持 Wi-Fi 和蓝牙连接）。
      未来适配更多 DJI 设备，敬请期待。

      畅片 app 如何与 Osmo Mobile SE 连接？
      1. 开启手机蓝牙。
      2. 打开畅片 app，进入“我的”页面，点击“我的设备”即可开始连接。
      使用 Osmo Mobile SE 连接畅片 app 后，可以使用哪些功能？
      畅片 app 提供多场景拍摄脚本：郊游、公园、户外露营、海边、城市、儿童、探店、运动等等，拆解脚本结构，多方位拍摄指导，助您快速上手和出片。
      连接 Osmo Mobile 系列设备后，畅片 app 还支持智能跟随、防抖、美颜等功能。
      在使用拍摄指导拍摄素材后，如何使用畅片 app 快速剪辑成片？
      打开畅片 app，进入“一键成片”功能，选择拍摄指导所拍摄的原始素材。“一键成片”会根据您的素材自动推荐主题匹配的模板，覆盖自然、城市、居家、探店、美食、萌宠、节日等多种场景，并智能选取素材中的高光片段，无须您手动编辑，直接预览成片。
      同时，您还可以随心切换多种模板，自定义调节所选片段、音乐、滤镜、文字、贴纸等内容。让您畅快剪辑，快速分享。
      Osmo Mobile SE 如何忽略已经连接过畅片 app 的设备？
      iPhone：打开畅片 app，在“我的设备”列表中查看已连接设备。向左滑动整条设备信息，然后移除设备。
      Android 系统手机：打开畅片 app，在“我的设备”列表中查看已连接设备。长按设备信息区域，然后移除设备。
      畅片 app 是否支持云台激活及固件升级？
      不支持，请下载 DJI Mimo app 完成云台激活及固件升级。
      针对 iOS 和 Android 系统的手机，Osmo Mobile SE 拍摄的素材会存储在哪里？
      iOS 系统：照片和视频存储在手机系统相册中。
      Android 系统：可选择存储在手机自带内存或外置存储卡中。

      Osmo Mobile SE 的电池是否需要激活？
      不需要。

      不能。
      Osmo Mobile SE 怎么充电？充电规格是多少？
      使用随附的充电线，将机身右侧的 Type-C 充电接口与电源连接，即可开始充电。

      可以。

      不能。
      蓝牙连接
      若附近有多台 Osmo Mobile SE，应如何确认我连接的是自己的设备？
      我们为每一台 Osmo Mobile SE 配置了一个识别码，贴于云台上。
      根据该识别码在 DJI Mimo app 界面上选择相应的设备名称进行连接即可。
      用户也可以在 DJI Mimo app 中修改自己设备的显示名称。
      Osmo Mobile SE 能否控制手机原生相机的功能？

      1. 可控制大部分手机的拍照和录像功能。
      2. 可控制华为手机（EMUI 10.0 以上版本）的拍照/变焦/切换前后置镜头/切换拍照与录像模式。
      请在 DJI 官网查看手机兼容列表，了解更多相关资讯。

      若要更换 Osmo Mobile SE 配对的手机，应如何操作？
      有两种方式：
      1. 先与已配对的手机断开蓝牙连接，并关闭该手机的蓝牙功能，再使用其他手机连接云台设备。
      2. 开启云台设备电源后，同时按住拍摄键、切换键和扳机键 1 秒，移除当前配对连接后再配对新手机。
      Osmo Mobile SE 与手机连接后，按键操作无响应，应该怎么处理？
      可分别尝试以下操作：
      1. 重启 Osmo Mobile SE。
      2. 重启 DJI Mimo app。
      3. 移除已经配对的手机（点击取消配对），关闭手机蓝牙，然后再重新开启手机蓝牙进行配对。
      * 若上述操作不可行，建议直接通过 DJI Mimo app 连接云台设备与手机，而不要通过手机系统蓝牙进行配对。

      通用。
