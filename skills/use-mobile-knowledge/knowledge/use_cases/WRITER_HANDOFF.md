# Mobile 场景怎样交给培训写手

这份资料提供选材，不提供固定评论句型。场景、人物心理和细节均为编辑假设，未来新稿维持 `training_fiction`。当批的数量、人物、回复、语气与检查继续由[Mobile 能力入口](../../SKILL.md)连接的共享写手负责；已经进入共享流程时不重新回调入口。

## 先找到这个时刻有什么值得说

从[详细场景目录](guide.md)按当次拍摄任务选卡，也可从[卖点反查表](selling-point-map.md)看同一能力的不同用途。先理解原帖实际在分享、提问或讨论什么，再判断场景关联；没有原帖时，将题目明确标成假想训练命题。

同一个旅行画面可能引起三种不同关注：常负责拍摄的人想进入画面；同行者关心拍摄会不会打断行程；喜欢构图的人想掌握人物与背景的位置。角色身份可以重叠，选择由当次语境决定，不按年龄、性别或职业固定分配心理。

卡片里的发生时刻帮助定位需求，卖点说明产品可以参与什么，心理取舍提供理解线索。正式写作取相关部分即可，不能把它们顺序拼成“遇到问题—买了产品—解决问题—推荐”的统一故事。具体细节有解释作用才取用，不为了显得真实而强加亲友、意外或小缺点。

## 可发散的关注点

| 同一拍摄任务 | 可以选择的不同关注 | 需要核对的产品边界 |
|---|---|---|
| 独自旅行入镜 | 确认站位；保留背景；少打断同行；喜欢亲自控制镜头 | 8P FrameTap手机投屏与模块预览分别说明，不据此推断与所有拍摄模式并用 |
| 家庭活动记录 | 摄影者也参与；记录互动；大家站位；希望操作简单 | 固定构图、遥控、人物跟随是不同选择；不保证每个人始终在画面内 |
| 猫狗活动 | 接近地面视角；记录表情；拍人与宠物同框；留意主体大小 | 降机位与识别跟随分别核对，猫狗不外推所有动物，不保证高速运动始终跟住 |
| 练习回看 | 看清脚步；比较两次动作；保留移动范围；自己启停 | 跟随不一定优于固定全身构图；不能把手势启停写成自动判断动作完成 |
| 口播与教学 | 开讲前确认构图；转向白板；分段重录；核对收音 | 云台转向、跟随、取景与录音输入分别核对；模块2收音未核，不套一代模块 |
| 手工和商品展示 | 看物件轮廓；交代操作步骤；安排陈列镜头；保留手部位置 | 框物不保证手和全工序入镜；8P A/B控制云台朝向，不是设备自行位移 |
| 空间记录 | 理解动线；展示变化；交代细节位置；控制讲解节奏 | 增稳不等于消除步行起伏，不添加测量、建模、业绩提升等能力 |
| 旧设备重新使用 | 从现有配件开始；练一种操作；减少学习负担；发现已有用途 | 逐款保留杆、脚架、拨轮、滑杆与软件差异，不默认需要升级 |

表中关注点是可选联想，不是每类场景必须覆盖的项目。场景卡的 `when_not_needed` 可帮助判断是否值得使用相关能力，也不要求每条评论人为加一句顾虑或否定。

## 分别保存三种材料

需要观察实际拍法、使用者原话或真实接话时，另查[体验材料](../experience_materials/guide.md)。详细场景卡仍是编辑假设；没有完整作品不能用卡片补原片过程，旧款自述也不代表8P／8实拍。资料可以完整，具体评论只取一个有来由的兴趣。

- 产品事实：回到卡片引用的完整事实与当前官方来源，保留准确型号、组件、手机组合、连接路径、软件条件、核验日期和相关缺口。卡片中的一句用途解释不能替代这些依据。
- 原帖证据：只记录实际读取或用户明确提供的画面、话语、设备和上下文。本库的“适用话题”不能变成原帖确实发生了什么；真实社媒链接仍沿统一读取流程。
- 训练人物：购买、持有、使用经历、关系、情绪和可选生活细节进入当批 `personas`。这些可以虚构，但不能写回产品记录或用来补齐真实原片。

`writing_material` 的内容是待校准的构思选项，不是认可范文。当前资料没有实际主评或回复，因此没有把选材检查冒充正式训练批次检查。

## 后续调用示例

下面是检索与创作任务的示意，不是已经存在的帖子，也不预设固定评论数量：

- “调用 Mobile 场景卖点库，围绕一个人旅行、想进画面又不想耽误行程，找适合8P的不同关注点；再按共享写手标准产出培训草稿。”
- “这次假想训练主题是猫狗日常，用Mobile8相关场景取材，分别考虑低机位和跟随，先核对模块与手机条件。”
- “已有Mobile6，围绕周末手持练镜头发散，不借用新品遥控和追踪模块；按共享写手选择值得表达的部分。”
- “围绕手工演示找场景：展示成品与记录完整工序分别考虑，若固定构图更合适就保留这个判断。”

检索到某卡后，可以用 `python3 scripts/use_cases.py query --id MOBILE-USE-001` 展开完整资料；按具体型号与关键词组合筛选，结果会同时显示待核和冲突。脚本从自身所在目录定位知识，跨项目无需读取 op 历史任务。
