# Mobile 详细使用场景与培训选材

本版 48 张微场景卡，把具体时刻、拍摄任务、卖点用途、心理取舍与表达切入点连接起来。

场景与价值为编辑推演，心理为待验证假设；选材为 `training_fiction / pending_calibration`，不是用户研究、真实原帖、已发生经历或认可范文。卡片字段供分析取用，不是每条评论的必写步骤或固定句式。

## 按当前任务找场景

| 场景组 | 数量 | 可选情境 |
|---|---:|---|
| [旅行与独自出镜](travel.md) | 4 | 独自入住后，拍一段自己与窗边景色的合影；给旅行片段补一个从街角转向建筑的镜头；一天多段旅行自拍，提前决定哪几段值得开机；已有 Mobile 8，先试一段 Mimo 跟随自拍 |
| [同行与关系记录](relationships.md) | 4 | 生日合影里，让负责拍照的人也站进去；同行不想一直等，约定几个短片段再收起来；两个人都想出镜，先留一段坐着聊天的画面；朋友陆续加入画面时，理解原生人物跟拍的选择 |
| [亲子共同参与](parenting.md) | 4 | 孩子趴着搭积木，改从较低视角拍他的动作；家长加入孩子的模仿游戏，不一直留在手机后面；孩子展示新学的小动作，沿用熟悉原生相机；手持记录后一起回看，装夹也要照顾手机操作 |
| [猫狗与低角度](pets.md) | 4 | 猫沿着沙发边慢慢走，先把视角降下来；两只宠物同时出现，先明确这次想跟哪一只；已有 Mobile 8 和模块2，先核固件再试拍狗的短移动；宠物已经安静休息，用手持转向交代它周围的小环境 |
| [日常拍摄与镜头练习](everyday.md) | 4 | 下班路上只拍几个变化，拍完仍回到日常节奏；布置完书架，试一个从旧物到新物的 A/B 镜头；试拍随身物品时，先检查常用手机带壳组合是否顺手；只练一个转向，把阳台植物和窗景接在一起 |
| [舞蹈健身与技能回看](practice.md) | 4 | 独自练舞时，用人物手势减少走回手机操作；录同一段健身动作，先把机位保持一致；练带侧移的表演片段，比较 Mimo 跟随与固定全身画面；自己录一段器乐或演讲练习，先确认人和动作范围 |
| [独自口播与内容制作](solo_content.md) | 4 | 录书桌口播时，为手中的书和背景都留位置；把一节讲解拆成短段，在出镜位置开始下一段；沿用原生相机，从桌边走到白板前解释；录一段双手展开纸样的讲解，先保证内容完整 |
| [直播与远程教学](live_teaching.md) | 4 | 远程白板讲解时，从提纲走到示意图旁；双人远程对谈前，把两路声音真正送进手机；开播展示布料前，试调近处补光而不承诺颜色一致；视频通话示范打结，先让双手一直在画面里 |
| [手作与商品展示](craft_product.md) | 4 | 举起手工作品时，把跟随目标选在作品上；拍一段拌馅或折纸过程，先把完整动作范围框好；拍一排手作陈列，试不同起止朝向和转动时长；展示模型接缝时，主动决定何时拉近取景 |
| [空间与经营记录](space_business.md) | 4 | 装修进度短片中，先交代这处变化在房间哪里；记录踢脚线与地面衔接，主动把视角降下来；围绕一组展陈手持移动，让观众看见前后关系；给小店开门日记练一个从门牌转到柜台的镜头 |
| [拍摄流程与旧款再利用](workflow_legacy.md) | 8 | 已有7P，先完成一段工作台前的人物介绍；已有7，先在Mimo里试一次人物走进画面；用已有6练一次从花盆整体到叶片的焦点选择；用SE拍同一盆花，分别试横构图与竖构图；重新拿出OM5，给近期完成的小物留一段记录；换了手机壳后，重新检查常用拍摄组合；一天分几段拍店内素材，按实际工况安排电量；录制一组分段课程，分别照看云台与FrameTap的电量 |

## 检索

以下命令在本知识库目录运行；跨项目可用脚本绝对路径，参数与工作目录无关。

```sh
rg -n '同行|全身|白板|装夹|旧款' use_cases/cards.jsonl
rg -n 'MOBILE-SELL-001' use_cases/cards.jsonl
python3 scripts/use_cases.py query --model osmo_mobile_8p --keyword 合影
python3 scripts/use_cases.py query --selling-point MOBILE-SELL-002
python3 scripts/use_cases.py query --id MOBILE-USE-001
```

查询返回整张卡、所引卖点、直接和卖点关联的完整事实、官方来源登记及该型号的全部待核／冲突。多个筛选条件取交集；无命中表示未找到选材，不代表产品不支持。产品事实单独查询仍用原 `scripts/query.py`。

格式见[SCHEMA](SCHEMA.md)，维护见[总维护说明](../MAINTENANCE.md)。
