## MOBILE-USE-041｜已有7P，先完成一段工作台前的人物介绍

**型号**：Osmo Mobile 7P；场景编辑：2026-09-07（不替代事实核验日期）

**可关联角色**：[已有云台或曾经闲置的用户](../audiences/guide.md#mobile-aud-013)、[独自口播／课程录制者](../audiences/guide.md#mobile-aud-006)、[小店店主／经营者](../audiences/guide.md#mobile-aud-008)

**发生时刻**：可设为原本已有Osmo Mobile 7P，现在想给每周手作记录加一段人物介绍。准备时先清点现有手机夹和一代模块，确认能否完成这段有限移动的讲述。

**想完成的拍摄**：在已有7P的内置支撑与一代模块人物路径上，试拍工作台前的简短介绍。

**具体难点**：看到新款演示后容易把新增功能当作重新开始的前提，但当前任务可能只需要固定机位或有限人物跟随。

**卖点如何参与**：

- 按实际持有组合清点7P、对应手机夹与一代模块，不从原标准套装推定附件都还在。
- 在稳定水平无风处摆好内置支撑，先以固定画面录制人物介绍。
- 如果讲述中需要侧移，再按一代模块人物路径在Mimo外的相应App试拍；拍录按键兼容独立核对。

**对应卖点**：[杆、脚架、拨轮集中在机身，扩展人物拍摄](../selling_points/osmo_mobile_7p.md#mobile-sell-021)

**可能价值**：可能帮助已有用户把注意力放回现在想记录的内容，用现有功能检验新任务是否成立。

**心理取舍（假设）**：想要——希望重新建立记录习惯，而不是继续让设备闲置。；犹豫——担心旧设备不够新，或配件找不齐影响开始。；取舍——先完成一段可用的介绍，再判断是否确有其他功能缺口。

**可供训练选择的表达方向**（分析线索，非待复制评论）：

- 从新增任务进入旧设备价值，不靠新旧价格排名。
- 观察清点附件与选择固定机位的具体准备。
- 允许只用现有支撑也能完成任务。

**可选细节**（只有在当批训练人物中设定，或由真实材料证实后才能使用）：可虚构或待实证：工作台上展示的本周作品。；可虚构或待实证：现有配件是否仍单独收在袋中。；可虚构或待实证：讲述者是否需要在台前左右移动。

**可能适用的话题语境**（假想条件，实际选材先读原帖）：假想话题条件：原帖明确持有7P并讨论重新使用或人物记录。；假想话题条件：原帖展示7P的一代模块与工作台机位。

**不能据此替真实原帖补写**：不能反推原帖设备闲置多久或附件原本遗失。；不能把7P外观当成模块2、FrameTap或新款算法的证据。

**何时不需要这项能力**：站位不变的介绍先用固定机位即可；没有新增任务时，不必为了补齐新功能购买配件或升级。

**关键条件摘要**：单独限定Osmo Mobile 7P，内置杆与脚架不能移写为7的结构。；一代模块在7系列已核跟随范围是人物，不借8的人宠能力。；实际SKU和二手附件需另核；模块2兼容仍待核，不作肯定或否定。；支撑与App拍录条件分别确认。

**不可推论**：7P装一代模块就能跟所有宠物。；已有7P必须升级后才适合记录人物。；所有7P套装都附带相同模块。

**想完成的拍摄**：在兼容Mimo中试用无模块人物跟随，比较跟随与固定构图是否满足当前短片。

- 确认准确型号为7，在稳定水平无风表面使用内置三脚架，不寻找不存在的内置延长杆。

**可供训练选择的表达方向**（分析线索，非待复制评论）：

- 从没有模块但有明确任务的状态进入。
- 让试拍后的判断围绕画面需求，而非全体新手的购买结论。
- 分清无模块Mimo与原生系统的不同路径。

**可选细节**（只有在当批训练人物中设定，或由真实材料证实后才能使用）：可虚构或待实证：人物是拿书坐下还是从桌边走过。；可虚构或待实证：进入画面前后想保留的动作。；可虚构或待实证：先试固定构图还是先试跟随的顺序。

**可能适用的话题语境**（假想条件，实际选材先读原帖）：假想话题条件：原帖明确讨论7不装模块的Mimo跟随。；假想话题条件：原帖展示已有设备重新试拍的过程。

**何时不需要这项能力**：人物活动范围本就完整在固定画面里时不需要跟随；当前没有额外App需求时也无需立即添模块。

**关键条件摘要**：7没有内置延长杆，使用变焦滑杆而非7P侧拨轮。；无模块跟随本卡限定Mimo，不推广任意App。；鸿蒙另有适配手机与固件路径，不能说7所有原生跟拍必需模块。；模块2支持状态仍待核，未列不等于不支持。

**不可推论**：7自带延长杆与拨轮。；无模块就完全不能智能跟随。；所有手机都能得到相同最新算法。

**想完成的拍摄**：使用SE已核横竖拍切换与基础控制，练习不同画幅的构图选择。

**具体难点**：直接切换方向会改变边缘内容，横屏好看的布置未必可以不调整地搬到竖屏。

**卖点如何参与**：

- 确认是Osmo Mobile SE而非DJI OM 4 SE，按其切换键操作横竖拍。
- 分别检查花盆与窗框在两种画幅里的位置，需要时调整实际机位或取景。
- 想尝试旋转拍摄再按M键与摇杆的已核步骤练习，遇结构限位停止，不把模式当无限转动。

**对应卖点**：[围绕模式切换、变焦滑杆和Mimo练拍](../selling_points/osmo_mobile_se.md#mobile-sell-024)

**可能价值**：可能让重新拿起设备的人把学习目标缩小到一种可比较的画面差异，积累自己的构图偏好。

**心理取舍（假设）**：想要——希望知道自己为什么更喜欢某一种画幅。；犹豫——担心看了太多教程却一直没开始拍。；取舍——先比较两段简单素材，是否继续学运镜留到下一次。

**可供训练选择的表达方向**（分析线索，非待复制评论）：

- 从横竖构图的不同取舍进入，而非用模板化新手焦虑。
- 观察边缘内容与留白的选择。
- 把只做一次小练习写成主动节奏。

**可选细节**（只有在当批训练人物中设定，或由真实材料证实后才能使用）：可虚构或待实证：窗框是否希望完整保留。；可虚构或待实证：花盆旁多留一点桌面还是更靠近主体。；可虚构或待实证：横屏与竖屏分别准备用于何种个人记录。

**可能适用的话题语境**（假想条件，实际选材先读原帖）：假想话题条件：原帖准确说明是Osmo Mobile SE并讨论构图练习。；假想话题条件：原帖展示同一场景横竖拍或基础按键操作。
