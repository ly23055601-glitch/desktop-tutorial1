## MOBILE-USE-001｜独自入住后，拍一段自己与窗边景色的合影

**型号**：Osmo Mobile 8P；场景编辑：2026-09-07（不替代事实核验日期）

**可关联角色**：[独自旅行／看展者](../audiences/guide.md#mobile-aud-001)、[想拍自己、但不想在公共场合久架手机的人](../audiences/guide.md#mobile-aud-012)

**发生时刻**：抵达住处后，窗边光线和窗外景色刚好适合留一段记录。拍摄者想坐进画面，又需要确认窗框没有正好穿过头顶。

**想完成的拍摄**：用固定机位把人物、窗框和环境一起安排好，再开始一段短自拍。

**具体难点**：手机摆好后看不到屏幕，反复走回去检查会打断刚坐下的自然状态。

**卖点如何参与**：

- 选择稳定水平的桌面摆好云台，并先在手机端检查背景与人物预留位置。
- 按兼容手机路径把手机屏幕投到 FrameTap，进入画面后检查站位或坐姿并微调构图。
- 确认当前手机与 App 的遥控拍摄功能，拍一小段后回看；本场景不叠加模块跟随。

**对应卖点**：[站到画面里后查看手机取景并调整构图](../selling_points/osmo_mobile_8p.md#mobile-sell-001)、[内置延长杆与独立支腿，兼顾手持和固定取景](../selling_points/osmo_mobile_8p.md#mobile-sell-016)

**可能价值**：对想自己掌握自拍构图的人，可能把确认动作留在出镜位置，让记录更符合自己想保留的空间关系。

**心理取舍（假设）**：想要——既想在照片里，也想自己决定人和风景的比例。；犹豫——不想为了一个镜头把入住休息变成反复摆拍。；取舍——愿意先做一次连接和机位设置，换取随后自行确认构图；也接受只拍一小段。

**可供训练选择的表达方向**（分析线索，非待复制评论）：

- 人物与环境的比例由谁决定
- 进入画面后才发现的小构图问题
- 独处时的拍摄自主感与休息时间之间的取舍

**可选细节**（只有在当批训练人物中设定，或由真实材料证实后才能使用）：待虚构或待实证：坐下后头顶留白与站着试机位时不同；待虚构或待实证：窗帘边缘或椅背进入画面的具体位置；待虚构或待实证：试拍后选择保留一次转头而非整段摆姿势

**可能适用的话题语境**（假想条件，实际选材先读原帖）：假想话题条件：原帖讨论独自旅行怎样把自己拍进去；假想话题条件：原帖展示室内自拍构图或远程取景操作

**不能据此替真实原帖补写**：不能反推原帖作者独自出行、入住酒店或无人帮拍；不能把假想窗边成片描述成原帖已拍到的画面

**何时不需要这项能力**：有人愿意按自己的构图协助，或只想拍窗外风景时，普通手持或手机固定拍摄就可能够用。

**关键条件摘要**：FrameTap 手机投屏须按具体机型、系统与固件核对；手机能蓝牙连接不等于能投屏。；这里看的是手机屏幕，不能用模块镜头预览代替最终构图。；内置脚架只在无风、稳定水平表面使用；遥控快门另看 App 兼容。

**不可推论**：所有手机都能投屏、变焦和录像。；手机投屏、Mimo 拍摄和模块跟随已确认可同时开启。；从远处看见预览就保证最终画质和构图。

## MOBILE-USE-002｜给旅行片段补一个从街角转向建筑的镜头

**型号**：Osmo Mobile 8；场景编辑：2026-09-07（不替代事实核验日期）

**可关联角色**：[独自旅行／看展者](../audiences/guide.md#mobile-aud-001)、[日常Vlog初学者](../audiences/guide.md#mobile-aud-002)、[手机影像爱好者](../audiences/guide.md#mobile-aud-011)

**发生时刻**：旅行素材里已经拍了不少建筑正面照，但缺少一段说明它在街角哪里的视频。拍摄者想从路口一侧转向建筑入口，练习一个有起点和终点的镜头。

**想完成的拍摄**：用一段水平转向交代街角与建筑的相对位置。

**具体难点**：不知道怎么开始运镜，容易随手一转就把方向和停顿都交给偶然。

**卖点如何参与**：

- 先在不影响通行的位置确定取景起点、终点与转动方向。
- 选好对应云台模式，按 Mobile 8 的摇杆操作触发平移轴自动旋转，观察何处需要停止。
- 试拍后比较转动是否太多，按需要停止回中；完成后收回延长杆并折叠。

**对应卖点**：[用摇杆触发自动旋转，先练一种运镜](../selling_points/osmo_mobile_8.md#mobile-sell-008)、[磁吸装夹与折叠收纳，便于穿插拍摄](../selling_points/osmo_mobile_8.md#mobile-sell-020)

**可能价值**：可能给初学者一个可观察、可修改的小练习，让片段承担说明空间关系的任务。

**心理取舍（假设）**：想要——想知道自己为什么转镜头，而不只是模仿一个炫技动作。；犹豫——担心现场学功能拖慢游览，转得太久也让片段没重点。；取舍——只练一种操作并接受一次试拍，把学习范围限制在当天能理解的小动作。

**可供训练选择的表达方向**（分析线索，非待复制评论）：

- 旅行素材缺少的是位置交代还是画面数量
- 学会停止与决定开始同样重要
- 同一街角如何用动作而非术语讲清位置

**可选细节**（只有在当批训练人物中设定，或由真实材料证实后才能使用）：待虚构或待实证：起点选路牌、终点选入口的构图意图；待虚构或待实证：回看后发现转过头又重新缩短镜头；待虚构或待实证：拍完把设备收起继续逛街的动作

**可能适用的话题语境**（假想条件，实际选材先读原帖）：假想话题条件：原帖在讨论新手第一次练云台运镜；假想话题条件：原帖展示城市漫游的镜头衔接

**不能据此替真实原帖补写**：不能认定原帖作者的建筑镜头由自动旋转完成；不能替原帖杜撰拍摄地点、失败次数或学习进度

**何时不需要这项能力**：只需记录建筑外观，静态构图已经交代清楚时，无需为用功能而添加旋转。

**关键条件摘要**：自动旋转操作保留 Mobile 8 的模式与停止方式；不是 8P 的 A/B 点设置。；无限位只指平移轴，不能把横滚旋转也写成无限。；手机装夹和配件平衡需检查；云台不会自行选择建筑或剪辑成片。

## MOBILE-USE-003｜一天多段旅行自拍，提前决定哪几段值得开机

**型号**：Osmo Mobile 8P；场景编辑：2026-09-07（不替代事实核验日期）

**可关联角色**：[独自旅行／看展者](../audiences/guide.md#mobile-aud-001)、[已有云台或曾经闲置的用户](../audiences/guide.md#mobile-aud-013)、[同行旅行但拍摄节奏不同的人](../audiences/guide.md#mobile-aud-014)

**发生时刻**：一天行程里有出发、逛街、休息和回程几个想记录的节点。拍摄者希望把手机和云台的电量留给真正想拍的片段，而不是一直开着等待。

**想完成的拍摄**：按实际拍摄组合安排分段使用、补电机会和必要的手机供电。

**具体难点**：看到最长续航数字后很容易把所有配件和拍摄工况算成一种用法。

**卖点如何参与**：

- 先列出需要手持、固定自拍或遥控的几个片段，不给每段默认加跟随与补光。
- 分别检查云台与FrameTap电量，再按所用模块、跟随和补光估计消耗；模块作为云台供电的工作负载，不作为独立电池检查。
- 需要给手机供电时确认输出接口与适用线材，并把消耗云台电量纳入后续安排。

**对应卖点**：[按拍摄组合安排续航，并可给手机供电](../selling_points/osmo_mobile_8p.md#mobile-sell-018)、[内置延长杆与独立支腿，兼顾手持和固定取景](../selling_points/osmo_mobile_8p.md#mobile-sell-016)

**可能价值**：可能让有限的拍摄注意力和电量围绕具体片段分配，而不是围绕一个最大时长数字产生过高预期。

**心理取舍（假设）**：想要——希望当天重要片段还有电可用，也希望旅行本身保留空白时间。；犹豫——担心电量焦虑让自己不断看设备状态。；取舍——愿意放弃持续待机和没必要的配件组合，换取更明确的分段拍摄计划。

**可供训练选择的表达方向**（分析线索，非待复制评论）：

- 续航关切背后是连续拍摄还是一天内零散使用
- 应急给手机供电和保留云台电量的权衡
- 设备准备如何服务几个明确片段

**可选细节**（只有在当批训练人物中设定，或由真实材料证实后才能使用）：待虚构或待实证：在午间休息时整理片段与查看电量；待虚构或待实证：原计划全程带着拍，后来只保留出发与回程；待虚构或待实证：某一段临时手机供电后调整后续安排

**何时不需要这项能力**：只拍很短一段且电量充足时，不需要把补电和多配件准备变成额外流程。

**关键条件摘要**：基础、模块跟随、补光与手机供电不是同一续航工况。；FrameTap 的待机口径不代表持续投屏或操作时长。；给手机供电会消耗云台电量；接口与线材需按当前组合核对。

## MOBILE-USE-004｜已有 Mobile 8，先试一段 Mimo 跟随自拍

**型号**：Osmo Mobile 8；场景编辑：2026-09-07（不替代事实核验日期）

**可关联角色**：[独自旅行／看展者](../audiences/guide.md#mobile-aud-001)、[已有云台或曾经闲置的用户](../audiences/guide.md#mobile-aud-013)

**发生时刻**：准备下一次短途出行时，拍摄者重新拿出了已经拥有的 Mobile 8。比起先添配件，他想先验证现有设备能否拍好一段走进画面的自拍。

**想完成的拍摄**：在 Mimo 内完成一次无模块人物跟随试拍，再判断任务是否覆盖。

**具体难点**：把不装模块误解为完全不能跟随，会让用途验证变成先购物再学习。

**卖点如何参与**：

- 使用兼容 Mimo 与手机，先在可控场地摆好稳定固定机位。
- 在 Mimo 内选择人物，安排一段短距离走入画面的动作并试拍。
- 回看人物大小和背景变化，再决定继续调整 Mimo 设置、改固定构图或另查其他跟随路径。

**对应卖点**：[先用Mimo尝试不加模块的跟随](../selling_points/osmo_mobile_8.md#mobile-sell-010)、[内置延长杆和支撑可承担一次简单机位安排](../selling_points/osmo_mobile_8.md#mobile-sell-014)
