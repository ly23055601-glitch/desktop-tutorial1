# 产品总览：先分清手机、云台、软件和模块

Osmo Mobile 是用于手机拍摄的机械云台。以 Mobile 8 为例，三轴机构配合内置延长杆和三脚架承担持机、转动与机位布置；具体拍摄规格仍受手机和使用的 App 影响。不能把手机相机、App 算法或外接模块的能力全部写成“云台自带”。[设备定位](osmo_mobile_8.md#mobile-8-identity-001)、[Mimo 与手机差异](osmo_mobile_8.md#mobile-8-tracking-002)

## 同一段功能描述里的四个主体

| 主体 | 阅读时要确认什么 |
|---|---|
| 手机 | 具体机型、宽厚及整体重量、镜头、保护壳、系统版本和厂商开放能力 |
| 云台 | 准确代际、机械范围、按键和拨轮、安装条件、供电与固件版本 |
| 拍摄 App／系统接口 | 使用 Mimo、系统相机还是第三方 App；分辨率、镜头、跟随和原生控制是否适配 |
| 追踪模块／遥控器 | 配件代际、连接路径、可跟主体、取景来源、遥控功能、补光及收音是否分别有依据 |

这些是编辑整理的核对维度，具体结论以[型号事实](../INDEX.md#按型号阅读)和[兼容记录](../compatibility/guide.md)为准。

## 容易混淆的三件事

**云台跟随模式与智能主体跟随不同。** 双轴、平移、全域跟随描述手机朝向怎样响应手柄转动；智能跟随描述系统如何识别和追踪画面主体。全锁定也不表示锁住某个人物。[模式说明](osmo_mobile_8.md#mobile-8-stabilization-002)、[全锁定](osmo_mobile_8.md#mobile-8-stabilization-003)、[Mimo 跟随](osmo_mobile_8.md#mobile-8-tracking-001)

**机械旋转范围与效果评价不同。** 例如 Mobile 8 的平移轴可无限位旋转，另外两轴仍有结构限位；这条机械事实不能证明“所有方向都无限旋转”或“怎么跑都完全不抖”。[旋转范围](osmo_mobile_8.md#mobile-8-stabilization-001)

**能装上手机与能用全部功能不同。** 手机连壳的厚度、外接镜头总重和遮挡需要一起检查，具体 App／系统跟随也有独立要求。[安装范围](osmo_mobile_8.md#mobile-8-compatibility-001)、[带壳与外接镜头](osmo_mobile_8.md#mobile-8-compatibility-002)、[原生跟拍](osmo_mobile_8.md#mobile-8-tracking-004)

## 怎么把事实用于场景理解

从拍摄任务出发，再确定设备与路径。例如固定口播先考虑摆放和构图，自拍先确认所用相机与跟随方式，宠物拍摄再确认具体跟随对象及环境条件。场景卡只解释这些选择，不提供真实消费者结论，也不预设每个问题都要推荐购买。

阅读顺序建议：[代际差异](differences.md) → [跟随与遥控](tracking.md) → [具体问题](faq.md) → [场景解释](../scenarios/guide.md)。
