# 本项目已确认的本人素材

<a id="main-author"></a>

来源：本项目用户在2026-09-05的写作方向讨论中明确说

> 我自己本身就有pocket，也有使用过的，所以你也可以轻微写用过的感受的

可确认：当前用户拥有并使用过Pocket产品线设备

尚未确认：具体代际、颜色、套装、购入时间、使用频率、拍摄习惯、个人行程、家庭职业，以及具体的满意点或问题

本人备选稿可说“Pocket已经有了”。“这个按键我喜欢”“想试这种拍法”是当前看完材料后的态度，不等于声称上手实测。不能把拥有设备扩写成“上次在云南用过”“每天都带”“用了一年防抖特别稳”等经历

这些素材只属于当前用户，不适用于其他客户、博主或楼中楼的其他角色。若后续任务换了发布者，不继承这里的拥有事实。多条备选稿可以使用同一人的素材，但不表示有多位真实消费者都说过这些话

需要具体体验才向用户补问型号与真实感受；其余角度可继续写，不把补问变成每次写作的前置门槛。后续新确认的材料记录原话、日期、归属，不能从优秀案例推断个人背景
