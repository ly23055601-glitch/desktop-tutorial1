## 当前稳定偏好

- 抖音、小红书与 B站的实时采集只按 [统一读取 Skill](../../read-social-links-with-social-helper/SKILL.md) 执行；本风格基线只消费证据包，不定义批次、兜底或重试。
- 无法读取就不猜。先确认平台、型号、画面/台词/观点和证据强度，参数、竞品与功能因果按条件核验。
- 每链接默认 3 组纯净评论，每组 1 条主评与 2–4 条楼中楼；身份、心理、证据级与种草级仅用于内部判断。
- 一条主评只抓一个瞬间，不盘点全片，不用三连画面证明看过视频。
- 真人感来自少解释：允许省略、半句话、突然收住、短问、单纯偏好和轻微跑题，不强行完成逻辑闭环。
- 三条主评的长度、开头、标点、情绪和回复数量不要排队；楼中楼可以只接情绪、直接反驳、保留分歧或聊到一半停。
- 产品关联要能回答“这对谁有什么实际用处”，不靠增加产品名密度。产品结果、用户收益与条件式选择分散在整组互动中。
- 每组只讨论一个产品点；每链接最多一组出现克制购买倾向，不催单、不制造虚假共识。
- 受众和心理只决定关注点，不写成虚构身份传记；不得编购买、持有、使用、关系、职业或故障经历。
- 批量低同质化先改变锚点、任务、立场和互动入口，再改变句长与产品位置；只换同义词不算去重。
- 上下文只保留证据胶囊、状态、滚动计数和必要指纹，不长期携带旧评论全文或原始抓取日志。
- 默认不展示分析，只给纯净可复制成稿。

## 当前 Nano 任务覆盖项

这些规则比 op 中较早的模板优先：

- **不采用固定“两明一隐”。** Nano 是否在主评或回复中点名，由当前内容决定；不得形成固定露出比例、固定组别或固定位置。
- **保留最低自然识别。** 明确以 Nano 为主题的链接，整组默认至少一次自然出现 `Nano` 或 `Osmo Nano`；这不是固定组别或次数配额。
- **禁止三连景、三连动作、三连卖点。** 原帖本身不是清单或强对照时，一条只留一个触发点。
- **不固定楼中楼剧本。** 不安排“认同—科普—反驳—总结”，也不机械循环 `2/3/4`。
- **不靠代称制造随机感。** “Nano”“这小东西”“挂脖这个”等称呼都不能重复轮播。
- **去 AI 优先于信息完整。** 若产品解释让评论变成测评总结，将解释下放一层、改成问题或直接删除。
- **不做同义追问接力和万能公平总结。** 同一问题没有新增立场就停；竞品出现也不自动补“各有用途、看需求”。
