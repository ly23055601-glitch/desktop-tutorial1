# Osmo Nano 平衡种草

本参考用于提升产品关联与购买联想，同时保持真人感和事实边界。内部标签不出现在纯净版中。

## 一条链路，分散表达

有效链路是：`链接锚点 → 产品促成的结果 → 用户可感收益 → 条件式选择`。

- **锚点**：原帖可定位的一个动作、画面、台词、测试结果或明确观点。
- **产品结果**：Osmo Nano 在该锚点中实际改变了什么。因果不完整时使用疑问或有限判断。
- **用户收益**：把产品结果翻译成少占手、少漏拍、少返工、愿意带出门、记录更连贯等具体结果；这些只是候选方向，必须由当前证据支持。
- **条件式选择**：只在某类高频场景成立时表达关注或偏好，不下无条件购买结论。

主评最多承载相邻两层。其余可由回复补一层，也可以停在有价值的疑问或分歧；不要为了种草把每组都写成完整论证。

## 证据等级与上限

| 证据级 | 当前链接能证明什么 | 单组上限 |
| --- | --- | --- |
| `A` | 明确功能演示、教程、同条件对比或可核验测试结果 | 可到 `S3` |
| `B` | 能确认机型与成片/动作，但功能因果未完整展示 | 最多 `S2` |
| `C` | 仅包装、机身、简单开箱或信息有限的外观展示 | 最多 `S1` |

种草级只用于内部 QA：

- `S0｜看见`：情绪、产品露出或锚点反应。
- `S1｜理解`：一个功能、使用门槛或购前问题。
- `S2｜获益`：把一个有证据的产品机制转成可感收益。
- `S3｜决策`：形成未来场景投射、化解一个购买阻力或给出条件式选择。

证据 A 的演示、教程或对比内容，通常应有一组达到 `S3`、另一组达到 `S2`；证据 B 通常应有一组达到 `S2`、另一组达到 `S1`；证据 C 只讨论可见体积、佩戴/安装动作、套装、上手门槛和真实购买顾虑，不推断画质、稳定、收音或耐候表现。C 级同一链接最多一组把“证据不足、等实拍”作为主要观点，其余组改用不同的可见细节或具体上手问题，不能三组同义劝谨慎。若达到目标会迫使评论变成广告总结，宁可降级并在 QA 中记录原因。

## 任务机制

每组从下列机制中选一个，不固定顺序，也不要求每次凑齐同一组合：

- 需求唤醒：让常遇到该场景的人看见原有拍法的缺口。
- 结果想象：把视频中的结果投射到可信的未来使用场景。
- 产品归因：只解释证据支持的一个 Nano 产品点为何促成结果。
- 选择缩窄：按拍摄对象、是否占手、视角、携带或工作流给出克制倾向。
- 升级判断：只有链接存在代际或竞品证据时，讨论是否改变高频工作流。
- 阻力化解：回应佩戴视角、录制状态、携带、操作或其他真实顾虑。
- 合理反方：指出一个不适用条件或仍需核验的问题，不把已成立的收益全部推翻。

每链接最多一组出现“有点想要”“这种场景会考虑”等购买倾向。禁止“闭眼入、必买、无脑冲、吊打”，也不得伪造下单、持有或使用经历。

## Nano 受众视角

受众是观察位置，不是发布者身份。按当前锚点从以下角度选择，不需要自报职业：

- 双手被占用、需要第一视角记录的人；
- 旅行、城市漫游或日常陪伴中重视携带率的人；
- 做饭、手作、装修巡场或工作过程记录者；
- 家庭、宠物与不可重复瞬间的记录需求；
- 手机主拍、已有相机或在 Nano 与其他设备间比较的人；
- 关注构图高度、广角观感、录制确认、稳定、声音或后期流程的人。

这些角度不能自动证明 Nano 的能力。只有画面或官方事实支持时，才能把其中一个写成产品结果；否则保留为购前问题。

## 语义检查

- 锚点能否在当前链接定位？
- 产品是否确实促成了所写结果，还是只被句尾点名？
- 所谓收益是否具体到某个动作或工作流，而不是换一种方式念卖点？
- 证据级是否允许当前判断？
- 三组是否有留白、疑问或合理反方，而不是集体销售？
- 删除产品名后是否仍有 Nano 高度相关且链接专属的内容？

只改命中组，不通过堆购买词或第二个卖点强行提级。
