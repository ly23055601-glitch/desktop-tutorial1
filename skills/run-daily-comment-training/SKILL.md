# 每日批次计划

输入完整链接/材料集合、品线、数量、已有台账和用户约束。输出task_id、输入ID与别名、分组建议、已有产物版本、未完成项。默认每10个唯一链接一组只是上下文建议，用户数量优先；不能把每组当独立完整任务。

完成计划后返回[总控](../write-consumer-training-comments/SKILL.md)。由总控依序运行S1/S2/S3，全部组最终统一Q。续跑沿用task_id，避免重复登记或重新采集。旧KPI与原项目路径不作为便携包的启动条件；只有用户明确要求并提供台账时才更新统计，写稿数量与验收数量分开。
