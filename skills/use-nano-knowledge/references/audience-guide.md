# Nano 人群、动机与心理表达参考

本参考把人群讨论整理为可复用的观察方法，供产品理解、角色心理分析和评论培训调用。当前没有真实用户访谈、样本统计或消费行为研究支持这些画像；所有心理种子都是 `editorial_hypothesis`，状态为 `pending_user_calibration`。它们不证明人群占比、购买倾向或 Nano 已经满足某种需要。

## 从需要与具体事件识别角色

先理解本次问题、帖子或训练命题，再选少量相关种子；不按一张名单把每种人都写一遍。角色可以重叠，同一角色可以有多种甚至矛盾的动机。职业、年龄、性别和家庭身份不能直接决定兴趣、经济能力或表达口吻。

以下是按问题选择的观察方向，不是每次必须填齐的表格。已有材料能支持一个关注点，就围绕那个点继续；没有材料的心理只能提出为可能性。真实原帖的作者心理不能由假想人物设定补全。

| 观察方向 | 具体看什么 | 对表达的帮助 |
|---|---|---|
| 拍给谁看 | 自己、伴侣、家人、朋友、同好，或公开观众；也可能尚未想好 | 区分私人回忆、解释过程、交流话题和公开表达，不把拍摄都写成发作品 |
| 最近一次具体事件 | 当时正在做什么、为什么想拍、有没有开始、在哪里放弃 | 找到一个值得说的动作或机会，避免只写身份标签 |
| 想留下什么 | 一个小习惯、声音、过程、关系、某次进步、眼前所见 | 同一场景可以选择不同对象，不统一归结为“记录美好” |
| 顾虑与取舍 | 分心、设置、携带、机位、成像、素材积压、闲置等 | 顾虑有材料才展开，不为可信度强塞缺点，也不要求最终解决 |
| 使用前／中／后 | 出门是否想带；现场怎样安放、启停；拍后怎样导出、整理 | 分清兴趣、尝试和形成习惯，不能由想购买直接推定长期使用 |
| 回看与分享行为 | 是否真的翻看、给谁发、保存多久、哪些片段会删 | 区分拍摄动机与实际价值；没有这些信息时不虚构研究结论 |

心理表达可停在偏爱、犹豫、具体问题、普通感受或一次反应。每句话抓住人物此刻最想说的部分，不要求包含“背景—痛点—功能—效果—购买”的销售故事，也不让每个角色承担固定的提问、解答或收尾任务。

## 保留人群广度，按命题继续扩展

这份范围表记录此前讨论过的方向，不是已验证的用户分层。十条[心理假设种子](audience-hypotheses.jsonl)便于起步；本表中没有对应种子的方向可以按当前命题新建，不能硬塞进相近身份。

| 生活或拍摄方向 | 可以继续了解的差异 |
|---|---|
| 旅行、生活随手记录、徒步与骑行 | 希望参与当下、记录路线、分享过程或保留风景；活动强度和固定方式分别核验 |
| 亲子、宠物互动 | 在意小动作、声音、及时回应、共同活动或回忆；默认分析成人持有／佩戴相机，不推导儿童或宠物佩戴适用性 |
| 做饭、手作、DIY、工作过程 | 想讲清步骤、展示劳动、复盘操作，也可能只为保存过程；机位遮挡与近距离成像另核 |
| 钓鱼等等待某个瞬间的活动 | 关注有没有机会留下动作、是否值得持续准备；预录制不是一定捕捉，也不是关机常驻缓存 |
| 内容创作、已有设备、补充机位 | 关注视角、后期衔接、携带频率或用途重复；不默认专业人士必然需要、也不保证跨设备成片一致 |
| 情侣、夫妻、朋友结伴 | 可能想共同参与、互相留念或分享日常；关系身份不等于必须浪漫、热闹或购买送礼 |
| 技能学习、教学、校园社团与活动 | 想看见进步、说明操作、保存幕后或共同经历；回看是否有效需看机位和实际使用 |
| 异地分享、生活回忆整理 | 关注具体接收者、普通生活细节、整理与多年后回看；分享对象不一定公开，未必追求流量 |
| 不爱出镜、嫌拍摄麻烦 | 关注表达自在、减少准备、携带与开拍习惯；不把偏好诊断为性格问题，也不承诺拿到设备就会坚持 |
| 外观、新玩法、尝试设备本身 | 兴趣可以来自外形和探索，尚未形成用途也成立；不强行补上合理购买理由 |

## 产品相关性与心理证据分开

每条种子的 `related_fact_ids` 只是下一步可以查询的产品知识指针。它们**只表示功能与问题可能相关，不证明需求真实存在，更不证明功能能解决该顾虑或带来所述心理效果**。心理种子的 `origin` 指向原训练角色，不能代替官方产品来源。

从[事实条目](../../../../knowledge/nano/products/facts.jsonl)读取命中的完整记录，保留组件、条件、不可推论、状态、来源和核验日期；产品断言进入正文前核对当前官方资料。`pending` 不作肯定能力依据。Nano 使用准确的 Osmo 名称，不借用 Pocket 的机械云台、跟随能力或专属禁词。

例如，关注亲子或宠物的近距离画面时，`NANO-IMG-003` 用于查询成像距离边界，不能证明能拍清任意靠近的动作；关注骑行时，应读取 `NANO-ACC-001`、`NANO-ACC-002` 和 `NANO-MAN-002` 的配件及固定条件，不能从“想分享路线”直接推导某种挂法可靠。讲解这里的关注方向无需重复产品参数；实际回答功能问题才展开对应事实。

## 句子级讲解与完整评论批次

- **人群或心理分析**：按请求解释可能的动机、顾虑和差异，明确这是待验证假设；无需为了讲解给每个身份配完整故事。
- **句子级心理表达教学**：交付顶部标明“培训用假想消费者草稿”，人物设定单独保存，表达示例和心理解释按本次请求组织。此类讲解不是完整主评楼中楼批次，不宣称通过批次检查，也不自动补足主评与回复数量。
- **主评、楼中楼、批量写作或改写**：从[项目写手入口](../../write-consumer-training-comments/SKILL.md)继续进入共享写作能力，使用当前训练状态模板与 `check_training_comments.py`。数量、格式、互动、人物分离和去重沿用共享库，不在此另建评论规则。进入本参考前已经读过的入口不循环加载。
- **真实反馈研究**：保留实际原话、出处、采集日期与对应行为；未知的部分继续未知，不把训练假设回填成真实反馈。新社媒链接仍由统一读取技能一次接收完整链接集合。

## 原始示例与后续校准

既有十个角色见[原人物设定](../../../../outputs/nano/2026-09-06-audience-psychology/personas.json)，例句见[原句子级示范](../../../../outputs/nano/2026-09-06-audience-psychology/expressions.json)，说明见[原分析](../../../../outputs/nano/2026-09-06-audience-psychology/analysis.md)。这些记录是 `training_fiction`，尚待用户校准，不是用户认可案例、真实平台评论或研究样本。本参考只引用这组原件，不复制另一套范文；学习时提取关注点与省略方式，不能整句套用或只换身份、地点和产品名。

新增心理假设继续使用 `NANO-AUDH-` 编号，并记录来源性质。假想人物具体经历保存在当次训练材料，不写入产品事实或心理种子。用户明确认可某句话，也不意味着已经验证对应心理在真实人群中普遍存在；只在获授权的维护中记录明确反馈的适用范围。结构检查通过、助手自评或完成封装均不改变 `pending_user_calibration`。
