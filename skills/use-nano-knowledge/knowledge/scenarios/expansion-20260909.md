# Nano 场景深化：从具体生活细节找到卖点价值

编辑日期：2026-09-09。本轮新增20张细场景（061–080），细场景总数80；18组卖点各新增一条具体选材判断，保留原54个兴趣。新增场景、动机与观看价值均为编辑推演，待用户校准，不是消费者研究、实拍记录或成品评论。

这份短入口用于选题；完整卡片保留动作、接收者、动机、顾虑、拍摄安排、关联事实、条件、观看价值与不同兴趣分支。产品断言实际使用前仍按卡片回到当前官方来源。原60张卡和16件公开体验材料保留原性质。

## 卖点怎样更细地解释

18组卖点都新增了“当前情境—为什么值得在意—何时价值下降—需要观察什么”。这是一种选材判断，四项无需同时进入文案。完整内容见[卖点阅读版](../selling-points/guide.md)。

| 能力方向 | 更具体的使用价值（编辑解释） | 价值可能变小的情况 |
|---|---|---|
| 轻量与佩戴 | 记录者仍能接东西、做操作；也可能只是愿意多带一个机位 | 配件或穿着让设置变麻烦；本人根本不愿整理素材 |
| 第一视角 | 交代自己的手怎样参与互动，让过程中的回应有机会被留下 | 最想看的其实是自己的正脸、全身或所有人同框 |
| 分体屏幕 | 刚开始就知道花束、双手或桌面有没有拍到 | 真正需要的是自动跟随，或组合不支持所需阶段的监看 |
| 快捷与自动控制 | 短片段的入口，或提前安排一部分触发节奏 | 关键问题是没构好图、需要换模式或不能漏拍 |
| 预录制 | 提前等待时，给稍晚按键留出此前片段的可能 | 根本未开启缓存、目标出框或事件超出保留范围 |
| 慢动作 | 让一次短动作可以按不同节奏回看 | 需要的是原本音画语境，或不能安排适合的固定机位 |
| 画幅与广角 | 为脸、手、作品和周围环境分配画面空间 | 关键内容被裁掉，或真正需要远处细节、微距 |
| 色彩 | 直接欣赏喜欢的效果，或按自己的后期意愿选择路径 | 不愿调色却被强行引向流程；未知处理被归因于机内模式 |
| 收音 | 想听的人与相机位置可以分别安排；必要时保留另一份声音材料 | 不需要额外音轨，或其管理与监看取舍不符合当前任务 |
| 续航 | 够不够用的单位可以是上午、休息、下午这几个实际拍摄时段 | 必须长段连续拍，或没有符合条件的补电安排 |
| 内置存储与导出 | 开拍准备与拍后交给谁看是两件事；可按实际用途安排 | 机身已满、接收设备不适配，或没有人愿意挑片 |
| 防水与照片 | 某段涉水画面或一张定格可以独立有价值 | 维护不方便、环境不符合边界，或这次根本不需要该形式 |

产品事实的边界来自[大疆技术参数](https://www.dji.com/cn/nano/specs)、[FAQ](https://www.dji.com/cn/nano/faq)与[中文手册](https://terra-1-g.djicdn.com/6189933d30024fc1b331bffe4fe41837/osmo-nano/UM/20260626/Osmo_Nano_User_Manual_zh-cn.pdf)。本表的用途价值不来自官方对消费者心理的研究，也不代表Nano独占这些能力。

## 怎样给培训留下不同的表达空间

**同一段孩子递作品的画面，可以有不同兴趣。** 有人喜欢孩子递过来之后等待回应的表情；有人想留下自己接住作品的那只手；有人只喜欢当前画面的颜色；有人好奇低头会不会挡住镜头。四种关注各自成立，不必都包装成购买故事。

**同一段手冲咖啡，可以从视觉、声音或习惯进入。** 喜欢水流与杯子的关系，需要有可看的画面；喜欢注水声，需要真的听过；想给朋友讲一个步骤，才考虑人声位置；嫌整理音轨麻烦，也是一种可能的训练人物取舍。不要把这些兴趣统一归结为某类人都会喜欢。

**同一位已有手机的使用者，也不只有替代手机的需求。** 手机正在播放教程、显示清单或承担另一件事时，多一台记录设备可能有用途；手机闲着、固定机位已满足时，额外设备也可能没有多少价值。这种分工是情境解释，不是独家产品能力。

**成长与亲密关系不必靠大事件。** 同一只不配套的杯子、对旧物记忆不一致、轮流拍摄后发现对方注意到不同细节，都可以成为选材方向。没有实际材料时，只作为合成训练命题；不回填成原帖作者经历。

新增卡中的 `observable_details` 是后续可寻找的细节，不表示已经看见或听见；`interest_branches` 是可分别选择的兴趣，不是规定的角色台词。实际评论继续由[项目写手入口](../../../.agents/skills/write-consumer-training-comments/MODULE.md)使用当前共享标准完成，保持 `training_fiction`。
