# Nano 场景解释

以下7张卡均为 **编辑假设（editorial_hypothesis）**，用于理解培训命题中的可能需求。产品连接有官方依据；需求和使用结果没有真实用户反馈支持。卡片不分配角色经历，也不是可直接粘贴的评论模板。

结构化数据见 [cards.jsonl](cards.jsonl)。

<a id="nano-scene-001"></a>

## NANO-SCENE-001｜日常随手记录

**拍摄任务：** 在日常活动中较快开始记录一个片段。

**可能关注：** 是否来得及开始？ 是否需要腾出手？ 靠得太近是否清楚？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-FORM-002](../products/guide.md#nano-form-002) | 了解随身携带的主相机重量边界 |
| [NANO-MAN-007](../products/guide.md#nano-man-007) | 理解关机短按开始记录的实际操作 |
| [NANO-MAN-011](../products/guide.md#nano-man-011) | 理解预先设置的自动录像触发 |
| [NANO-CTL-001](../products/guide.md#nano-ctl-001) | 理解预录制保留按键前片段 |
| [NANO-IMG-003](../products/guide.md#nano-img-003) | 近距离记录前检查被摄体距离 |

**使用前提：** 先选择合适固定方式；自动录像与预录制各自设置，不假定互通；预录制不等于关机常驻缓存。

**不能外推：** 不能把快速开拍说成必定捕捉每个瞬间；不写成任何位置挂上都稳、无需设置。

**待核问题：** 没有新增产品待核项；人物与结果仍为训练设想。

<a id="nano-scene-002"></a>

## NANO-SCENE-002｜旅行步行

**拍摄任务：** 边走边记录沿途所见，必要时查看构图。

**可能关注：** 怎样佩戴？ 画面倾斜如何处理？ 短时查看与原片质量是否一样？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-MAN-001](../products/guide.md#nano-man-001) | 帽夹提供一种官方示例安装位置 |
| [NANO-MAN-002](../products/guide.md#nano-man-002) | 理解挂绳衣物厚度及运动限制 |
| [NANO-STAB-001](../products/guide.md#nano-stab-001) | 区分电子增稳与机械云台 |
| [NANO-STAB-002](../products/guide.md#nano-stab-002) | 理解HB范围和规格条件 |
| [NANO-FORM-005](../products/guide.md#nano-form-005) | 分体监看受到距离和干扰影响 |
| [NANO-FORM-006](../products/guide.md#nano-form-006) | 低清回放不代表原片画质 |

**使用前提：** 佩戴前确认卡扣与磁吸板状态；不将普通步行设想外推剧烈运动；无线麦克风同时使用时另读NANO-AUD-007。

**不能外推：** 不能承诺旅途全程无人看管也不会掉落；场景假设不证明原帖使用了某个增稳模式。

**待核问题：** NANO-GAP-003、NANO-GAP-005

## NANO-SCENE-003｜骑行记录

**拍摄任务：** 在确认固定方案后记录骑行第一视角片段。

**可能关注：** 胸带需配什么转接件？ 是否能用磁吸挂绳替代？ 录制内容会不会被循环覆盖？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-ACC-001](../products/guide.md#nano-acc-001) | 核对骑行胸带兼容所需的转接条件 |
| [NANO-ACC-002](../products/guide.md#nano-acc-002) | 注意类似名称转接件的脚注差异 |
| [NANO-MAN-002](../products/guide.md#nano-man-002) | 磁吸挂绳不用于剧烈运动 |
| [NANO-MAN-003](../products/guide.md#nano-man-003) | 短时静态球头不能借作行驶中固定依据 |
| [NANO-CTL-002](../products/guide.md#nano-ctl-002) | 理解循环录像覆盖最早片段 |
| [NANO-STAB-003](../products/guide.md#nano-stab-003) | 慢动作不能沿用普通视频的电子增稳 |

**使用前提：** 先核对胸带和转接件具体SKU，装配锁紧后再使用；启停与参数安排在安全停靠时操作；这条是场景操作建议，不是产品性能结论。

**不能外推：** 配件表的兼容标记不证明任何车速、路面或碰撞都安全；不承诺夜间颠簸画面零拖影。

**待核问题：** NANO-GAP-003、NANO-GAP-005

## NANO-SCENE-004｜亲子互动

**拍摄任务：** 由成人记录互动过程，关注操作和声音。

**可能关注：** 是否想腾出手参与？ 人物靠近镜头会怎样？ 无线收音时还能否查看画面？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-MAN-011](../products/guide.md#nano-man-011) | 预设自动录像可减少部分主动按键动作 |
| [NANO-IMG-003](../products/guide.md#nano-img-003) | 人物近距离接近时有成像距离边界 |
| [NANO-IMG-014](../products/guide.md#nano-img-014) | 日常广角是可选择视角而非人像结果保证 |
| [NANO-AUD-007](../products/guide.md#nano-aud-007) | 了解无线麦加分体录像时无画面显示 |

**使用前提：** 此卡默认成人持有或佩戴并检查安装；不从产品定位推导儿童佩戴适用性；当前帖若没有音轨或设备证据，不能宣称其用了无线麦。

**不能外推：** 没有验证自动人物追焦或机械跟随；不把编辑设想当作父母群体反馈或孩子实际表现。

**待核问题：** NANO-GAP-003、NANO-GAP-004

<a id="nano-scene-005"></a>

## NANO-SCENE-005｜宠物互动

**拍摄任务：** 由人持有或佩戴相机记录与宠物的互动。

**可能关注：** 宠物突然靠近能否清楚？ 如何选择机位？ 想慢放时需牺牲什么？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-IMG-003](../products/guide.md#nano-img-003) | 近距离成像不是自动追焦 |
| [NANO-MAN-003](../products/guide.md#nano-man-003) | 静态机位可先核对球头适用表面与时长 |
| [NANO-IMG-005](../products/guide.md#nano-img-005) | 4K慢动作与增稳限制一起考虑 |
| [NANO-CTL-001](../products/guide.md#nano-ctl-001) | 按需求理解预录制机制 |

**使用前提：** 首版未核验宠物身体佩戴方案；此卡不建议直接固定到宠物身上；地面低机位须保持固定，不让配件受撞击。

**不能外推：** 不能外推宠物识别、宠物自动跟随或始终对焦清楚；不可编造真实宠物使用反馈入库。

**待核问题：** NANO-GAP-003、NANO-GAP-005

## NANO-SCENE-006｜室内记录

**拍摄任务：** 记录室内活动，并考虑光照、动作、声音与后期。

**可能关注：** 光线较暗时怎样理解模式？ 广角人物边缘是否变形？ 是否愿意后期调色？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-IMG-001](../products/guide.md#nano-img-001) | 传感器规格提供硬件背景 |
| [NANO-IMG-015](../products/guide.md#nano-img-015) | 知道超级夜景功能的存在及待核规格 |
| [NANO-IMG-016](../products/guide.md#nano-img-016) | 了解拖影改善选项的有限承诺 |
| [NANO-IMG-008](../products/guide.md#nano-img-008) | D-Log M属于后期工作流 |
| [NANO-IMG-009](../products/guide.md#nano-img-009) | 使用对应Nano素材的LUT |
| [NANO-AUD-008](../products/guide.md#nano-aud-008) | 手持时避免遮挡机身麦克风 |

**使用前提：** 这些是可分别调查的选项，不认定能在同一模式同时开启；先确认实际光照和运动，具体设置以当前设备界面为准。

**不能外推：** 不能只凭传感器尺寸保证室内动态画面清晰；不能把主观喜欢某种画面写成普遍画质优势。

**待核问题：** NANO-GAP-003、NANO-GAP-006

## NANO-SCENE-007｜素材导出

**拍摄任务：** 将机身中的素材导出、备份并进入剪辑。

**可能关注：** 是导出到卡、手机还是电脑？ 导出时能否继续拍摄？ 手机与线材是否兼容？

| 产品依据 | 对当前任务的意义 |
|---|---|
| [NANO-STO-002](../products/guide.md#nano-sto-002) | 先分清录像位置与卡的用途 |
| [NANO-STO-003](../products/guide.md#nano-sto-003) | 通过模块导出至卡 |
| [NANO-STO-004](../products/guide.md#nano-sto-004) | 经图传模块向电脑导出且此时不能拍摄 |
| [NANO-STO-005](../products/guide.md#nano-sto-005) | USB-C手机有线传输有固件和设备条件 |
| [NANO-STO-006](../products/guide.md#nano-sto-006) | 通过Mimo导出到手机 |
| [NANO-IMG-011](../products/guide.md#nano-img-011) | HEVC播放编辑有环境要求 |

**使用前提：** 导出到卡、电脑或通过数据线到手机时，按要求让镜头朝前安装到图传模块；Mimo无线导出按其连接流程；删除机身原片或格式化之前，先检查导出文件完整、可播放并完成备份。

**不能外推：** 不能将存储卡导出说成插卡直录；不能承诺任何手机或线材都有相同速度和兼容性。

**待核问题：** NANO-GAP-006
