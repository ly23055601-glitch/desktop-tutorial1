# 从 Nano 卖点反查使用场景

由卖点和场景的现有引用生成。先按当前材料找一个有用的兴趣，再读对应卡片的条件；关联数量不是推荐强度，场景仍是编辑假设。

也可从[培训选材专题](../TRAINING.md)按生活片段进入。每个卖点下的三种兴趣可分别使用，不需写进同一条评论。
