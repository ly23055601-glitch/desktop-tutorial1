## 从当前材料中已经能分开的关注

**佩戴时的感受，与回看画面的感受分开。** [户外摄影](cases.md#nano-exp-004)作者在意拍摄主任务时少分心；本轮长片还补出了回去剪辑时如何组合第一/第三人称、以及愿意尝试低机位的解释。这些是作者的使用与剪辑价值判断，未取得观众回看留言。[眼镜与腕上屏幕](cases.md#nano-exp-001)材料有先压脸、调整后压力感降低的字幕自述；[评论中的外观玩笑](discussions.md)则是另一种反应，不能拿外观评价代替压力或长期舒适度证据。

**拍到了，与喜欢拍出的结果分开。** [亲子互动](cases.md#nano-exp-002)作者说这次留下了手机难拍到的状态；[手冲咖啡](cases.md#nano-exp-005)作者却觉得结果不如手机。两者都是具体作品中的反应，不用统一改成正面体验，也不能由此判定设备优劣。

**经常用，与舍不得放弃分开。** [低频持有](cases.md#nano-exp-007)保留了使用少却不想卖的矛盾态度；[多设备偏好](cases.md#nano-exp-012)记录的是出门时愿意选择谁。少用原因和携带选择要等本人说明，不凭身份补出动机。

**第一视角的吸引力可以不同。** 在[厨房教学](cases.md#nano-exp-006)中，相关问题是手上步骤能否让观看者理解；在[迎新准备](cases.md#nano-exp-009)中，是留下正式活动之前的现场；在[摄影幕后](cases.md#nano-exp-004)中，是补回拍摄者本人的过程。这些是对当前作品的编辑理解，并不证明观看者一定有参与感或不会晕。
