# 本轮来源补充与纠正

日期：2026-09-08。历史导出和已交付批次保留原记录；本页追加本轮实际复核结果，不倒改当时阅读范围或核验日期。

## 咖啡片开头文字

[EXP005](cases.md#nano-exp-005)旧证据记录把开头装饰字记为“Good time”。本轮打开原分辨率开头帧，实际为 **Food time**，见[复核图片](../../../outputs/nano/2026-09-08-experience-materials/media-review/019/opening.jpg)及[媒体审阅记录](../../../outputs/nano/2026-09-08-experience-materials/media-review.json)。

这项纠正只涉及可见装饰字，不改变作者对拍摄结果不满意并求助的语境；旧证据中的其他未核设置和音轨仍不因此得到确认。

## 眼镜佩戴片的前后条件

[EXP001](cases.md#nano-exp-001)的早期摘要漏掉了佩戴感受。本轮实际审阅104–137秒共66个2fps样本，主任务另直接查看相关联系图。作者的叙述顺序是：

- 约105–111秒展示相机与眼镜之间的短防丢绳。
- 约112.5–114.5秒承认眼镜戴好后存在压脸感。
- 约115–120秒介绍收紧眼镜后固定绳，用来分散鼻托压力；画面并未显示脑后拉紧的完整动作。
- 约122–127秒接着介绍仍觉得压脸时的口罩承托安排，并示意鼻托与口罩接触的位置。
- 约127.5–129秒出现案例中保留的低压力感字幕；它承接的是前一项安排。
- 约129.5–132.5秒作者评价该组合的第一视角较自然；这仍是公开评测中的个人评价，未有独立对照或实际回看过程。

可回查[前提与固定绳段](../../../outputs/nano/2026-09-08-experience-materials/wear-context/sheet-2.jpg)、[口罩与结果段](../../../outputs/nano/2026-09-08-experience-materials/wear-context/sheet-3.jpg)、[后续评价段](../../../outputs/nano/2026-09-08-experience-materials/wear-context/sheet-4.jpg)。时标为抽帧近似时间，不是逐字音频转写。

这里补充的是作者实际说了什么、展示了什么，不提供佩戴安全或承载建议；两种绳的用途、具体配件型号、全部连接动作、舒适度测量和耐久结果不能混为已核事实。

## 户外长评测的机位与画面归属

[EXP004](cases.md#nano-exp-004)的旧抽帧只留下帽檐小设备和胸前器材。本轮[长片补读](../../../outputs/nano/2026-09-08-experience-materials/long-review/review.md)确认约18秒字幕指认Nano帽檐设备，约500秒有Nano接帽檐夹座的近景；约177–181秒胸前画面则属于作者在讲的Action 6。约200–203秒近距离按向夹座的动作，所在身体/物体位置仍无法确认，不能与片尾拼成完整安装过程。

解说对象也不总等于该镜头的拍摄设备：约118–119秒字幕讲Nano但水印标Pocket；约247–248秒讲Nano用途但水印标Action，之后才切到标Nano的视角。记录保留作者的水印归属，不把全片影像质量并入Nano。剪辑后的故事用途是作者解释，未取得独立观众评价或当场回放反应；全部补读仍限字幕与静帧，音轨未听。
