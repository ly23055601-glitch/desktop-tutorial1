# DJI Mic 平衡种草规则

本参考用于把产品关联写得更强，同时守住真人感与声音证据边界。种草不是多写产品名，而是让读者自然理解：如果经常遇到这个录音场景，这个产品点能改变什么。

内部链路为：

`内容锚点 → DJI Mic 促成或关联的录音结果 → 用户可感收益 → 条件式选择`

不要让一条主评论写完四层。主评最多承载相邻两层，楼中楼可以再补一层或留下真实限制。

## 证据等级与表达上限

| 证据级 | 当前链接能确认什么 | 单组上限 | 可写范围 |
| --- | --- | --- | --- |
| A | 明确功能演示、受控同场景对比、可辨设置和原始/近原始音频，或可核验测试结果 | S3 | 可有限说明产品结果、收益与条件式选择 |
| B | 型号、佩戴/连接/录制动作和平台成片可确认，但声音因果或后期链路不完整 | S2 | 可谈可见操作收益和“这条里”的听感，不外推普遍音质 |
| C | 只有包装、机身、套装或简单开箱 | S1 | 只谈体积、收纳、佩戴位置、套装识别、连接门槛和购前问题 |
| U | 原帖、媒体和用户补充都不足 | 不生成 | 说明缺失证据，不用通用稿冒充已读 |

平台压缩、BGM、混响、调色式音频处理、后期降噪或响度调整会改变听感。A 级也只支持与其测试条件一致的有限结论，不自动代表所有环境、距离、设备和模式。

## S0–S3 只用于内部复核

- `S0｜看见`：只有情绪、外观或产品露出，没有功能收益。可留一组作为自然呼吸。
- `S1｜理解`：指出一个功能、连接方式、套装差异或真实购前问题。
- `S2｜获益`：把有证据的产品机制翻成具体收益，例如少重录、少补救、少一步连接、多人素材更好分、愿意随身带。
- `S3｜决策`：形成可信的未来场景投射、化解一个购买阻力，或给出带条件的型号/套装倾向。

等级不是越高越好。三组不能都像销售人员推进成交；至少允许一组停在情绪、问题或合理反方。

## Mic 产品点如何翻译成人话

只有证据支持时才使用下列方向：

| 可见或核验的产品点 | 可感收益方向 | 不能越过的边界 |
| --- | --- | --- |
| 小体积、背夹、磁吸、可换外观 | 领口存在感、穿搭协调、收纳意愿、是否愿意随身带 | 只看画面不能断言全天舒适、不坠领或适合所有面料 |
| 手机/相机/电脑接收端或 OsmoAudio 直连 | 少一个连接步骤、手机拍摄更快进入录制 | 必须核对具体型号、接口、模式和兼容列表 |
| 防风毛套、降噪、低切 | 在特定风声或环境噪声下减少干扰 | 不写“完全无风噪”“只剩人声”，不跨场景比较 |
| 自动限幅、安全音轨、内录、32-bit 浮点 | 突然变大声时多一层补救、降低不可重录素材的风险 | 不保证所有削波可恢复；区分发射器内录与接收端输出 |
| 多发射器、独立声道或多声道 | 多人录音更容易分开处理、少挤在一条轨里 | 核对套装、接收器、相机/电脑、转接件和模式条件 |
| 增益、音色预设、强弱降噪 | 更快接近当前人声和环境需要的设置 | 不把预设写成专业混音替代品，不假装作者使用了某档 |
| 充电盒、单发/双发套装、续航 | 出门少漏配件、单人或双人需求更容易选套装 | 价格、续航和清单必须当日核验并保留测试条件 |
| 无线传输和抗干扰 | 允许人物与相机保持一定距离 | 传输上限不等于复杂环境稳定距离；必须写测试条件 |

## 三组可以承担的任务

从内容自然选择，不固定顺序：

- 需求唤醒：让人意识到现有手机直录、距离、环境或多人收音的缺口。
- 结果想象：把链接中的录音结果投射到一个可信场景，但用“如果”“经常”表达，不伪装亲历。
- 产品归因：只解释一个有证据的 Mic 点为何与结果有关。
- 阻力化解：回应佩戴、收纳、连接、套装、后期或使用频率中的一个真实顾虑。
- 选择缩窄：按单人/多人、手机/相机、是否需要内录、是否常在户外等条件给克制倾向。
- 升级判断：旧款与新款都先核对型号和新增能力；没有代际证据时只留下会影响升级的问题。
- 合理反方：指出测试限制或替代方案，允许得出“不一定需要升级”的结论。

同一组只承担一个主要任务、讨论一个产品点。三组不按固定“共鸣—疑问—购买”槽位轮播。

## 主评与楼中楼分工

- 主评优先写锚点加反应、锚点加疑问，或一个明确收益；不要一口气交代场景、功能、参数和购买结论。
- 回复可以补原因、条件或不同意见，但默认两条就停。第三、第四条不是用来完成种草链路的固定位置。
- 有收益时先让收益成立，再补一个真实边界。不要三组都以“看不出、没写、不一定”结束。
- 每链接最多一组克制表达购买倾向，例如“经常录双人的话会多看一眼”。不使用强推、羞耻、攀比、恐惧或虚假稀缺。

## 心理机制的安全使用

心理机制只用于发现真实关注点：

- 自我投射：用条件句写未来场景，不自报职业、家庭或生活经历。
- 不确定性消除：问一个真正影响选择的问题，不安排回复假装官方解答。
- 损失规避：只谈漏录、补录或素材不可重来的实际风险，不夸大焦虑。
- 认知省力：讨论少一步设置、连接或后期，不宣称零学习成本。
- 对比决策：按场景和条件比较，不制造阵营、群体压力或虚假口碑。

策划标签不得出现在纯净评论中。禁止“作为老师”“学生党”“探店党”“老用户路过”等虚构身份开场。

## 语义验收

逐链接回答：

1. 每组能否定位到一个真实锚点？
2. 产品结果是链接证据支持，还是只由参数表推演？
3. 产品点是否被翻译成具体收益，而非换一种方式念卖点？
4. C 级开箱是否越级谈音质、降噪或传输表现？
5. 三组是否有不同的关注任务，并允许一组不种草？
6. 楼中楼是否自然停住，没有“问型号—报型号—下单”的排演？
7. 是否没有虚构购买、持有、职业、关系、使用时长或第三方背书？
