# Mic 人群需求与使用心理指南

本资料整理本任务此前的人群与心理讨论，属于**编辑需求推演，不是消费者调查**。没有真实访谈样本、购买者分布、年龄性别结论或市场规模证据。同一角色可能有不同动机，同一个人在选购、初次使用、熟悉使用与升级阶段也可能改变关注点。每张卡提供待验证方向和反例，不能仅凭身份断定真实人物心理。

这里的 16 张卡按工作或生活任务组织；新手、独自拍摄、设备共用等作为交叉标签叠加，不重复计算为 10 个独立市场群。不要强行把每种心理接到广告卖点、升级理由或购买结论。实际评论、改写及案例演示仍进入共享技能 `$write-consumer-comments`，按当前原帖或明确标注的训练命题选材；本资料只提供关注方向。

## 资料边界与取用方法

| 层次 | 本库位置 | 能说明什么 | 不能当作什么 |
|---|---|---|---|
| 产品事实与连接条件 | [知识库索引](../INDEX.md) | 按型号、部件、路径及条件核验的产品内容 | 用户确实这样使用或效果必然如此 |
| 场景整理 | [场景卡](../scenarios/cards.jsonl) | 从需求进入相关事实的检索线索 | 对所有职业、软件和设备组合的适用保证 |
| 角色心理假设 | [人群卡](cards.jsonl) | 可能的触发时刻、动机、取舍与观察方向 | 调研结论、真实用户反馈、产品事实 |
| 历史教学片段 | 本指南的 12 条片段 | 上文讨论过的假想表达，供后续校准 | 认可范文、可直接套用的模板、已发布评论 |

先找到当前人物要完成的任务，再选择确实相关的阶段或工作方式标签。只取有助于理解当前问题的一两项动机，并检查卡内反例；不要求把触发、痛点、功能、效果和结论拼成完整故事。若涉及具体产品断言，再沿 `scenario_ids` 回查当前官方事实、限制和待核项。场景引用只是检索入口，尤其线上会议、影视制作等扩展任务还需要另核实际设备、软件和流程。

心理分析可以用“可能在意”“有待观察”说明推演性质。真实人物的心理须有原材料支持；培训人物的经历可以假想，但保存在具体写作任务中，不追加到本文件的产品事实或当成已采集用户资料。

十个交叉标签已在卡中使用。它们表示**可供分析的情境**，不表示该职业的所有人都具有该标签。

|---|---|---|

| 团队共用设备 | 怎样清点、充电、交接设置；下一个人需要哪些信息 | MIC-A011、MIC-A012 |
| 已有无线麦考虑更换 | 现有工作流具体卡在哪里；是否愿意迁移配件与习惯 | MIC-A006、MIC-A007 |

## 从心理进入表达

“想要确定性”可以来自不同事情：创作者想保住第一遍的状态，摄影师关注答应交付的内容，家庭记录者想保存一句有个人意义的话。不要让三种人物都只重复“很安心”，也不能预设每个人都害怕损失。有人享受研究设置，有人更愿意沿用熟悉流程，有人暂时根本不想增加设备。

同一个人随阶段变化时，可以沿以下方向理解，不必补足完整成长故事：

| 阶段 | 当前可能需要解决的事情 | 可观察线索 |
|---|---|---|
| 选购 | 现有问题是否值得增加设备；整套流程怎样使用 | 描述已有拍法、实际不便和愿意付出的准备成本 |
| 初次使用 | 确认自己是否操作正确 | 试录、回听、询问输入或连接步骤 |
| 熟悉使用 | 形成自己愿意重复的习惯 | 出门实际选哪套组合、哪些设置很少再改 |
| 考虑升级 | 新任务是否超出现有工作流 | 人数、设备、交付对象或制作方式发生了什么变化 |

以下 **12 条是本任务此前已出现的历史教学片段**，保留原措辞以便后续复核。统一性质为：**培训用假想消费者草稿（教学片段，待校准）**。`review_status=pending_user_calibration`，没有用户逐条认可；它们不构成新一批评论交付，也没有执行写作批次验收。片段中的第一人称、关系、行为和主观感受均是假想，不能解释为用户本人或真实消费者经历。

| # | 角色或叠加标签 | 历史片段 | 取用时检查什么 |
|---|---|---|---|
| 1 | 初次创作／MIC-A001＋新手 | “第一次把麦夹上，还真有点要认真开拍的感觉” | 是当前材料能接住的参与感，还是仅靠身份安排台词 |
| 2 | 独自拍口播／MIC-A001 | “有时候第一遍说得最顺，停下来调完设备，反而忘了刚才怎么讲的” | 这一具体状态是否适合命题；不要扩写成固定的故障到满意故事 |
| 3 | 采访者／MIC-A005 | “人家刚聊到兴头上，我实在不好意思说等等，这段再讲一次” | 关注交流礼貌；不能由此断言真实受访者正在倾诉或不能补录 |
| 4 | 摄影摄像师／MIC-A007 | “收东西之前，我一定先听一遍关键那段” | 这是角色习惯；使用哪条监听或回听路径需要另核 |
| 5 | 直播讲解者／MIC-A004 | “最怕讲了一大段，才看见下面一直在说听不清” | 不能为表现真实而给每个角色安排焦虑，也不能伪造真实评论区反馈 |
| 6 | 教师、教练／MIC-A003 | “讲动作的时候我根本站不住，总想走过去比划一下” | 从具体示范动作选材；不把职业等同于所有人都走动授课 |
| 7 | 旅行记录者／MIC-A002 | “出去玩已经让朋友帮我拍好多次了，收音最好别再让人跟着折腾” | 是假想人物的同行取舍；不扩成所有旅行用户都嫌麻烦 |
| 8 | 家庭记录者／MIC-A008 | “他叫我的那一声，我想单独留一份” | 情感对象来自训练设定或真实材料；别给原帖虚构家庭关系 |
| 9 | 出镜者／MIC-A001、MIC-A015＋在意出镜形象 | “挑麦我还真会看颜色，毕竟夹在衣服上一直要入镜的” | 审美动机可以单独成立；具体颜色、佩戴和外观仍另查产品资料 |
| 10 | 团队成员／MIC-A011＋团队共用设备 | “麦是拿回来了，跟它一起出去的那根线呢” | 调侃能否独立成立；不要预先安排别人回答并替产品收尾 |
| 11 | 老用户／MIC-A006、MIC-A007＋已有无线麦考虑更换 | “新功能挺多，我先看看手上的配件还有多少能接着用” | “新功能挺多”没有具体事实支撑时须删改或补核，不得作为产品结论 |
| 12 | 轻度用户／MIC-A008、MIC-A016＋偶尔使用 | “隔一阵子才拍一次，每次拿出来都得重新回忆怎么连” | 是人物的使用间隔和记忆感受，不能推导产品普遍难用 |

这些片段展示关注点，不要求后续凑齐同样角色、长度、情绪或数量。真实原帖未表达的画面、设备、音轨和评论不能随训练人物一起虚构。短句、好奇或普通附和都可以成立，不能为每段补推荐、排除顾虑或购买收尾。

## 数据契约与后续校准

[cards.jsonl](cards.jsonl) 每行一张卡，ID 为 `MIC-A001` 至 `MIC-A016`。字段固定如下：

| 字段 | 类型与含义 |
|---|---|
| `id` | 唯一卡号；后续更新保留已有 ID |
| `role`、`trigger` | 非空字符串；任务角色及假设触发时刻 |
| `aliases`、`tags` | 非空字符串数组；检索别名与可叠加情境 |
| `motives`、`tensions` | 非空字符串数组；可能的诉求和取舍，不是心理诊断 |
| `behavior_signals` | 非空字符串数组；未来材料中可以观察的线索，当前均标“待观察” |
| `expression_directions` | 非空字符串数组；选材方向，不是已批准话术 |
| `counterexamples` | 非空字符串数组；防止身份定型、过度归因或机械推荐的反例 |
| `scenario_ids` | 非空字符串数组；引用现有场景卡 ID，作为回查产品资料的入口 |
| `status` | 固定 `editorial_hypothesis` |
| `evidence_status` | 固定 `not_user_research` |
| `origin` | 固定 `assistant_synthesis_from_thread_discussion` |
| `review_status` | 固定 `pending_user_calibration` |

后续若获得真实访谈或平台材料，独立保存原始来源、上下文与采集状态，再判断哪些假设获得支持、被反驳或仍未知；不要因为看到了一个相似例子就把全卡或整个人群升级为已验证。若用户只认可某句写法，只记录该句与认可范围，不能把认可迁移到心理统计或产品结论。结构检查只能证明 JSON、引用和状态约定是否正确，不能证明心理真实、语言自然或用户认可。
