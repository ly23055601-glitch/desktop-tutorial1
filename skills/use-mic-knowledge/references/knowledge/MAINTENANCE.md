# Mic 知识库维护

## 来源优先核对适用条件

默认采用中国大陆中文官方资料；引用其他地区或语言要保留来源标记，不能把海外套装、法规或价格当成大陆情况。优先找到该型号当前手册、参数／FAQ、兼容表和固件说明；不存在一条“永远用某类页面覆盖其他页面”的规则。

下载页列有一份手册，只证明文档入口存在。登记为已读手册前须打开实际 PDF，记录版本、页码和读取范围。保留来源页面日期与实际核验日期，两者不相互替代。官方能力不能由产品介绍图片、搜索摘要或本地旧稿证明。

## 新增或纠正一条知识

1. 阅读实际来源，确认精确型号、部件、地区、版本、模式和测试条件。在 `sources/` 新增或更新来源登记，保留可定位证据。
2. 将可独立使用的结论放入事实或兼容记录。支持与不支持都要有依据；未找到资料用 `pending`／`unconfirmed`，并写明缺什么。
3. 来源冲突时保留至少两处定位。只有明确的版本变化、适用条件差异或新的官方解释才能消解；不要选择更有利于种草的一方。独立成立的较窄事实可另记为已核验。
4. 更新受影响场景和型号索引。场景有未核事实时撤去肯定式答案；检索会把失效证据所依赖的场景列为待核。
5. 运行审计与相关行为测试，再刷新覆盖及来源目录。正文写作引用时另按任务需要复核当前来源。

```bash
python3 references/knowledge/scripts/mic_knowledge.py audit --format json
python3 -m unittest discover -s references/knowledge/tests -v
python3 references/knowledge/scripts/build_reports.py
```

需要同时重写机器验收记录时，运行 `python3 references/knowledge/scripts/validate.py`，它会运行相同测试并保存十二个场景查询的实际返回编号。

## 更新触发与历史

新型号、新固件、新连接组合、官方文档修订或用户明确指出事实问题时，更新相关条目；本版不配置定时任务。价格与库存不作为稳定知识保存，后续任务涉及时按地区、日期和具体套装即时核对。

事实修正保留原 ID，在 [CHANGELOG.md](CHANGELOG.md) 说明变更前后的结论及来源；新增不同能力使用新 ID。修改源记录后生成阅读报告，不能只修改报告中的数字。已经读取的历史文档可留作版本证据，不自动以旧版本代替最新条件。

## 维护边界

产品层只含官方知识和基于官方事实的编辑场景。`audience/` 单独保存角色心理编辑假设与待校准教学片段，不属于消费者调研。真实消费者资料后续另行建层；需要读抖音、小红书或 B站时，将该次完整链接集合交给统一社媒读取技能，不在本库脚本里另建采集流程。真实消费者的音频体验不能转成普遍产品性能结论。

文风、回复结构与用户认可案例由共享写手能力库维护；Mic 知识库不复制另一套写作规则，也不把助手自评稿作为用户认可案例。

新增卖点时先登记具体能力事实，再按 [卖点指南](selling_points/guide.md)关联用途价值、角色、条件和限制。`selling_points/reviews_*.jsonl` 记录当次实际读取的来源与范围，不能用一次页面复核给整库更新日期。事实改为待核或冲突后，相关卖点将移出可直接引用结果；更新完整卡时同步阅读指南并重新发布个人快照。

详细场景维护于 `writing_scenarios/*.jsonl`，按实质任务或阶段变化扩展，不只替换职业、人物关系或地点。路线关联同型号卖点，心理和原帖触发线索仍是编辑假设；具体假想人物与成稿不写入该层。修改后运行 `python3 references/knowledge/scripts/build_writing_scenario_guides.py` 生成阅读指南，再运行相关行为测试及重新封装。待核依赖按路线隔离，不把另一型号的可用能力补到该路线。

同一生成命令还更新 `writing_scenarios/selling-point-map.md`，不手动维护第二份关联。`selling_points/value-expansion.md` 深入解释需求、偏好和取舍，沿用底层事实；扩展用途不等于产品能力或消费者证据有更新。


## 使用体验材料

`training/experience-materials.md`为Mic声音和实际过程的观察指南，`materials/`保存轻量便笺、历史候选索引及原话／反馈范围。收到真实作品、原音或讨论时保留原出处、实际读取范围及不确定项；材料已收到、文件存在、已看／听和已核验分别记录。没有评论或原话时不以training_fiction补齐。当前盘点的历史分类与采集日期保留，不因复用变成新采集。

共享四类材料使用个人写手的当前体验指南，产品侧不新增采集或评论规则。原始媒体留原位置，本包只携带说明与来源指针；跨机复核须另外提供原素材，不能把缺文件当已看过。后续私聊或语音材料是否迁移依当次资料使用范围处理，不默认复制全部私人原记录。修改后显式发布快照，重新检查新入口和文件引用，不登记每日新稿KPI。
