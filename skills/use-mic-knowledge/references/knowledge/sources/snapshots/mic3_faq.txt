DJI Mic 3 可以搭配哪些产品使用？
目前可以搭配相机、智能手机（支持 USB-C、Lightning 接口连接或蓝牙直连）、电脑等设备。
DJI Mic 3 支持 DJI OsmoAudio™连接生态，发射器可直连 Osmo 360、Osmo Action 5 Pro、Osmo Action 4 或 Osmo Pocket 3，带来原声级音质，也简化了创作装备与流程。
如需了解更多详情，请前往 DJI Mic 3 官网
下载页面
查看《手机 & 平板兼容列表》和《OsmoAudio™兼容列表》。
DJI Mic 3 不同产品套装有什么区别？我应该怎么选择？
DJI Mic 3（两发一收）包含充电盒、一个接收器和两个发射器，适用于双人收音，满足长续航需求。
DJI Mic 3（一发一收）包含一个接收器和一个发射器，主要针对单人收音场景，更适合单人创作。
DJI Mic 3 发射器可搭配手机、Osmo 360、Osmo Action 5 Pro、Osmo Action 4 或 Osmo Pocket 3 使用。此外，DJI Mic 3 发射器还可与其他 DJI Mic 3 产品套装组合使用，实现多发多收创作。
DJI Mic 3 接收器可与其他 DJI Mic 3 产品套装组合使用，实现多发多收创作；也可单独作为时码器使用。
DJI Mic 3 是否需要激活？
DJI Mic 3 无需激活即可使用。您可以扫描包装箱上的延保二维码，登记可享一年延保服务。
DJI Mic 3 发射器、接收器如何进行固件升级？
1. DJI Mic 3 接收器可通过手机连接头（USB-C 或 Lightning）连接手机或直连 DJI Mimo app，在 DJI Mimo app 内升级接收器固件。将接收器放入充电盒后，还可为发射器和充电盒升级固件。
2. DJI Mic 3 发射器可直连 DJI Mimo app，实现单个发射器的固件升级。
DJI Mic 3 手机连接头（Lightning）需单独购买。
DJI Mic 3 发射器和接收器如何对频？
同一套装内的接收器和发射器在出厂前已完成对频操作，若需要重新对频，可以参考以下方法：
方法一：将接收器与发射器放入充电盒中即可完成对频操作。
方法二：开启发射器和接收器电源，在接收器主界面下滑进入设置页面，左滑选择“设备配对”，选择“添加 TX”，选择需要配对的 TX 位置；长按发射器配对按键，跟随页面指示完成配对，若发射器指示灯处于蓝绿交替快闪状态，表示正在对频；绿灯常亮表示已完成配对。
配对过程中可以选择“取消”以中断配对。
DJI Mic 3 有哪几种声道模式？
DJI Mic 3 可提供单声道、双声道和四声道三种声道模式。
1. 单声道模式：全部发射器收录的音频组合成一个音频输出。
2. 双声道模式：两个发射器收录的音频分别记录至对应的单独通道上输出，两个以上发射器时，TX1 和 TX3 组合成左声道输出，TX2 和 TX4 组合成右声道输出。
3. 四声道模式：四个发射器收录的音频分别记录至对应的单独通道上输出。
四声道模式的兼容信息详见 DJI Mic 3 官网
下载页面
的《DJI Mic 系列热靴兼容列表》及《四声道电脑软件兼容列表》。
DJI Mic 3 充电盒有什么功能？
充电盒可用于发射器与接收器配对，还可以收纳发射器、接收器、手机连接头（USB-C 或 Lightning）、带锁音频转接线、防风毛套、磁铁、磁吸背夹，充电盒在满电状态下可为一个接收器和两个发射器提供约 2.4 次完整充电。
Lightning 连接头需单独购买。
DJI Mic 3 的 USB-C 和 Lightning 转接头是否和 DJI Mic、DJI Mic 2、DJI Mic Mini、DJI Pocket 2 的转接头通用？
不通用。
DJI Mic 3 发射器和接收器是否兼容 DJI Mic、DJI Mic 2、DJI Mic Mini 发射器和接收器？
不兼容。
DJI Mic 3 发射器和接收器的最大传输距离是多少？
400 米*
* 使用 DJI Mic 3（两发一收，含充电盒），未开启无损音频传输模式，在空旷、无干扰且无遮挡的环境下测得。
此外，其他典型场景下的预估传输距离如下（仅供参考）：
两发多收，未开启无损音频传输模式，在空旷、无干扰且无遮挡的环境下的预估传输距离为 400 米。
四发多收，未开启无损音频传输模式，在空旷、无干扰且无遮挡的环境下的预估传输距离为 200 米。
两发多收，开启无损音频传输模式，在空旷、无干扰且无遮挡的环境下的预估传输距离为 200 米。
四发多收，开启无损音频传输模式，在空旷、无干扰且无遮挡的环境下的预估传输距离为 100 米。
DJI Mic 3 充电盒给发射器、接收器充满电分别需要多长时间？单独给充电盒充满电需要多长时间？
建议使用规格 5 伏、2 安（最大）的充电器为 DJI Mic 3 发射器和接收器充电，使用规格 5 伏、3 安（最大）的充电器为 DJI Mic 3 充电盒充电。
DJI Mic 3 发射器和接收器均支持快充功能。使用充电盒时，发射器和接收器可在 18 分钟内同时充至 80%*。发射器还可以通过磁吸充电线充电，18 分钟内也能充至 80%*。
在室温下，DJI Mic 3 充电盒给接收器、发射器充满电需约 50 分钟*。单独给充电盒充满电需约 1.5 小时*。
* 数据在受控测试环境下测得，仅供参考。
如何开启 DJI Mic 3 的降噪功能？如何调节降噪挡位？
可通过双击 DJI Mic 3 发射器的电源按键，开启/关闭降噪功能。
在群组连接时，使用 DJI Mic 3 接收器录音的用户，可在接收器主界面上滑进入群控页面调整设置全部已连接的发射器的强、弱降噪挡位，或是点击对应发射器区域设置强、弱降噪挡位。
使用手机录音的用户，可通过 DJI Mimo app 设置强、弱降噪挡位。
使用 DJI OsmoAudio™直连 Osmo 360、Osmo Action 5 Pro、Osmo Action 4 或 Osmo Pocket 3 时，可通过上述产品的菜单设置。

DJI Mic 3 是否支持自动省电、超时自动关机功能？
DJI Mic 3 发射器支持自动省电，且仅在发射器开机状态下生效。当发射器开机，并且未检测到接收器信号时，将自动进入休眠状态；当再次检测到信号时，它将自动唤醒并连接接收器。
DJI Mic 3 支持超时自动关机功能，需提前在接收器屏幕上或 DJI Mimo app 内分别对接收器与发射器设置，且超时关机时间为 15 分钟。具体运作逻辑如下：
1. 接收器与发射器均开启：发射器未检测到信号，自动省电不关机，接收器持续开机运作；15 分钟后两者均自动关机。
2. 接收器开启，发射器不开启：发射器未检测到信号，自动省电不关机，接收器持续开机运作；15 分钟后接收器自动关机，发射器继续保持自动省电但不关机。
3. 接收器不开启，发射器开启：发射器未检测到信号，发射器自动省电不关机，接收器持续开机运作；15 分钟后发射器自动关机，接收器持续开机运作。
4. 接收器与发射器均不开启：只有发射器自动省电运作，两者均不会自动关机。
DJI Mic 3 背夹/磁铁
DJI Mic 3 的磁吸吸力是多少？
DJI Mic 3 的磁吸吸力为 10 牛。
DJI Mic 3 采用单极充磁方式，能吸起 1.0 千克的铁块。
DJI Mic 3 磁吸背夹、磁铁是否会影响银行卡？
所有的磁铁产品均含有磁，建议将 DJI Mic 3 磁吸背夹、磁铁远离银行卡、心脏起搏器、RAM 芯片和硬盘等产品。
DJI Mic 3 磁吸背夹、磁铁在使用时会有哪些限制条件？
1. 请勿在穿着厚衣物（如毛衣、羽绒服等）时使用，避免吸力削弱，导致发射器脱落。
2. 在剧烈运动（如跳跃、快跑或其他更剧烈的运动）时请谨慎使用。
DJI Mic 3 发射器
DJI Mic 3 发射器可以安装至哪里使用？
DJI Mic 3 发射器可搭配磁吸背夹，安装在领口、衣襟、帽檐等位置，且磁吸背夹支持四向调节，收音效果更好。发射器还可搭配磁铁吸附在衣物的其他位置，如柔软衣物的中间部位，以避免下坠。此外，发射器自带磁吸功能，可根据录音需要吸附在场景中的金属物体上。
DJI Mic 3 发射器以哪种方式收音？指向或全向？
DJI Mic 3 发射器为全向收音。
DJI Mic 3 发射器有哪几种工作模式？
1. 发射器连接接收器，通过 2.4 GHz/5 GHz 频段连接。
2. 发射器蓝牙直连手机。
3. 发射器通过 DJI OsmoAudio™直连 DJI 部分产品。
各国家/地区支持的工作频段及其对应的可用范围有所不同，详情请参考当地法律法规。
发射器通过蓝牙直连手机时能否实现直播收音？如何连接？支持哪些功能？
1. 取决于直播软件和手机系统是否支持，您可以使用蓝牙耳机测试支持情况。若直播时蓝牙耳机无法收音，则无法使用发射器蓝牙直连手机进行直播收音。部分手机型号不支持双声道模式直播，请以实测为准。软件兼容信息详见 DJI Mic 3 官网
下载页面
的《第三方 App 兼容列表》。
2. 连接方式如下：开启发射器电源后，长按 2 秒发射器配对按键，此时手机会自动搜索可连接的蓝牙设备，找到 DJI Mic 3 TX 后并点选配对。若发射器指示灯处于蓝灯常亮状态，表明配对成功；若手机蓝牙无法搜索到 DJI Mic 3，请重启手机蓝牙功能，并按上述方式重新配对。
3. 发射器蓝牙直连手机收音时，可支持音色预设、增益、降噪、静音、低切、32-bit 浮点内录、双文件内录和自动增益。这些功能需通过 DJI Mimo app 或接收器设置后生效。其中，降噪和内录功能可通过发射器上的电源按键开启或关闭。
DJI Mic 3 发射器可无线连接哪些设备？这些设备最多可同时连接多少个发射器？
DJI Mic 3 发射器最多可同时连接 8 个 DJI Mic 3 接收器，DJI Mic 3 接收器最多可同时连接 4 个 DJI Mic 3 发射器。
DJI Mic 3 支持 DJI OsmoAudio™连接生态，发射器可直连 DJI 部分产品：Osmo Action 4 可直连 1 个发射器，Osmo Pocket 3、Osmo Action 5 Pro 和 Osmo 360 均最多直连 2 个发射器。支持连接 2 个发射器的设备也支持麦克风产品混连，可在 Mic 2、Mic Mini、Mic 3 中任选其二进行连接。
DJI Mic 3 发射器支持蓝牙直连手机，但手机仅支持连接一个发射器。
自动增益调节如何选择？
DJI Mic 3 支持自动增益调节功能，可通过接收器、DJI Mimo app 或 DJI OsmoAudio™设备进行设置。该功能默认关闭，开启后可选择自动控制或动态控制两挡。
自动控制（防爆音）：适合音频音量变化较大的收音场景，能够平滑处理音量，抑制突发的音量跳动，确保声音输出流畅、平衡。例如在赛场采访时，遇到突然的引擎声或发令枪声等情况。
动态控制（响度均衡）：会根据输入电平的变化自动调整音频输出的动态范围，通过提升或降低增益来补偿输入电平过低或过高的情况，适合录音室等安静环境。
开启自动增益调节后，不支持接收器增益调节。
当发射器直连部分 DJI OsmoAudio™设备时，以上两挡自动增益调节功能不生效，仅 DJI OsmoAudio™设备机身内置的自动防爆音功能生效，详见 DJI Mic 3 官网
下载页面
的《OsmoAudio™兼容列表》。
DJI Mic 3 发射器的内部存储空间是多少？是否支持外接 SD 卡存储？
DJI Mic 3 发射器内置 32GB 内存，不支持外接 SD 卡。不同规格下的录制时长如下：
24-bit（单文件）：57.3 小时
24-bit（双文件）：28.6 小时
32-bit 浮点（单文件）：43.0 小时
32-bit 浮点（双文件）：21.5 小时
DJI Mic 3 发射器内录的文件格式是什么？如何提取发射器中的音频文件？
单机内录时，每隔 30 分钟保存一个文件。24-bit 和 32-bit 浮点文件格式均为 WAV。
内录文件可通过有线连接和 app 素材下载两种方式拷贝：
有线连接：可通过标配的发射器磁吸充电线将发射器连接至电脑，或将发射器放入充电盒，通过标配的数据线将充电盒连接至电脑，从而导出录制的音频文件。
App 素材下载：打开 DJI Mimo app，连接发射器，在 app 页面中找到“素材下载”功能，从而导出录制的音频文件。
文件规格中的原文件和处理文件是什么？
DJI Mic 3 发射器内录支持同时录制原文件和处理文件，可在“TX 设置”-“文件类型”中进行选择。
原文件为发射器采集的未经处理的音频，文件名以“orig”结尾；处理文件则是经过音色预设、低切、降噪和自动增益调节等算法处理后的音频，文件名以“edit”结尾。
DJI Mic 3 发射器内录文件的命名规则是什么？
以录音文件夹“TX_MIC001_20250530_115001”为例：
TX：表示该文件夹为发射器的内录文件夹。
MIC001：表示该发射器内录的第一个文件夹，每满 50 个文件会新建一个文件夹。
20250530_115001：表示文件夹的创建日期和时间。
以录音文件“TX01_MIC002_20250527_202904_orig.wav”为例：
TX01：表示当前发射器的序号是 TX01。发射器序号由接收器按配对时序依次分配，重新配对时会改变发射器序号。
配对完成后，无论发射器是否和接收器连接，内录文件的发射器序号都会按照上一次配对的次序。
当发射器和接收器连接时，从接收器上主动删除发射器会重置内录文件的发射器序号为 TX00。
若购买的是单发射器，内录文件的发射器序号为 TX00。
发射器连接手机、OsmoAudio™设备时，内录文件的发射器序号均为 TX00。
MIC002：表示当前发射器录制的第二个文件，后续录制文件依次编号。
20250527_202904：表示文件的创建日期和时间。
连接接收器或 OsmoAudio™设备时，日期和时间会与连接设备同步；单独使用发射器时，可通过 DJI Mimo app 同步手机的日期和时间。
orig：表示发射器采集的未经处理的音频；若为 edit，则表示经过算法处理后的音频。
如何删除 DJI Mic 3 发射器中的音频文件？
发射器音频文件可连接至电脑导出或删除，若需格式化，也可通过接收器或 DJI Mimo app 进行格式化操作。
如果 DJI Mic 3 发射器存储已满，并且开启了循环内录功能，则会自动删除最早的录音文件。
DJI Mic 3 接收器
DJI Mic 3 接收器最多支持连接多少个发射器？
DJI Mic 3 接收器最多可同时连接四个 DJI Mic 3 发射器。
DJI Mic 3 接收器是否支持传输音频数据至 XLR 输入接口的设备？
不支持。
如何使用 DJI Mic 3 的监听功能？使用监听功能时，是否支持调节监听音量？
将 DJI Mic 3 接收器和发射器连接，然后将 3.5 毫米接头的耳机插入到 DJI Mic 3 接收器的 3.5 毫米监听孔，即可使用 DJI Mic 3 的监听功能；使用监听功能时支持调节监听音量，在 DJI Mic 3 接收器主界面下滑选择“RX 设置”-“监听音量”，在“监听选择”中可激活需要监听的发射器音频，在“监听音量”中可调节监听音量。
DJI Mic 3 接收器的屏幕是否支持防误触功能？如何开启？
DJI Mic 3 接收器屏幕支持锁定，主界面可长按拨轮 2 秒开启防误触功能，此时屏幕显示“锁定图标”，再次长按可关闭防误触功能。时码界面也支持防误触功能。
DJI Mic 3 接收器与手机连接时，手机能否回放声音？
无需移除接收器，即可实现手机回放声音。
DJI Mic 3 是否支持手机和接收器同时充电？
支持，当 DJI Mic 3 接收器通过手机连接头连接手机时，你可以使用充电线通过接收器 USB-C 接口连接外部电源，同时为手机和接收器充电。
DJI Mic 3 接收器输出的是数字信号还是模拟信号？
DJI Mic 3 接收器 OUT 接口输出模拟信号，用于连接相机。
DJI Mic 3 接收器 USB-C 接口和手机连接头（USB-C 或 Lightning）、热靴输出数字信号。
DJI Mic 3 的相机同步开关机功能是什么？如何使用？
DJI Mic 3 接收器通过 3.5 毫米 TRS 线或热靴连接相机使用时，可在接收器或 DJI Mimo app 内开启相机同步开关机功能，实现接收器与相机同步开关机。
如何使用四声道模式？音频怎么分配？
在“RX 设置”中可选择声道模式为四声道，选择四声道后，4 个发射器的音频将分别通过 4 个声道独立传输，不会被合并。需通过 DJI Mic 系列热靴转接件连接支持 MI 数字热靴的索尼相机，或通过 USB 连接电脑，方可使用四声道模式。
请注意，开启四声道后，通过 3.5 毫米输出接口输出的音频仍为双声道：TX1 和 TX3 为左声道，TX2 和 TX4 为右声道。
四声道模式的兼容信息详见 DJI Mic 3 官网
下载页面
的《四声道电脑软件兼容列表》。
无损音频传输是什么？适用于什么使用场景？
开启无损音频传输后，发射器传输给接收器的音频为 48 kHz 24-bit 无压缩素材，音质保留更好。
适用于对音质要求较高的录制场景，如高品质人声录制、乐器弹奏等。
由于无损音频传输码流较大，可能会影响传输距离，建议在无线干扰少、距离较近时使用。
室内模式和室外模式是什么？适用于什么使用场景？
室内模式和室外模式均支持 2.4 GHz 与 5 GHz 双频段自动跳频，区别在于两种模式在不同环境下覆盖的工作频段不同。
室内模式覆盖的频段更广，抗干扰性能更强。但由于部分国家或地区的法律法规限制，只有在室内场景下才能使用部分 5G 频段。用户需根据当地法律法规要求，并结合实际所处的室内或室外环境选择对应的模式。对于对 5G 频段使用没有环境限制的国家或地区，用户可在当地法律法规允许的情况下，默认选择室内模式。
群组连接和控制
群组连接时，如何区分主接收器和从接收器？
DJI Mic 3 支持多发多收功能。在多接收器组网时，建立群组的接收器为主接收器（界面显示为 Host），加入群组的接收器为从接收器（界面显示为 Sec）。只有主接收器可以配对和控制发射器，从接收器无法配对或控制发射器，且加入群组前，需断开所有已连接的发射器。
如何实现四发八收？
请按如下步骤配对：
1. 通过充电盒配对四发一收：先将接收器和两个发射器放入充电盒，待接收器屏幕显示发射器状态后取出两个发射器，再放入另外两个发射器，待接收器屏幕显示发射器状态后取出两个发射器和接收器。手动配对四发一收：将发射器和接收器开机，在接收器主界面下滑进入设置菜单，选择“设备配对”-“添加 TX”，点击未连接的 TX 图标进入配对状态，长按发射器配对按键进入配对模式（蓝、绿色灯交替闪烁），依次配对四个发射器。
2. 配对八收：已配对发射器的接收器为主接收器，在主界面下滑进入设置菜单，选择“设备配对”-“添加 RX”；其余接收器为从接收器，在主界面下滑进入设置菜单，选择“设备配对”-“添加 Group”。屏幕上出现鉴权码后，在主接收器上点击确认，即允许从接收器加入群组。依次添加 7 个从接收器即可建立四发八收。
从接收器加入群组前，需断开所有已连接的发射器。
群组连接后，将发射器/接收器放入充电盒是否会自动断开连接？
放入充电盒后，发射器/接收器会自动关机，但不会清除配对信息。
发射器单控和群控分别支持哪些功能？如何使用？
接收器连接两个及以上发射器后，可以使用发射器群控功能。在主接收器主界面上滑，或通过拨轮选中状态栏后，双击拨轮即可进入群控页面。在群控页面下，支持调整发射器的内录和降噪设置。
在接收器主界面点击任一发射器区域，或通过拨轮选中任一发射器后，双击拨轮即可进入发射器单控页面，在单控页面下，支持调整发射器内录、静音、降噪和音色设置。

时间码
时间码中的 LTC 和 ATC 是什么？如何使用？
时间码是一种用于音频和视频内容的时间标记，通过时间码可以快速同步音视频文件，提升制作效率。
LTC 即线性时间码，用于支持时间码功能的相机、录音机、时码器同步时码信息。
ATC（Audio-TC）即音频时间码，用于原生不支持时间码的相机，通过占用音频轨道的方式写入时间码。
您可以查阅相机或录音机的用户手册，了解其支持的时间码格式，并选择相应的转接线。常见的非线性编辑软件均支持读取线性时间码和音频时间码。
为什么开启时间码后，素材中会有规律的蜂鸣声？
开启 ATC（Audio-TC）输出后，时间码信息会通过视频的左声道输出，因此在播放素材时会听到规律的蜂鸣声。达芬奇等软件支持从音频轨道获取时间码，实现素材同步。
主接收器、从接收器和发射器之间的时间码是如何同步的？
在发射器和接收器连接并建立多发多收网络后，主接收器会自动定时向发射器和从接收器同步时间码信息，无需用户手动操作。
发射器支持时间码输入吗？
发射器会自动从接收器获取时间码，不支持从接收器以外的设备同步时间码，也不支持将时间码输出至其他设备。
如何同步外部时间码？
每个接收器都可以将时间码输出到相机、录音机等设备。请根据设备接口选择合适的连接线和输出模式。例如，DJI Ronin 4D 支持时间码输入，可通过 3.5 毫米 TRS–SDI 转接线将接收器与 Ronin 4D 的时码接口连接，并将接收器的时间码模式切换为 L-OUT，同时将设备帧率调整为一致，即可向 Ronin 4D 输出时间码。
只有主接收器支持输入外部时间码。主接收器同步后，会自动将外部时间码同步给从接收器和发射器。将主接收器的输出口连接到外部时码器，并切换到 L-IN 模式，点击 Sync 按钮，即可将外部时间码同步到接收器和发射器。同步外部时码器后，您可以选择断开与外部时间码的连接，或保持连接。断开连接后，DJI Mic 3 的时间码会独立运行；保持连接时，主接收器会持续接收外部时间码，并同步至网络内所有接收器和发射器。
断开与外部时码器连接时，请确认接收器屏幕上已弹出断开连接的图标，以避免再次连接时码器时出现误同步。
如何将时间码同步到 Osmo Pocket 3 或 Osmo Action 5 Pro？
开启 DJI Mic 3 的时间码功能，切换接收器的时间码模式为 L-OUT，调整设备至相同帧率。在 Osmo Pocket 3 或 Osmo Action 5 Pro 上进入系统设置，下滑找到时间码，通过 USB-C 手机连接头插入 Osmo Pocket 3 或 Osmo Action 5 Pro，即可同步时间码。
开启时间码会影响音频输出吗？
DJI Mic 3 提供 4 种时间码输出模式：
N/A：接收器运行时间码但不对外输出。
L-IN：用于外部时码器同步时间码信息至接收器。
L-OUT：接收器以线性时间码（LTC）方式对外输出时间码。
A-OUT：接收器以音频时间码（Audio-TC/ATC）方式对外输出时间码。

DJI Mic 3 的时间码精度如何？支持哪些帧率？
DJI Mic 3 的时间码偏移为 0.5 ppm，即 24 小时内最大偏移 1 帧*。
DJI Mic 3 支持的时间码帧率包括：23.98F、24F、25F、29.97F、29.97DF、30F、50F 和 60F。

DJI Mic 3 配件
DJI Mic 3 搭配 DJI Mic 系列热靴转接件时，可以实现哪些功能？
DJI Mic 系列热靴转接件可将 DJI Mic 3 接收器与索尼相机的 MI 热靴接口连接，无需使用相机连接线（3.5 毫米 TRS）即可实现收音，且支持 48 kHz 24-bit 数字音频收音。在使用该转接件时，索尼相机还能为 DJI Mic 3 接收器供电。
在接收器或 DJI Mimo app 中开启跟随相机开关机功能后，当 DJI Mic 3 接收器通过热靴连接相机时，相机开机，接收器会自动开机；相机关机，接收器会自动关机。
此外，该转接件还能解决部分索尼相机（如 A7S3、FX3、A6700 等）在通过 3.5 毫米线材连接某些麦克风时可能产生电流声的情况。
DJI Mic 系列热靴转接件可以在哪些相机上使用？
DJI Mic 系列热靴转接件仅适用于索尼 MI 热靴接口相机。设备兼容信息详见 DJI Mic 3 官网
下载页面
的《DJI Mic 系列热靴兼容列表》。
DJI Mic 系列热靴转接件可以与 DJI Mic、DJI Mic 2 或 DJI Mic Mini 搭配使用吗？
DJI Mic 系列热靴转接件适用于 DJI Mic 3 和 DJI Mic Mini，不兼容 DJI Mic 和 DJI Mic 2。
使用 DJI Mic 系列热靴转接件和使用相机连接线（3.5 毫米 TRS）有什么区别？
DJI Mic 系列热靴转接件可实现数字音频收音，并为接收器供电，而相机连接线（3.5 毫米 TRS）则提供模拟音频收音。无论采用哪种连接方式，接收器都支持随相机同步开关机。
DJI Mic 系列热靴转接件连接相机后，相机提示不兼容，该如何处理？
若相机不支持数字音频信号，将无法识别 DJI Mic 系列热靴转接件。设备兼容列表详见 DJI Mic 3 官网
