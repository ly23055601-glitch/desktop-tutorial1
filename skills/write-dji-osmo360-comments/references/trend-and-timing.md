# 热点与时间节点规则

本文件只在内容自然涉及时加载。默认目标是“自然轻梗”：热点帮助观众进入语境，但不承担评论的全部信息价值。

## 时间基准

- 默认使用中国时区判断“今天”“周末”“开学”“毕业季”“黄金周”等节点；链接标明其他地区或用户指定时区时，以该语境为准。
- 同时检查原帖发布时间和计划使用评论的时间。旧帖不得套用当前热点，预写稿不得假装某事件已经发生。
- 节日、赛事、旅行季、开学或毕业等节点必须与画面、字幕、口播、可见操作或目标人群有自然联系，作者标题和文案不能单独提供关联。

## 平台内优先核验

1. 先查看实际画面、字幕、口播及可见评论区是否已出现相关措辞、梗或节点讨论；作者标题和文案只作事实核对。
2. 再查看对应平台近期可见语境，确认同一表达当前的含义、情绪方向和适用人群。
3. 需要确认事件日期、赛程、发布或官方名称时，使用主办方、品牌或权威机构的当日页面。
4. 无法确认来源、含义、时效或是否冒犯时，不使用该梗；改用具体画面反应。

不得只凭记忆判断“现在流行”。不要把跨平台流行词强行搬运为目标平台的原生表达。

## 使用门槛

一个热点或梗只有同时满足以下条件才可进入正文：

- 与链接中某个具体锚点直接相关；
- 目标人群自然会理解，不需要长篇解释；
- 删除后评论仍有具体观察和清楚观点；
- 不依赖虚假身份、群体共识或未经核验的事实；
- 不借公共悲剧、灾害、未成年人风险、医疗事故、政治争议或群体污名制造轻浮笑点。

## 节点转译

- 旅行季：落到“本人入镜、行李、天气、路线、导出和使用频率”，不只写“出游必备”。
- 毕业季与纪念日：落到不可重复的画面和拍摄者也能入镜，不用“不买会后悔”施压。
- 骑行、滑雪和赛事：落到速度、机位、安装、规则和防护条件，不蹭与产品无关的输赢话题。
- 新品发布或购物节点：价格、优惠、库存、赠品与套装必须当日核验；不制造倒计时、断货或“全网都在买”。
- 节假日家庭场景：落到多人同框和完整记录，同时尊重路人、儿童与场地隐私。

## 标注与纯净版

- 使用热点或节点时，在标注版的 `时效语境` 写核验日期、平台语境、与内容锚点的关系及失效边界。
- 纯净版不写核验过程，但必须保留必要的商业关系披露。
- 同一链接最多让一组以明显热梗作为节奏工具；其余两组保持不同表达，避免整套稿同时过期。

## 失败与回退

- 平台趋势不可见：只使用实际媒体或可见评论区已经出现且含义明确的表达；否则采用平台基线。
- 热点与产品关系牵强：不用热点，改写为场景共鸣、具体疑问或条件判断。
- 链接发布时间不明：不写“刚发布”“最近都在”等时间判断。
- 事件仍在变化：只写已确认事实，或把未确认部分改为问题，不抢跑结论。
