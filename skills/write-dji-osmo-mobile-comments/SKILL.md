# DJI Osmo Mobile 消费者评论入口

## 默认训练路由

写评、改写和案例演示统一作为培训教育稿，使用`content_mode=training_fiction`、`product_line=osmo_mobile`。先读取[共享消费者写作](../../writer-core/core/write-consumer-comments/SKILL.md)，由共享层统一负责选材、人物、种草、表达与教学诊断，以及主评与回复数量、格式、材料读取及训练检查。真实链接、真实素材或用户表示自己用过，都不切换写作模式；已读证据包直接复用。

本层只补充目标产品、称呼、产品事实与专属原帖证据。训练允许的购买、持有、使用、关系和主观感受设定按共享层执行；这些设定不构成真实产品参数或原帖事实的证据。涉及实时社媒读取时执行共享层指向的[统一社媒读取技能](../read-social-links-with-social-helper/SKILL.md)。

## 产品专属边界

- 目标是DJI Osmo Mobile／DJI OM手机云台；正文可用`OsmoMobile`、`DJIOM`、`OM`及材料已确认的具体代际称呼。Pocket的禁用`Osmo`规则不适用于本产品。
- 区分材料中的`OsmoMobile8P`、`OsmoMobile8`、`OsmoMobile7P`、`OsmoMobile7`、`OsmoMobile6`、`OsmoMobileSE`、`DJIOM5`等具体型号，不把新代能力倒灌旧款，也不混为Pocket、Action、360或RS。
- 在任何项目都先按需使用[Mobile产品与人群能力库](../use-mobile-knowledge/SKILL.md)，从其随附知识库读取具体型号事实、兼容条件、场景和按需卖点，心理分析读取独立角色假设。已读入口不回调，写法继续使用同一共享层。具体产品断言按当日官方依据确认，事实ID不直接冒充旧审查claim注册号；角色表达示例不作真实反馈或认可范文。首版不含竞品与实时价格，相关请求另查当前官方来源。
- 区分DJIMimo内跟随、DJIOM多功能追踪模块及模块2、AppleDockKit与其他系统原生跟拍；支持快门控制不等于支持原生相机跟随。
- 兼容性同时核对手机重量、尺寸、保护壳、镜头模组、配件及软件；能夹住或符合载荷不代表完整兼容。
- 机械旋转范围、创意运镜、无限位跟随和最终增稳效果不是同一能力；续航、补光、跟随／遥控距离须保留测试条件，单次故障不能外推为型号通病。

## 按需资料与兼容模式

`op-conversation-sync.md`和旧入口中的自动op增量同步、固定三组、固定最低回复数及禁设经历等规则只供下述真实材料／旧稿模式使用；训练不回读op或加载其写法。

产品资料只消费型号、机制、参数、核验入口和事实条件；其中任何旧数量、先强卖点、固定槽位、结尾、角色经历或可迁移文风要求均不覆盖共享层，也不沿产品资料回读完整旧入口。

跨项目使用时不自动读取 op 历史聊天；保留流程中的 op 增量同步仅在用户明确要求同步 op 规则时执行。真实资料核验与旧稿审查可直接使用当前材料、已固化规则与现行产品依据。

只有用户明确要求对真实消费者资料、本人亲历进行专门核验或复核旧稿时，才对该核验／审查任务使用`content_mode=real_material`并读取[保留的真实材料与旧稿流程](references/legacy-real-material-workflow.md)。旧稿不为通过审查而重标为训练稿，核验与审查均不授权发布。原脚本、测试、状态模板和事实注册表保持原状，供其兼容流程使用；`training_fiction`使用共享层训练检查，不调用旧真实性严格检查器。
