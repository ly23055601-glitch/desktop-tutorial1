# Pocket4 / Pocket4P 拍摄观感与表达

这层帮助理解使用者喜欢什么、何时想拍、拍完会随口说什么。先读与当前帖子有关的一组；完整材料保留，评论只取最值得说的一点。更新于2026-09-08。

| 当前需要 | 入口 |
|---|---|
| 看光线、人物状态及直出/调色说明 | [作品材料](works.md)：7份有限抽帧、作者处理说明和一份完整四页文字体验；完整实拍作品仍待补 |
| 理解色彩偏爱、使用习惯和配件感受 | [偏好与使用阶段](preferences.md)：用原句说明差异，不按身份标签配口吻 |
| 分清相似选购问题背后的不同在意点 | [选购与上手](choice-and-learning.md)：旅行携带取舍、学习负担与首次购买；来自2篇既有文字材料 |
| 学主评与实际回复怎样承接 | [9组讨论](discussions.md)：90条既有原句，明确父句与未知关系分开；按需打开单组 |
| 保留自然原句、判断修改是否多余 | [用户反馈对照](feedback.md)：明确允许的表达与实际前后稿，保留反馈作用范围 |
| 追溯或继续补全 | [来源索引](source-index.json)、[待补材料](gaps.md) |

使用[原有帖子类型快照](post-types.source.json)分类。例如，成片与作品展示先看喜欢的效果；生活与过程记录看何时想拿起拍；测评与使用反馈看作者的条件和取舍；配件与设备方案看实际装取、握持和监看感受。同一作品可兼有几种内容，这些只是检索入口，不固定卖点、语气、长短或开头。

**这批材料的三种性质分开使用**：看过的静帧可支持有限视觉观察；作者和评论者原话可支持他们表达了什么；用户对例句的认可只支持相应表达要求。原片型号、处理条件、说话者亲历或用户个人审美没有证据时仍未知。短附和可以有价值，普通聊天不必每句增加参数或走向购买结论。

按用户最新要求，这一版以现有材料完成整理，后续补读已停止。不同光线下的人像、旅行和日常完整实拍作品仍未补齐，7篇媒体补读未提交的历史状态保留；这些是证据边界，不再阻塞本版交付。需要总览时读[一页使用入口](../START.md)。实际写评仍经当前Pocket写手和共享写手；本次不产生每日培训稿或KPI。
