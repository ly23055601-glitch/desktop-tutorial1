# Pocket 比较时的真实表达

这里整理人们如何限定需求、说明取舍、保留其他选择，以及把比较条件说清楚。原话是公共讨论，不是产品实测、用户本人的经历或已认可范文；分析也不作为固定评论模板。

[5张比较卡](cards.jsonl)均为 `case`：4张重组历史 `train` 材料，1张来自2026-09-10本批B站采集。共涉及5个独立作品；同一作品的多个观点不重复算独立证据，没有一张卡达到3篇独立作品支持的 `pattern` 门槛。旧留出正文和停止的C3评论附件未用于本专题。

| 卡片 | 比较对象与关注点 | 证据范围 |
|---|---|---|
| PKC-001 | Pocket4语境下的手机、微单、单反；携带、照片/视频、活动分工 | 历史1帖；保留继续使用手机的意见，父句未知 |
| PKC-002 | 原话里的 `luna`、`松下ZS300`；同样在意便携，也会推荐另一设备 | 与001同帖；名称与规格待核，不能当作已完成横评 |
| PKC-003 | Pocket4、4P和旧代；已有4与新买的建议不同 | 历史1篇作者文字；保留“已有4不必执着4P” |
| PKC-004 | 4与4P；自拍局部偏好、热感与人像优先级 | 历史2帖；保留偏好4的反例，四句不能拼成对话 |
| PKC-005 | Pocket3换4P；同场景、模式、调色和升级必要性 | 本批1帖3条评论；2条直接父句关系明确 |

例如，PKC-005的开口者先要求同场景比较，并提出“如果提升很小，那就不用换了”。回复者区分调色感受、成片观感和双镜头需要；后续回复补充希望比较的模式和地点；昵称相同不作为同一账号身份认证。可学习的是如何回应前一句、继续明确比较条件。网友的“假log”、肤色和调色空间说法没有因此成为事实，也没有证据证明新的对比测试已完成。

历史作品与本批近7天作品分别标在 `evidence_period`，不按评论日期把旧作品改算新作品。本批目前新增的是Pocket内部代际比较；同类口袋/云台相机及运动相机的跨品牌比较仍有缺口，实际发现、读取范围和阻塞见[研究批次清单](../_provenance/project/outputs/social-comment-research/2026-09-10/op-pocket-7d-01/manifest.json)。历史提及不能补齐本批配额。

## 检索与追溯

```bash
python3 "<技能目录>/knowledge/scripts/pocket_knowledge.py" search '旅行 携带' --model pocket_4 --competitor 手机
python3 "<技能目录>/knowledge/scripts/pocket_knowledge.py" search '同场景 不换' --model pocket_4p --competitor Pocket3
python3 "<技能目录>/knowledge/scripts/pocket_knowledge.py" search 'PKC-005'
```

`evidence_ids`指向[评论表](../corpus/comments.jsonl)或[原帖文字记录](../voice/records.jsonl)。每项 `source_refs` 保存原始作品/评论ID、normalized文件及行号、原导出表的行列、引文字符位置、文件哈希和直接父句。原话、评论分析与官方事实分别使用；具体性能比较需另核双方当前官方资料。型号未知、持有未核、媒体未读等边界保留在卡片中。

需要实际写稿时，仍进入当前Pocket与共享写手流程；本专题不增加每日培训新稿KPI，也不把第三方经历转为其他说话者的亲历。
