# 详细场景编辑自检记录

编辑日期：2026-09-07。范围仅为 `use_cases/cards.jsonl`、`guide.md` 和本文件。这是场景编写者的自检记录，不是用户验收、独立实机测试或新增消费者研究；根代理的独立审读与最终交叉映射另行记录。

## 本批形成的内容

22张卡：12张分别说明两款条件，3张仅Pocket4，7张仅Pocket4P。连接57个现存 `verified` 产品事实ID及18个既有表达卡ID。场景覆盖独旅、同行走拍、日常自述、桌面展示、穿搭与变装、亲子、家人共同入镜、宠物、食物、双人访谈、室内夜间、慢放、后期、手机及电脑传输、存储、配件收纳和型号选择。

相近题材按任务拆分：独旅离机触发与站位远程构图各有不同动作；全身竖屏与旋转换装分别解决画幅和剪辑素材；亲子优先主角与家庭整体入镜分别服务单一主角和一组人；桌前展示是人和物轮流合焦，探店近摄是镜头及物距选择。同行走拍与环境/人物双段取景合为一张，避免只换人物重复铺量。

## 已完成自检

- 22个ID及标题唯一，全部明确 `evidence_kind=editorial_hypothesis`。每卡3–5步操作、2–3个开口理由，条件、取舍、不适合情况和条件式承接点均非空。
- `models`只含 `pocket_4` / `pocket_4p`，`model_notes`逐一对应。引用均存在且为 `verified`，每条至少与该卡一种型号适配；双款卡没有将专属事实推成共同能力。全部表达引用存在且非holdout。
- 产品断言、编辑价值与场景假设分开；没有把网友意见用来认证参数。既有`pattern`不被升级为人口比例或普遍心理。PUC-011无直接表达证据，明确留空。
- PUC-001已经按审读意见补齐“可识别画面内开录并确认→退回画外→再走入”的动作，避免暗示人在画外也能做手势。其他回复机会同样不捏造父句，只在当前父句具备所说信息时使用。
- Pocket4手势、4P双镜头、两款慢动作、P4音频备份、FrameTap/Mimo互斥、两款存储及OTG恢复均按各自事实保留。胶片影调慢动作冲突与4P续航手柄冲突两条pending未进入肯定依据。

## 边界与未覆盖

本批是产品条件支撑的选材扩充，不是全功能说明书。没有覆盖长时间连续录制实测、不同环境的散热、实时续航、雨水或水下、穿戴/骑行固定、第三方支架和镜片、峰值传输速度、所有剪辑App与手机组合。未覆盖不等于不支持，遇到具体问题应查独立事实或当前官方资料。

Live Photos、轨迹延时、网络摄像头等已有个别事实，但本批未再扩卡：这样保留细化空间，也避免仅为数量而写完整流程。出现明确任务时可以在相应模式条件得到核对后新增。Pocket4宠物对象范围已在同期事实更新中独立核定；当前宠物卡选用4P作为具体场景，不构成Pocket4不支持或资料缺失的结论。

没有实拍验证22套完整流程。固定方式适配、具体距离、动作速度、遮挡、光线、音轨、焦点与后期效果都要针对任务检查。除官方确切操作外，试录、回看、安排站位和分段是编辑建议；来源的单项支持不能拼成任意模式组合通用教程。

PUC-014使用的Pocket4视频自动低光增强仍保留原事实核验日期，不能因新场景编辑或其他事实重核而称已全部更新。涉及GB/CH/DE来源的规格和条件，不默认其与目标地区设备的所有菜单、固件完全相同。

这三文件不新增采集、评论草稿、人物亲历或每日KPI，也不将助手自检标为用户认可案例。后续维护时先更新事实，再复查关联场景；如果事实降为pending，应从场景肯定依据撤下或明确保留待核问题。
