# Pocket4P｜写手主库

核验日期：2026-09-06。与 Pocket4 并列为当前重点。事实记录见 [facts.jsonl](facts.jsonl)，来源见 [official.jsonl](../sources/official.jsonl)。表达切入点是编辑推导；官方能力不能替代原帖证据、实际体验或使用人群原话。

## 先理解它改变了哪些拍摄选择

不要只记“双摄”“人像”“智能”。要把它们放回拍摄行为：人站在哪里、想要环境还是更紧的构图、谁需要留在焦点上、相机该不该转向他、拍摄者能否碰到屏幕。两颗镜头不意味着两路同时录制，人脸焦点不意味着云台会自动跟人走，遥控器也不意味着手机能够同时监看。

| 真实问题 | 应调取的知识 | 可发展的表达关注点 |
|---|---|---|
| 想拍全身环境，也想拍近一点的人 | PKF-P4P-001、002 | 景别选择、人物与背景的关系；不能写双路同时拍 |
| 想跟拍宠物而不只是拍人 | PKF-P4P-030、028 | 先确认跟随对象与模式；支持不等于原帖已使用或永不丢失 |
| 多人入镜时镜头关注谁 | PKF-P4P-004、019；PKF-S-010、011 | 群体构图、优先主角、焦点与镜头运动的差别 |
| 一个人站远些如何开始拍 | PKF-P4P-005、010、014 | 手势、遥控器、手机连接之间的操作安排 |
| 拍脸和展示物品怎么选焦点 | PKF-P4P-016；PKF-S-010、013 | 选择对焦方式，而不是承诺机器永远懂意图 |
| 晚上想让脸更合适 | PKF-P4P-006、007、008、017 | 补光、肤色修饰和整片风格的分别选择 |
| 想自己调色还是尽快发出 | PKF-P4P-018、022；PKF-S-015 | 后期意愿与工作流，不能仅靠参数猜人群 |
| 两人说话，配件怎么带 | PKF-P4P-009 | 兼容发射器数量、是否需要接收器 |
| 拍完带走素材 | PKF-P4P-003、012；PKF-S-005、007、008 | 容量、电量、手机转存与备份分别安排 |

## 人像、对焦、运镜

双镜头是构图选项。是否适合眼前帖子，还取决于作者距离、画面里想保留什么、以及原帖是否确有镜头切换证据。事实库只确认物理双摄及一次一颗工作；没有把“3倍=更漂亮”“中焦=所有人像都好看”当作事实。[4P 官方快速攻略，第05节](https://repair.dji.com/help/content?customId=01700043704&lang=zh-CN&paperDocType=FAQ&re=CN&spaceId=17)

对焦学习应先区分三件事：焦点落谁身上、是否预先登记主角、云台是否带着镜头转动。官方专门说明锁定主角追焦与登记主角优先只处理焦点，基础智能跟随才带云台运动。这个区别适合帮助写手听懂“想拍得清楚”和“想有人帮我拍”可能是两个不同需求。[对焦模式与跟随关系](https://repair.dji.com/help/content?customId=01700009262&documentType=&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)

模式边界不能省略。展示对焦不应扩写为所有模式可用；轨迹延时不能借普通视频近物对焦的能力。对话里的问题应落在真实组合上，避免把附带广告断言的句子加一个问号就当成疑问。

## 从具体操作问题调取知识

以下英国 FAQ 条目保留 `region=GB / locale=en-GB`，来源没有标出对应固件版本。可学习其具体操作关系；涉及中国大陆菜单、模式组合或存在冲突时，应核对目标设备版本。来源：[DJI 英国官方商品 FAQ](https://store.dji.com/uk/product/osmo-pocket-4p-vlog-combo?set_region=GB&vid=241311)。

| 需要回答的问题 | 知识入口与边界 |
|---|---|
| 左键为什么有时放大、有时回广角？ | PKF-P4P-020：单击结果取决于当前倍率；双击与长按又是不同动作。右键的自定义操作见021 |
| 想在中焦构图时用D-Log 2？ | PKF-P4P-022：不能省略1x限制；后期文件见PKF-S-015 |
| 广角和中焦慢动作一样吗？ | PKF-P4P-023：各自上限不同，不能互套 |
| 为什么低光模式用不了宣传里的最高倍率？ | PKF-P4P-024：12x有模式排除项，不由普通视频推断所有模式 |
| 近拍物品前要退后多少？ | PKF-P4P-025：两镜头最近对焦距离不同，实际仍需查看合焦 |
| 多人跟随时还能边拍边推近吗？ | PKF-P4P-019：先在普通视频安排构图，再考虑多人跟随的变焦限制 |
| FrameTap在手里怎么调取景和回看？ | PKF-P4P-010、026、027：配对、控制距离、摇杆用途与回放各有边界 |
| 遥控器监看能当素材导出吗？ | PKF-P4P-027不支持这种推断；导出走相机到手机/电脑的独立路径 |
| 拍4K竖屏是不是必须有竖拍菜单4K选项？ | PKF-S-016：中国帮助页区分竖拍裁切与横向握持，两种操作不要混叫 |

## 机身从开机到回放的基本操作

中国攻略正文与3.1两张静态操作图已逐项核对；以下入口限4P，仍需连同事实条件使用。

| 要做的事 | 已核操作入口 |
|---|---|
| 首次激活 | PKF-P4P-036：手机开Wi-Fi和蓝牙，Mimo首页相机图标连接并按提示激活；配对过FrameTap时先关掉它 |
| 开机、开始和停止拍摄 | PKF-P4P-031：关机时短按拍摄键开机；就绪后短按拍照或开拍/停录；长按关机按正文限定为非拍摄状态 |
| 改拍摄模式和规格 | PKF-P4P-032：左下角选模式，底部上滑调当前模式参数；这不证明录制中可切模式 |
| 架机后选跟随目标、退出 | PKF-P4P-033：画面双击选智能跟随对象，摇杆单击退出；画面单击对焦测光是另一个动作 |
| 用摇杆调构图 | PKF-P4P-034/035：上下用途先分俯仰或变焦，双击回中、三击切前后朝向；C键默认映射见021 |
| 拍完确认和带走 | PKF-P4P-037/038：拍摄界面右滑本机回放，再按手机或电脑路径传输；回放不等于已备份 |
| 收纳前卸配件 | PKF-P4P-013：先取下补光灯和增广镜，再关机收纳；保护件的完整安装仍待补 |

4P音频连接已经核到对频路径、成功音量条与自动重连（009）；发射器内录、相机音频备份和内置环境声混音仍要分开核对。开拍和停录步骤也不能回答“录制中可否从普通视频切慢动作”或各规格下1x/3x互切的完整限制。

## 低光、风格、配件

暗处拍人可分别关心光打在哪里、脸部修饰怎样预览、最终画面是什么风格。补光灯有亮度和色温调节；App 美颜要通过 Mimo 预览，胶片影调又有自己的模式边界。它们不能随意叠加，也不能通过成片观感倒推作者开启了哪种设置。事实 PKF-P4P-006、008、017 保留了具体限制；007 因地区来源对慢动作支持范围的冲突已转为待核，不能继续引用为通用事实。[快速攻略，3.4–3.5](https://repair.dji.com/help/content?customId=01700043704&lang=zh-CN&paperDocType=FAQ&re=CN&spaceId=17)

收音与遥控配件应写到连接关系。兼容无线麦可直接连相机，但不是任意蓝牙麦都通用；FrameTap 与 Mimo 一次只能连接其中一个。滤镜需要按本型号的旋转锁定步骤安装，不能套用旧机的磁吸操作。[手机连接排查](https://repair.dji.com/help/content?customId=01700009275&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)

## 麦克风、遥控器和电脑的连接安排

无线麦的对频路径和成功标志补在 PKF-P4P-009；兼容型号可直连，不能进一步推断发射器的内录、降噪或备份方式一致。4P 音频备份的文件格式、声道配置和模式排除项仍未取得成功打开的当前主站原文；不要把 Pocket4 手册中的备份规则直接挪给4P。

中国帮助页明确4P作网络摄像头时可用FrameTap控制云台（PKF-P4P-029）。Mic2发射器蓝牙收音需要电脑软件可选择音频输入（PKF-S-017）。把“机位遥控”“相机视频输入”“电脑音频输入”分别安排，能回答有画面却没选对声音来源的问题。这些条目不代表所有软件、分辨率和输出模式都兼容。[网络摄像头使用指引](https://repair.dji.com/help/content?customId=zh-cn03400006962&lang=zh-CN&re=CN&spaceId=34)

## 素材流转与待核项

本轮将存储容量、可装素材时长与电池能拍多久分开记录。若写手谈“拍一天”，必须知道是在谈容量、供电还是实际工作节奏，不能拿其中一个替代另一个。拷贝前也要先分清手机 OTG 与 Mimo 无线连接两条路径。[OTG 手机传输指引](https://repair.dji.com/help/content?customId=zh-cn03400007307&lang=zh-CN&re=CN&spaceId=34)

- **明确冲突**：快速攻略 3.5.5 和第05节对续航手柄的增时数字不一致，PKF-P4P-015 标为 `pending`。正文暂不引用分钟数，也不选一个旧数字补齐。
- **新增地区冲突**：中国攻略对胶片影调列出视频和慢动作；英国商店仅列Video，PKF-P4P-007为`pending`。未获取可解释差异的地区/固件版本记录。
- **主资料缺口**：4P完整手册、完整参数矩阵和固件历史仍未成功读取。英国商店FAQ本轮已成功打开，但并未补齐主站全部支持信息。
- **优先补核**：4P音频备份/声道分配/模式排除项；各镜头低光帧率与色彩组合的完整矩阵；FrameTap实体键、升级和全部传输边界；有线800MB/s、无线90MB/s的完整测试条件；续航手柄与胶片影调冲突。当前已核到的单项限制不能代替完整兼容矩阵。
- 不把产品名称、官方演示与第三方实拍效果混为同一类证据；待核事实不直接当作肯定正文；CW2以复核官网的`product/product_fact`链验收，LH13专项另需登记claim。
- 本文件没有真实用户的持有、购买或试用经历。人群口吻与真实顾虑由语料库提供，写手只学习表达方式，不借用他人的人生事实。
