# Pocket2｜代际对照

核验日期：2026-09-06。当前主库集中 Pocket4/Pocket4P，本页只保留已经完成的旧代对照知识。

理解 Pocket2，应把收音设置与配件连接一起看。讨论四麦、定向收音或音频变焦时，要能回到实际菜单和使用动作；讨论“拍完查看”还要分清看画面与听到回放声音。不要把后代存储与无线连接体验套用过来。[Pocket2 官方 FAQ](https://www.dji.com/pocket-2/faq)

| 问题 | 事实索引 |
|---|---|
| 激活、近摄、跟随限制 | PKF-P2-001–003 |
| 锁定、回中与翻转 | PKF-P2-004–005 |
| 四麦、定向收音、音频变焦、回放 | PKF-P2-006–009 |
| 插卡、全景导出、原片导出 | PKF-P2-010–011、013 |
| 美颜和防水壳组合边界 | PKF-P2-012、016 |
| 电脑连接、升级前置条件 | PKF-P2-014–015 |

电脑连接与升级分别有本型号的额外条件，应先读 [官方传输排查](https://repair.dji.com/help/content?customId=01700009294&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)和[固件升级指引](https://repair.dji.com/help/content?customId=01700006836&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)，不能让一个通用“重启试试”覆盖所有问题。
