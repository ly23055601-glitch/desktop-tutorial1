# Pocket4｜写手主库

核验日期：2026-09-06。与 Pocket4P 并列为当前重点；初代、Pocket2、Pocket3 只供代际对照。事实记录见 [facts.jsonl](facts.jsonl)，来源台账见 [official.jsonl](../sources/official.jsonl)。下文的表达切入点是编辑推导，不是用户访谈结论或真人使用经历。

## 先理解使用流程

学习这台机器，宜顺着“取出开机→决定拍谁、拍什么→选择构图与运动→收音→转存→收纳”走。功能不是同时开启的开关列表；同一个“想自己拍”，可能分别指启动方便、离机控制、画面跟着人走、焦点留在人脸上、回手机剪片省事。写手先确认是哪件事，再调对应事实。

| 真实问题 | 应调取的知识 | 能发展成的讨论 |
|---|---|---|
| 想拍时能否迅速开机 | PKF-P4-001、017 | 取机、取夹、旋屏，以及是否提前设好即拍 |
| 镜头能不能自己动 | PKF-P4-002、008；PKF-S-010 | 旋转运镜、主体跟随与人脸追焦的区别 |
| 我离开相机后如何操作 | PKF-P4-016 | 手势距离和画面里的识别提示 |
| 想拍人，也想展示手里的东西 | PKF-S-010、013 | 人脸焦点与展示模式需要怎样切换 |
| 晚上拍人想调整什么 | PKF-P4-003、006、015 | 自动低光增强、美肤与影调选择、额外补光 |
| 两个人说话怎么收声 | PKF-P4-004、009 | 双无线麦与现场声备份分别做什么 |
| 拍完怎么整理 | PKF-P4-005、010、011；PKF-S-007、008 | 内置存储、手机/电脑转存、线材与备份 |

## 运镜、对焦与低光

旋转运镜与主体跟随是不同拍法，不能把“能旋转”和“能跟随”拼成同一段同时工作的承诺。尤其要分清人脸追焦与云台跟随：前者管理焦点，后者才会带镜头转向主体。这直接决定了“我站着讲”“我在房间走动”“拿东西靠近镜头”三类内容该问什么。[旋转和操作说明](https://repair.dji.com/help/content?customId=01700043653&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)、[对焦与跟随区别](https://repair.dji.com/help/content?customId=01700009262&documentType=&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)

低光学习要拆成三个问题：环境暗不暗、人物脸部是否需要补光、想保留哪种风格。自动增强、灯光与美肤不是同一能力，也不是画质保证。Pocket4 的自动低光增强有明确固件引入记录；介绍时保留版本和设置前提，不把更新说明变成“原帖夜景一定由此拍出”。[2026-04-16 固件说明](https://dl.djicdn.com/downloads/DJI_Osmo_Pocket_4/RN/DJI_Osmo_Pocket_4_Release_Notes_en.pdf)

拍桌面小物与拍轨迹延时也不能直接拼接：该型号的轨迹延时默认无穷远，普通视频里的近物构图经验不能平移过来。把“不知道某个组合是否可用”留成具体问题，比随口说所有场景都适合更真实。[对焦模式表](https://repair.dji.com/help/content?customId=01700009262&documentType=&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)

## 声音、配件与素材

双人收音时，先区分需要两个独立说话者，还是只是想留现场声。无线发射器数量与内置麦音频备份是两层问题。音频备份还受延时、网络摄像头及传输模式限制，不能把“备份”写成任何工作状态下都兜底。[用户手册，印刷页21](https://dl.djicdn.com/downloads/DJI_Osmo_Pocket_4/UM/v1.0/Osmo_Pocket_4_User_Manual_en.pdf)

配件知识应包括安装、使用和收纳。增广镜、补光灯、续航手柄分别改变拍摄条件，也增加操作步骤；有配件清单不能证明每个套装都赠送、作者已经购买、或已在原片使用。PKF-P4-006、012、013 专门保留这些边界。

内置存储解决的是当下素材落在哪里，不等于不需要备份。连电脑传文件也与接电源继续拍摄不同。遇到电脑不识别、要求格式化等问题，要先理解线材、连接模式和素材保全，再讨论处理；不把故障指引写成个人实测。[电脑传输排查](https://repair.dji.com/help/content?customId=01700009294&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)

## 写作调用与缺口

- 原帖没展示具体设置时，可回应当前好奇或用途兴趣，不能归因为某项功能造成了画面。
- 数字、功能组合与菜单名称进入正文前，复核对应事实的条件及当日官方资料；CW2须将已复核官网证据登记为`product`并绑定`product_fact`，只有LH13专项另按claim注册表验收。
- 本轮已读快速攻略、用户手册、一个固件版本说明及专项支持页；未声称找到当日完整固件历史。
- 待补：各模式/倍率完整规格表、当前 D-Log 色彩版本与限制、无线麦最新型号矩阵、各手机剪辑与导出格式限制、最新套装差异。主站/商城部分页面本轮读取失败，未用旧注册表补成已核验。
- 真实使用者对握持、发热、续航、对焦和出片的感受，另从经过核验的语料学习；本文件没有提供任何可借作本人经历的素材。


## 本轮补充：声音、竖屏与调色的具体接口

- 音频备份见PKF-P4-009：控制中心开启后，兼容无线麦录视频时可同步保存内置麦，选择独立AAC或附加音轨；延时、网络摄像头、DisplayPort传输不支持。此为Pocket4手册规则，不套给4P。[手册，印刷页21](https://dl.djicdn.com/downloads/DJI_Osmo_Pocket_4/UM/v1.0/Osmo_Pocket_4_User_Manual_en.pdf)
- PKF-S-014补上Pocket4自己的D-Log→Rec.709 LUT，避免与其他型号或色彩配置混用。[官方LUT型号表](https://repair.dji.com/help/content?customId=01700007105&lang=zh-CN&paperDocType=ARTICLE&re=CN&spaceId=17)
- PKF-S-016区分竖拍裁切与横向握持；PKF-S-017记录Mic2在网络摄像头下的蓝牙收音条件。把画幅、机位、视频输入和声音输入分别设置，不能由一个“支持”推断整套配置都可用。
