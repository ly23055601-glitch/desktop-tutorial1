# 两篇现成材料的调用对照

这两例展示知识库实际怎样参与写作。独立匿名审读对第一帖的整体偏好持平；第二帖轻微偏好接入后的写法，因为“中焦拍人”与“拍半身”把具体型号连到了想拍什么。没有发现必须修改项，保留原稿。

两篇不足以证明整体写作提升，也未验证多层楼中楼能力。结果是一次模型审读，未记为用户认可；结构检查通过也不代表真实消费者体验或发布效果。

## 看稿与看依据

| 材料 | 接入前 | 接入后 |
|---|---|---|
| Pocket4参数帖 | 想试配方、想看无滤镜对照，有一条审美偏好回复 | 想分开尝试拍摄与后期、询问阴晴条件，未额外加回复 |
| Pocket4P开箱帖 | 想看整套收纳、室内人像原片 | 在意装袋是否方便、想了解中焦拍半身，未替作者回答体验问题 |
| 正文 | [接入前草稿](baseline/draft.md) | [接入后草稿](enriched/draft.md) |
| 写作依据 | [状态与逐句来源](baseline/training-state.json) | [选材简报](enriched/brief.md)、[状态与逐句来源](enriched/training-state.json) |
| 结构检查 | [结果](baseline/structure-check.json) | [结果](enriched/validation.json) |

接入后的材料没有为增加知识量而堆进D-Log、运镜或不相关配件说明。收纳问题保持“你说”的作者归属；中焦存在单独查了当前官网，拍半身是说话者的愿望，未承诺效果。来源中的未读画面、作者过往体验和缺父句的评论都没有补成证据。

## 如何选取和审读

两个写手拿到完全相同的固定输入，在独立上下文中写稿，接入后写手不看接入前草稿。选取规则是已有合格holdout中按原序号各取一篇Pocket4与Pocket4P，未按生成结果挑样本，未改变学习/留出分组。

第三个独立审读者看到每帖随机标为X/Y的稿件，先保存判断，再揭示映射。这次随机结果恰好两帖均为X=接入前、Y=接入后；不在审读前告知。五项0–2的粗尺度中四份稿件均为10/10，只表示此次文本在适用程度上成立；第一帖持平、第二帖轻微偏好属于逐句定性判断，不计算改善百分比。

[匿名逐句审读](blind-review.md)、[结构化审读](blind-review.json)、[匿名输入包](blind-packet.json)、[原始映射](reveal.json)、[揭示后结果与原稿哈希](revealed-results.json)均保留，审读后没有修改稿件。

## 固定输入与范围

- [Pocket4原始文字输入](inputs/012-6a4335f10000000017008cde.md)：原文提供拍摄参数与后期设置，20条实际评论；未读图片或视频，不评价成片效果。
- [Pocket4P原始文字输入](inputs/032-6a40a5d40000000007021f64.md)：作者尚未开拍、表达外观与收纳顾虑，10条实际评论；这些评论缺少可核父子关系，不据此编原有对话。
- [选取清单与输入哈希](manifest.json)：输入冻结后未改写。来源中的账本哈希代表冻结当时状态；后来关闭采集队列只更新状态说明，原始输入、源文字和分组未改变。

所有草稿标为培训用途，本次额外遵守不虚构过去经历、不移植第三方亲历的研究限定。两篇保持holdout，样稿和审读都不进入公开用户表达语料。原30篇规模已取消，当前例稿不会触发补采。
