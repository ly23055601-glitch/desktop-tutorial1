## 对照怎么做

从已有合格holdout按原序号各取一篇Pocket4与Pocket4P，先选输入再写稿，不改变分组，也不把这些材料写入学习卡。两组使用[相同输入与哈希](small-sample/manifest.json)、当时的CW2规则（仅为历史试验版本；[当前入口](../../../write-dji-pocket-comments/SKILL.md)不用于反推当时规则）及相同任务限制，在独立上下文中生成；接入后的写手不阅读接入前草稿。

两组均标明培训用途，本轮另加实际经历来源限制：不虚构过去的购买或使用经历，不把作者或评论者经历移给说话者。产品能力如进入正文，仍独立核对当前官方资料。没有读取的图片、连续视频或声音不补写成作品内容；没有父句的来源评论不推断关系。

第三个独立审读者只看共同输入、现行规则及每帖随机标为X/Y的稿件，先记录判断再揭示映射。逐帖按贴帖、产品理解、具体兴趣、表达自然、回复承接各0–2分审读，给出原句和理由；跨帖差异只做两篇范围内的观察。没有必要的回复可以不写。事实错、未追溯能力、冒用经历或虚构原帖内容不能用总分抵消。

稿件正文和结构检查结果保留在各组目录，检查通过只证明结构符合约定。有限模型审读不等于用户偏好、真实消费者经历或投放效果；两例中没有体现的改善不作推断。

## 历史工具

[原30篇设计](HISTORICAL-30-POST-PROTOCOL.md)与[离线输入构建工具](PREPARE_INPUTS.md)继续保留供追溯，不是当前交付待办。本次只复用工具的单帖来源核对与机械提取函数，另建两帖manifest；没有降低原30篇冻结命令的门槛，也没有声称执行了完整冻结。

CW2使用共享训练契约的`product`来源与`product_fact`断言。只有明确开展真实材料专项或旧LH13稿复核时，另用旧流程的`product_facts`与claim登记，不混算两种模式。审读反馈标为模型审读，只有用户明确给出的意见才记为用户反馈。
