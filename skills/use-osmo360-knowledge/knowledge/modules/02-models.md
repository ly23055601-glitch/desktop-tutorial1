# 02 两代产品与差异

学习目标：看到一项规格时，能说清型号和模式。定位与取舍是基于官方功能的编辑分析，不是实测排名。

## 先确定完整型号

资料中统一使用 **Osmo 360（第一代）** 和 **Osmo 360 II**。不要把“360”“大疆全景”当成已经确认代际的依据。产品档案分别见[第一代](../products/osmo_360.md)和[II 代](../products/osmo_360_ii.md)。

## 主要差异速查

| 维度 | Osmo 360（第一代） | Osmo 360 II |
|---|---|---|
| 普通全景视频 | 最高 8K/50fps，相关高帧率需相应固件。[D1-002](../CARDS.md#d1-002) | 最高 8K/60fps。[D2-003](../CARDS.md#d2-003) |
| 全景超级夜景 | 最高 8K/30fps。[D1-004](../CARDS.md#d1-004) | 最高 8K/60fps；单镜头夜景另有上限。[D2-004](../CARDS.md#d2-004)、[D2-007](../CARDS.md#d2-007) |
| 普通单镜头 | 最高 5K/60fps。[D1-003](../CARDS.md#d1-003) | 最高 4K/60fps。[D2-005](../CARDS.md#d2-005) |
| 极广角单镜头 | 最高 4K/120fps，按模式和画幅选择。[D1-003](../CARDS.md#d1-003) | 非 1:1 所列画幅最高 4K/120fps；1:1 最高 60fps。[D2-006](../CARDS.md#d2-006) |
| 全景普通／慢动作帧率（不含Vortex） | 全景4K/100fps；FAQ另说明4倍慢动作路径。[D1-002](../CARDS.md#d1-002)、[D1-028](../CARDS.md#d1-028) | 专用全景慢动作最高4K/240fps；不是普通8K模式。[D2-008](../CARDS.md#d2-008) |
| Vortex专用规格 | 4:1特殊画幅，不能代替普通全景规格。[D1-030](../CARDS.md#d1-030) | 大陆名称为时空凝固；8K/100、120fps与6K/180、200fps，按专用像素尺寸使用。[D2-009](../CARDS.md#d2-009) |
| 全景延时 | Timelapse／Hyperlapse有8K25/30等输出规格。[D1-029](../CARDS.md#d1-029) | 运动延时最高8K30，静止延时最高16K30；不属于普通实时录像。[D2-010](../CARDS.md#d2-010) |
| 用户自行维护镜片 | 机身镜头不支持用户自行更换。[D1-024](../CARDS.md#d1-024) | 可另购 II 专属套件更换外层镜片，不是更换整个模组。[D2-038](../CARDS.md#d2-038) |
| 主角跟随 | 本库未确认与 II 代同等的模式、条件和导出能力。[缺口](../GAPS.md) | 可检测 2m 内人脸，Mimo/Studio 跟随平面输出最高 4K/30fps；丢失超过 5 秒需重新锁定。[D2-024](../CARDS.md#d2-024)、[D2-025](../CARDS.md#d2-025) |

两代均有标称 128GB、约 105GB 可用内置存储；它们也是不同于最终视频文件大小的容量概念。[D1-011](../CARDS.md#d1-011)、[D2-015](../CARDS.md#d2-015)

## 如何讲解升级价值

完整判断路径见[卖点专题：选用与升级](../selling-points.md#upgrades)：记录现有设备和拍法，找已经发生的未满足任务，再核对具体差异及新增投入。需要按角色挑选讲解点时使用[角色索引](../selling-points.md#roles)，不按年龄、职业或预算标签自动安排卖点。

编辑分析应从具体任务出发。例如，需要普通全景 60fps，II 代的已核验规格能够回应这一需求；常用普通单镜头 5K/60fps，则应保留第一代这一差异。不得将“更新一代”归纳成每项规格都更高。[D1-003](../CARDS.md#d1-003)、[D2-003](../CARDS.md#d2-003)、[D2-005](../CARDS.md#d2-005)

涉及画质、低光、散热或稳定性时，模式列表只能说明可选能力。要判断实际效果，还需要同条件素材；本库没有该类实测。
