# 04 后期工作流

学习目标：分清素材传输、取景剪辑、处理效果和导出，不把软件能力写成机内直接拍摄。流程为编辑归纳，软件能力与条件按卡片核验。

## 从素材到成片

```text
记录全景素材 → 传输/导入 → 决定保留全景或重构平面
                              ↓
              选择朝向与画幅 → 剪辑/防抖/色彩 → 导出并检查
```

两代全景视频使用 OSV，平面视频使用 MP4（HEVC）。第一代全景另有 LRF 代理，不能把代理当作原始全景素材。把文件复制到电脑仅完成传输；从全景素材生成普通平面成片，仍需后期取景和导出。[D1-012](../CARDS.md#d1-012)、[D1-020](../CARDS.md#d1-020)、[D2-047](../CARDS.md#d2-047)

## 手机和电脑的入口

| 路径 | 已核验的能力与门槛 | 培训时需要补查什么 |
|---|---|---|
| DJI Mimo | 已读下载页列 v2.11.9，iOS 15+ 或 Android 9+，还需核对推荐设备。[D1-021](../CARDS.md#d1-021) | 精确手机、应用版本、输出模式及功能是否显示 |
| DJI Studio | 已读页面列 v1.2.11；Mac 为 macOS 11+、M1 或更新芯片；Windows 为 Windows 10+；建议至少 16GB 内存，还需对照 CPU/GPU 推荐。[D1-022](../CARDS.md#d1-022) | 具体功能是否限系统或芯片，处理速度和输出设置 |
| Studio → Resolve | 先在 Studio 预处理，选 Resolve 专用格式后用插件取景；已核验入口要求 Resolve 20.0.1+，macOS 15+ 或 Windows 10 64-bit 22H2+/Windows 11。[D1-023](../CARDS.md#d1-023) | II 代素材的完整插件与版本矩阵仍需核验；已有官方稿确认该工作流方向。[D2-028](../CARDS.md#d2-028) |

最低系统门槛不等于任何高规格素材都能流畅处理。上表是核验日快照，培训前应重新检查设备与软件。[D1-021](../CARDS.md#d1-021)、[D1-022](../CARDS.md#d1-022)

## II 代需要讲清的处理能力

- **主角跟随**：Mimo 或 Studio 导出跟随人物的平面视频，最高 4K/30fps；不能说成跟随平面直出 8K/60fps。[D2-024](../CARDS.md#d2-024)
- **64 倍慢动作**：以 4K/240fps 全景素材配合 Studio 的后期插帧实现，功能限 Apple M 系列 Mac。不是相机直接录制 1920fps。[D2-026](../CARDS.md#d2-026)
- **等效 8K/480fps**：由原生 8K/60fps 全景素材经 AI 插帧得到的时间流畅度描述；平面导出的尺寸还取决于裁切与软件设置。[D2-027](../CARDS.md#d2-027)

## 用真实作品理解拍后选择

按[空间视角与体验材料](../training/experience-materials.md)将同一原片与实际不同导出关联，补上本人确实做过的处理与偏好原话。先看哪一种画面让人喜欢，再解释已核验能力与投入；不同导出若还改变速度、色彩或声音须标明，不冒称单一取景对照。没有原文件或处理记录时保留证据缺口，不能由成片反推作者设置。

## 成片检查方法

这是编辑建议：先核对画幅和朝向，再检查拼接边缘、主体是否出框、声音和色彩；最后检查导出文件的实际尺寸与帧率。记录源素材模式、处理软件版本和导出设置，使后续比较可以复现。

全景防抖可在软件导出时选择；单镜头防抖有帧率、画幅和视角限制。使用 D-Log M 时也应提前规划色彩处理，不以低饱和预览直接判定画质差。[D1-006](../CARDS.md#d1-006)、[D1-027](../CARDS.md#d1-027)、[D2-019](../CARDS.md#d2-019)

本库未确认所有设备、所有模式的统一导出矩阵，详见[缺口清单](../GAPS.md)。下一章：[配件与维护](05-accessories.md)。
