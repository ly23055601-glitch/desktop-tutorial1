# 06 六类场景与内容理解

本章全部为**假想场景与编辑推演**。这些是培训用任务分析，不是用户亲历、真实实拍结果或人群调研结论。每个场景都按“任务—帮助—条件—限制—表达误区”展开。

本章保留六类入门概览；进一步选材使用[48张详细场景卡](../scenario-bank.md)，按[卖点反查不同任务](../training/scenario-to-copy.md#value-matrix)。每张细卡把具体事件、心理矛盾、后期交付和表达角度放在一起；仅发散选材时不生成评论。

<a id="travel"></a>
## 旅行：同一次拍摄保留多个方向

详细选材：[独行与共同出行SC01～04](../scenarios/01-life-travel.md#sc01)、[送礼判断SC16](../scenarios/01-life-travel.md#sc16)、[分享与整理SC33～37](../scenarios/03-creation-workflow.md#sc33)。

价值讲解入口：[后期取景](../selling-points.md#sp01)、[隐形自拍杆](../selling-points.md#sp02)、[分享流程](../selling-points.md#sp17)。结合希望自己出镜、留住共同经历及减少现场犹豫的心理假设，说明同行者、拍摄者和素材整理者各自承担什么。

- **用户任务**：希望从一段旅途中分别选出人物和周围环境的画面。
- **功能如何帮助**：两代全景素材可供后期选择视角，之后生成需要的平面成片；一代本库直接核验的取景路线有独立的软件条件，见[SP17](../selling-points.md#sp17)。[D1-031](../CARDS.md#d1-031)、[D2-052](../CARDS.md#d2-052)
- **需要条件**：实际使用全景模式，保存原始素材，并准备可处理素材的手机或电脑。[D1-012](../CARDS.md#d1-012)、[D1-021](../CARDS.md#d1-021)、[D1-022](../CARDS.md#d1-022)
- **使用限制**：近距离主体可能出现拼接问题；后期取景仍需要时间。[D1-007](../CARDS.md#d1-007)
- **表达误区**：把“后期可以换方向”说成“不需要剪辑”，或把完整全景 8K 说成所有裁切视角都有 8K 细节。

<a id="night"></a>
## 城市夜景：人物和夜色都要进入画面

详细选材：[夜市SC14](../scenarios/01-life-travel.md#sc14)、[现场参与SC46](../scenarios/03-creation-workflow.md#sc46)。

价值讲解入口：[夜景](../selling-points.md#sp05)、[色彩与调色](../selling-points.md#sp07)。先了解对方要记录夜间氛围还是动作细节，再判断模式和后期投入，不能把模式上限代替实际表现。

- **用户任务**：记录夜间步行和街景，并判断设备提供哪些夜景模式。
- **功能如何帮助**：第一代全景超级夜景最高 8K/30fps；II 代全景超级夜景最高 8K/60fps。[D1-004](../CARDS.md#d1-004)、[D2-004](../CARDS.md#d2-004)
- **需要条件**：确认使用的是全景超级夜景，不能拿普通模式或单镜头规格替代。II 代单镜头夜景最高 30fps。[D2-007](../CARDS.md#d2-007)
- **使用限制**：这些模式规格不能证明实际噪点、运动拖影或肤色表现胜过另一台相机。
- **表达误区**：把高帧率夜景支持描述成所有低光环境都明亮清晰；比较结果应等同条件素材验证后再写。

<a id="cycling"></a>
## 骑行：拍摄后选择骑手或路线

详细选材：[骑行的四种任务SC17～20](../scenarios/02-outdoor-action.md#sc17)。

价值讲解入口：[取景](../selling-points.md#sp01)、[外部视角](../selling-points.md#sp02)、[防抖](../selling-points.md#sp06)。已有运动相机时，先确认缺的是同伴、自己、路线还是整理时间，再看[是否需要新增设备](../selling-points.md#upgrades)。

- **用户任务**：从同一段行进记录中挑选不同朝向，再整理成平面视频。
- **功能如何帮助**：全景拍摄保留周围方向；后期取景与防抖用于成片处理。[D1-001](../CARDS.md#d1-001)、[D2-019](../CARDS.md#d2-019)
- **需要条件**：核对具体安装配件和型号，试拍检查杆体对齐、拼接位置及声音。[D1-026](../CARDS.md#d1-026)、[D2-018](../CARDS.md#d2-018)
- **使用限制**：物理能装上不等于该组合已经获得完整运动安装验证；单镜头 HorizonSteady 也有帧率与视角条件。[D2-019](../CARDS.md#d2-019)
- **表达误区**：宣称任何车架、任意转接角度都能隐形，或者任何帧率都保持水平锁定。

<a id="skiing"></a>
## 滑雪：低温中的运动记录

详细选材：[雪场与动作SC21～24](../scenarios/02-outdoor-action.md#sc21)。

价值讲解入口：[慢动作回看](../selling-points.md#sp08)、[供电安排](../selling-points.md#sp13)、[环境与维护](../selling-points.md#sp14)。区分希望看清动作与愿意承担准备、维护和后期工作的程度。

- **用户任务**：记录运动过程，同时安排电池和素材管理。
- **功能如何帮助**：两代官方工作温度范围包括 -20℃，可据此介绍工作温度边界。[D1-014](../CARDS.md#d1-014)、[D2-035](../CARDS.md#d2-035)
- **需要条件**：按实际电池型号安排供电，充电应在 5～40℃ 范围内；安装件按准确用途核对。[D2-034](../CARDS.md#d2-034)、[D2-035](../CARDS.md#d2-035)
- **使用限制**：25℃ 实验室续航不能直接套到雪场；官方建议避免在雨雪及水上活动中使用透明保护镜，以免起雾。[D2-033](../CARDS.md#d2-033)、[D2-045](../CARDS.md#d2-045)
- **表达误区**：把低温工作范围说成低温续航不衰减，或宣称可以在 -20℃ 直接充电。

<a id="motorcycle"></a>
## 摩旅：安装、收音与长时拍摄一起考虑

详细选材：[停靠讲述、人车同框、露营与徒步SC25～29](../scenarios/02-outdoor-action.md#sc25)。

价值讲解入口：[安装](../selling-points.md#sp11)、[收音](../selling-points.md#sp15)、[已有设备配合](../selling-points.md#sp18)。以路线记录、同行讲述或个人回忆的具体任务选择能力，不默认所有摩旅者都需要两台相机。

- **用户任务**：在记录路线的同时保留讲述，并规划分段素材。
- **功能如何帮助**：两代可以直连兼容 DJI 发射器；全景记录供后期挑选方向。[D1-015](../CARDS.md#d1-015)、[D2-030](../CARDS.md#d2-030)
- **需要条件**：核对安装件与发射器准确型号；先试拍并回听，明确想保留哪些声音。相机音轨不因发射器具有独立内录能力就自动成为 32-bit float。[D1-015](../CARDS.md#d1-015)、[D2-029](../CARDS.md#d2-029)
- **使用限制**：本库没有高速抗振、风噪或长时间热停的同条件实测；官方续航有特定实验条件。[D1-013](../CARDS.md#d1-013)、[D2-049](../CARDS.md#d2-049)
- **表达误区**：承诺任何速度都无风噪、全程不断录或机身永不发热。

<a id="water"></a>
## 水上活动：区分水面、防水和水下全景

详细选材：[水面、水下与维护SC30～32](../scenarios/02-outdoor-action.md#sc30)。

价值讲解入口：[环境与镜片维护](../selling-points.md#sp14)。先了解实际水面／水下任务及器材准备意愿；同一防水数值不能自动转成相同的成片收益。

- **用户任务**：先明确是在水面记录，还是需要真正的水下全景画面。
- **功能如何帮助**：两代有机身防水规格；II 代另有适配全隐形防水壳方案。[D1-010](../CARDS.md#d1-010)、[D2-036](../CARDS.md#d2-036)、[D2-037](../CARDS.md#d2-037)
- **需要条件**：检查盖板与密封；II 代壳体按规范安装，水下主体安全拼接距离为 1m。第一代适用壳体须另行核验，不能由 II 代类推。
- **使用限制**：裸机防水不保证水下拼接；透明保护镜不能代替防水壳；标称壳体深度也有环境与状态条件。[D2-037](../CARDS.md#d2-037)、[D2-045](../CARDS.md#d2-045)
- **表达误区**：把“裸机防水 10m”说成“下水随便拍都无缝”，或将透明保护镜描述成潜水附件。
