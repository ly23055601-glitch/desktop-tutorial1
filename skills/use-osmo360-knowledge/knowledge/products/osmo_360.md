# Osmo 360 产品档案

本页只对应 **Osmo 360 第一代**。卖点相关能力于2026-09-07复核；历史固件基线保留原核验日，具体以卡片日期为准。官方事实见链接知识卡，卡内保存条件、版本和原始来源；“培训理解”属于编辑归纳。

## 先建立型号和模式概念

想了解“这些功能为什么值得在意”，先看[卖点专题](../selling-points.md)中标为“第一代”的能力栏：从[全景取景](../selling-points.md#sp01)、[隐形自拍杆](../selling-points.md#sp02)、[单镜头用途](../selling-points.md#sp03)出发，再按需要看[慢动作](../selling-points.md#sp08)、[延时与时空凝固](../selling-points.md#sp09)、[收音](../selling-points.md#sp15)和[后期投入](../selling-points.md#sp17)。已有本机的用户可查[升级判断](../selling-points.md#upgrades)，区分真实任务差异与新鲜感。

培训理解：把它理解为可记录周围视角、再选择成片构图的相机。讲产品时先说“全景”还是“单镜头”，再说分辨率和帧率；全景预览视角的变化不等于记录范围随之变化。[D1-001](../CARDS.md#d1-001)

| 查阅项 | 已核验要点 | 事实卡 |
|---|---|---|
| 硬件 | 183克；两颗1/1.1英寸方形CMOS | [D1-009](../CARDS.md#d1-009) |
| 普通全景录像 | 最高8K50；另有6K60、4K100 | [D1-002](../CARDS.md#d1-002) |
| 单镜头录像 | 普通视频最高5K60；极广角最高4K120；录像中前后镜头切换限4K60及以下，不是同时录两路 | [D1-003](../CARDS.md#d1-003) |
| 超级夜景 | 全景8K/6K最高30fps；单镜头极广角4K/2.7K最高30fps | [D1-004](../CARDS.md#d1-004) |
| 照片 | 全景120MP；单镜头30.72MP | [D1-005](../CARDS.md#d1-005) |
| 色彩 | 10-bit、D-Log M；需区分记录能力和具体导出路径 | [D1-006](../CARDS.md#d1-006) |
| 增稳 | 全景导出时可选；单镜头HorizonSteady有视野、比例、帧率限制 | [D1-027](../CARDS.md#d1-027) |
| 慢动作 | 全景4K100、单镜头极广角4K120的4倍慢动作路径；不混同Vortex | [D1-028](../CARDS.md#d1-028) |
| 全景延时 | Timelapse、Hyperlapse有8K25/30等规格；帧率指延时输出，不是普通实时录像 | [D1-029](../CARDS.md#d1-029) |
| Vortex专用模式 | 使用4:1特殊画幅，具体分辨率/帧率见卡；不是普通2:1全景规格 | [D1-030](../CARDS.md#d1-030) |

这些数字属于指定模式。培训中禁止把“8K全景”直接写成每个平面视角都拥有8K细节，也不要把产品页的“1英寸全景覆盖”换写成传感器物理尺寸。

## 拍摄前按这条顺序核对

1. **设备与版本**：Mimo激活后检查固件。当前已读发布记录基线为V01.03.08.70；智能影调还受Mimo版本和拍摄规格限制。[D1-017](../CARDS.md#d1-017)、[D1-018](../CARDS.md#d1-018)
2. **机位**：主体距相机至少0.75米是官方拼接建议；自拍杆隐形需要全景模式及正确对齐，不能依靠折角转接件任意摆放。[D1-007](../CARDS.md#d1-007)、[D1-008](../CARDS.md#d1-008)
3. **声音**：按TX型号核对直连支持，最多两发；另存的机身备份音轨也要纳入素材清单。[D1-015](../CARDS.md#d1-015)、[D1-016](../CARDS.md#d1-016)
4. **存储和电池**：检查可用容量、选定卡型及剩余录制时间。宣传续航数字只能连同实验室条件使用；工作温度与充电温度分开判断。[D1-011](../CARDS.md#d1-011)、[D1-013](../CARDS.md#d1-013)、[D1-014](../CARDS.md#d1-014)、[D1-025](../CARDS.md#d1-025)
5. **配件**：确认快拆装配、镜头保护模式与环境限制；透明保护镜不能因机身有防水规格就用于水下。[D1-010](../CARDS.md#d1-010)、[D1-024](../CARDS.md#d1-024)、[D1-026](../CARDS.md#d1-026)

## 从素材到成片

| 阶段 | 应完成的工作 | 事实依据 |
|---|---|---|
| 搬运素材 | 经Mimo下载或USB复制，区分OSV原素材、MP4平面素材和LRF代理 | [D1-012](../CARDS.md#d1-012)、[D1-019](../CARDS.md#d1-019) |
| 决定输出 | 培训理解：先确认要交互全景还是固定构图平面片，再安排取景和编辑 | [D1-020](../CARDS.md#d1-020) |
| 确认工作设备 | 查Mimo推荐机型或Studio系统及配置要求 | [D1-021](../CARDS.md#d1-021)、[D1-022](../CARDS.md#d1-022) |
| 接入Resolve | 使用官方插件路径时，先在Studio预处理并导出专用格式 | [D1-023](../CARDS.md#d1-023) |

培训理解：验收成片时应同时检查主体是否被取景裁掉、接缝是否经过脸部、地平线、声音以及导出参数。先试导出一小段，再决定整批素材流程；这一建议不代表本次已做设备实测。

## 不能直接下的结论

- “防水10米，所以裸机水下全景一定拼接正常”：官方明确指出折射与拼接限制。[D1-010](../CARDS.md#d1-010)
- “190分钟续航适用于8K、亮屏、无线收音等任意组合”：对应的是6K24及长续航模式等指定条件。[D1-013](../CARDS.md#d1-013)
- “任意DJI麦克风都能插接收器使用，视频直接存32-bit float”：需按TX兼容表和机内保存说明判断。[D1-015](../CARDS.md#d1-015)
- “Studio在所有电脑上功能一致、全都可按同一上限导出”：本次只确认下载页门槛，未完成设备与导出组合验证。[D1-020](../CARDS.md#d1-020)、[D1-022](../CARDS.md#d1-022)

价格、套装实时清单、透明保护镜之外的完整配件交叉兼容、全套后期功能和同条件画质/散热表现仍需专项核验。源记录在[第一代来源账本](../sources/dji_first.jsonl)，结构化事实在[第一代知识卡数据](osmo_360.facts.jsonl)。
