# Osmo 360 II 产品档案

本文只对应 **Osmo 360 II**。卖点相关能力于2026-09-07复核；价格、历史固件及导出缺口保留原卡日期。当前参数与FAQ已实际读取中国大陆正文，另用大陆帮助中心与澳门商城脚注补证。海外来源在知识卡及账本标明，不据此推断大陆销售套装或价格。

使用方法：先看“模式速查”，再按任务查操作与限制。卡号可跳到事实、条件及官方来源；“培训解释”是编辑归纳。

## 型号与成像

卖点学习入口：阅读[专题](../selling-points.md)中标为“II代”的能力栏，结合[夜景任务](../selling-points.md#sp05)、[慢动作](../selling-points.md#sp08)、[主角跟随](../selling-points.md#sp10)、[镜片维护](../selling-points.md#sp14)及[素材传输](../selling-points.md#sp16)理解价值与条件。是否替换现有设备见[选用与升级判断](../selling-points.md#upgrades)，不能只凭代际名称下结论。

Osmo 360 II 配置双 1/1.1 英寸方形 CMOS、f/1.9 光圈。“1 英寸全景影像”采用全景成像面积口径，不能把两种写法当成互相矛盾的传感器规格。机身参数为 61×36.3×81mm、183g。[D2-001](../CARDS.md#d2-001) [D2-002](../CARDS.md#d2-002) [D2-048](../CARDS.md#d2-048)

**培训解释：**先确认相机在拍全景还是单镜头，再解释分辨率。整张球面画面的像素需要覆盖各方向，后期取其中一个视角，不能直接承诺该视角保留全部球面像素。

## 模式速查

下表是培训用关键上限；像素尺寸与可选帧率见对应卡片。它不替代相机的当前设置界面。

| 模式 | 核验结果 | 易混点 |
|---|---|---|
| 普通全景视频 | 8K、6K 均可选 24/25/30/48/50/60fps。[D2-003](../CARDS.md#d2-003) | 8K 是完整全景规格 |
| AI 超级夜景 2.0／全景 | 8K、6K 均最高 60fps。[D2-004](../CARDS.md#d2-004) | 不继承到单镜头夜景 |
| 普通单镜头 | 4K、2.7K，4:3／16:9，最高 60fps。[D2-005](../CARDS.md#d2-005) | 不沿用一代的 5K 参数 |
| 单镜头极广角 | 4K／2.7K 的 4:3、16:9、9:16 最高 120fps；1:1 最高 60fps。[D2-006](../CARDS.md#d2-006) | 1:1 与其他比例不同 |
| 单镜头超级夜景 | 4K／2.7K、4:3／16:9，25/30fps。[D2-007](../CARDS.md#d2-007) | 不可写为 4K/60fps |
| 全景慢动作 | 4K 3840×1920，100/200/240fps。[D2-008](../CARDS.md#d2-008) | 与普通全景视频分开 |
| 时空凝固（Vortex） | 专用模式有 8K/100、120fps；6K/180、200fps。[D2-009](../CARDS.md#d2-009) | 不可概括为普通 8K/120fps |
| 全景延时 | 运动延时最高 8K/30fps；静止延时最高 16K/30fps。[D2-010](../CARDS.md#d2-010) | 16K 不是普通实时录像 |
| 照片 | 全景最高 120 MP、单镜头 30.72 MP；格式表列 JPEG、RAW。[D2-011](../CARDS.md#d2-011) | RAW 与 HDR 具体组合另核验 |

视频支持 10-bit；D-Log M 不适用于拍照、静止延时与长续航模式，开启后智能影调、胶片影调均不可用。相机也没有独立的“HDR 视频拍摄模式”。[D2-012](../CARDS.md#d2-012) [D2-013](../CARDS.md#d2-013)

智能影调可调节对比度、提亮人脸；开启后需导入DJI Mimo查看效果，并与D-Log M互斥。它不等于所有素材无需调色。[D2-053](../CARDS.md#d2-053)

单镜头录像时可切换前后镜头，条件为最高4K/60fps；不等于同时录两路，也不能套到120fps。[D2-054](../CARDS.md#d2-054)

官方最高 14.5 级动态范围测得于 **全景 8K/30fps、普通色彩、自动曝光、前后测光**的实验室条件，不代表所有模式或场景。[D2-014](../CARDS.md#d2-014)

## 拼接、自拍杆和防抖

- 常规全景拍摄，主体应至少距相机 0.75m；使用全隐形防水壳拍水下内容时为 1m。贴近相机的手、车身或人物可能跨越接缝，培训时应先检查距离和机位。[D2-017](../CARDS.md#d2-017)
- 自拍杆隐形依靠双镜头重叠区域与拼接；相机和杆保持直线，连接处不能偏离相机前后平面。转接件折出角度可能影响隐形效果。[D2-018](../CARDS.md#d2-018)
- 全景防抖在 Mimo 或 Studio 导出时选择。普通单镜头 HorizonSteady 限于标准视角、16:9、畸变校正、最高 60fps；极广角单镜头也限于最高 60fps。[D2-019](../CARDS.md#d2-019)

**培训解释：**“隐形”是特定拍摄和拼接条件下的效果。讲机位时，应展示一段测试素材，检查杆、手和接缝，再开始正式拍摄。

## 首次使用与拍摄操作

首次使用通过 DJI Mimo 激活：手机打开 Wi-Fi、蓝牙并登录 DJI 账号，连接相机后跟随提示。固件升级同样由 Mimo 推送，升级前相机电量大于 15%。[D2-020](../CARDS.md#d2-020) [D2-021](../CARDS.md#d2-021)

存储分为内置与 microSD：标称内置 128GB，可用 105GB；microSD 最高支持 1TB。选卡时核对官方型号清单，不能仅凭同为 V30 认定已经兼容。[D2-015](../CARDS.md#d2-015) [D2-016](../CARDS.md#d2-016)

主角跟随可检测相机周围 2m 内的人脸，通过 Mimo 或 Studio 输出跟随主角的平面视频，最高 4K/30fps。丢失主角超过 5 秒会提示；主角重新入画后仍需手动锁定。[D2-024](../CARDS.md#d2-024) [D2-025](../CARDS.md#d2-025)

远离触屏操作时，可使用已开启的语音、手势或扭转开拍：语音建议在安静环境 1m 内，手势约 2m 内，扭杆需连续两次且每次超过 45°。关机时短按拍摄键可用 SnapShot；停拍 3 秒无操作后自动关机。[D2-041](../CARDS.md#d2-041) [D2-042](../CARDS.md#d2-042)

## 素材与后期路径

全景素材可在后期改变拍摄角度；转换为平面视频需截取所需视角，输出规格受裁切和软件设置影响。不能把球面8K理解为每个取景视角都有8K。[D2-052](../CARDS.md#d2-052)

| 任务 | 操作路径与限制 |
|---|---|
| 手机连接和下载 | 手机 NFC、蓝牙开启并已安装 Mimo；解锁停留主屏幕后碰相机。相机回放页先选片再碰，可下载选中素材；全景视频进入 Mimo 相册，其他进入手机相册。[D2-022](../CARDS.md#d2-022) |
| 电脑或有线取素材 | 可用读卡器或 USB-C 文件传输；相机需选择对应 USB 文件传输模式。[D2-023](../CARDS.md#d2-023) |
| 区分原片与成片 | 全景素材为 OSV，平面视频为 MP4（HEVC）。复制文件只是传输，接下来还需决定保留全景还是重构平面视角。[D2-047](../CARDS.md#d2-047) |
| 主角跟随成片 | 用 Mimo／Studio 输出最高 4K/30fps 的跟随平面视频。[D2-024](../CARDS.md#d2-024) |
| 64 倍慢动作 | 4K/240fps 全景素材配合 Studio 的后期插帧；该功能限定 Apple M 系列 Mac。[D2-026](../CARDS.md#d2-026) |
| “等效 8K/480fps” | 来自 8K/60fps 全景素材的 AI 插帧效果；不等于相机原生录制，平面分辨率还受取景裁切和导出设置影响。[D2-027](../CARDS.md#d2-027) |
| 进入 DaVinci Resolve | 官方发布稿给出的路径是先由 Studio 导出全景视频，再通过插件导入 Resolve；完整插件版本矩阵仍待补齐。[D2-028](../CARDS.md#d2-028) |
| 运动模糊／ND 效果 | 当前支持 Apple M 系列 Mac 的 Studio，以及 iPhone 14 及以后机型的 Mimo；先更新软件。[D2-046](../CARDS.md#d2-046) |

**培训解释：**“原生拍摄帧率”“后期插帧”“播放慢放倍率”“平面输出分辨率”是四个独立字段。完整的各平台导出矩阵还没有核验，不把某个功能的导出上限推给整个软件。

## 收音

机身有 4 个麦克风，录音规格为 48kHz、16-bit、AAC。外接 DJI Mic 发射器不意味着相机音轨自动变成 32-bit float。[D2-029](../CARDS.md#d2-029)

大陆帮助中心列明可无线直连 DJI Mic 2、Mic Mini、Mic 3、Mic Mini 2、Mic Mini 2S 的 TX，**不支持通过 RX 连接**。相机可同时连接两台支持的 DJI 无线发射器；在相机麦克风菜单打开 TX1/TX2 配对，再让发射器进入蓝牙配对状态。[D2-030](../CARDS.md#d2-030) [D2-031](../CARDS.md#d2-031)

**培训解释：**安排双人收音前，记录两台发射器的准确型号、固件和连接模式，分别试录并回放确认。型号兼容清单不能代替对混搭和特殊音频功能的检查。

| 主题 | 标准说法及条件 |

| 续航 | 全景 8K/30fps 最长 100 分钟，长续航模式最长 120 分钟。条件是 25℃ 实验室、Wi-Fi／手势／语音／快剪助手关闭、屏幕关闭；欧盟和英国另有温度法规差异。[D2-033](../CARDS.md#d2-033) |
| 温度与充电 | 工作 -20～45℃、充电 5～40℃；FAQ 建议 PD 3.0、最大 PD 输出至少 30W 的 USB-C 充电器，支持边充边用。[D2-035](../CARDS.md#d2-035) [D2-043](../CARDS.md#d2-043) |
| 长期存放 | 超过 10 天不用，建议 40%～65% 电量储存，约每 3 个月充放电维护。[D2-044](../CARDS.md#d2-044) |

| 全隐形防水壳 | 另购后标称 50m，水下安全拼接距离 1m；数值来自受控水压实验，受环境与产品状态影响。[D2-037](../CARDS.md#d2-037) |
| 镜片受损 | II 的外层镜片可通过对应更换套件自行更换；不是镜头模组或传感器更换。[D2-038](../CARDS.md#d2-038) |
| 透明保护镜 | 仅防泼溅，不供水下使用；官方建议避免在雨雪及水上活动中使用，以免起雾，不能代替防水壳。[D2-045](../CARDS.md#d2-045) |

| 发热排查 | 高规格和长时间拍摄会增加发热；可降规格、关屏、关闭不必要的 Wi-Fi 并改善通风。没有固定热停时间或永不热停保证。[D2-049](../CARDS.md#d2-049) |

水下使用前应关紧电池仓和 USB-C 保护盖，避开温泉、腐蚀或不明液体、极端涉水环境和长时间高冲击水流。[D2-036](../CARDS.md#d2-036)

## 代际培训要点

II 档案可确认的变化包括更高普通全景和夜景帧率、主角跟随、外层镜片自行更换、NFC、双向磁吸设计等。比较时应同时查阅[一代档案](osmo_360.md)的当前卡片，避免把上市时参数当成一代现状。[D2-003](../CARDS.md#d2-003) [D2-004](../CARDS.md#d2-004) [D2-022](../CARDS.md#d2-022) [D2-024](../CARDS.md#d2-024) [D2-038](../CARDS.md#d2-038) [D2-039](../CARDS.md#d2-039)

**培训解释：**新一代的某项上限提高，不代表所有模式上限都提高。普通单镜头的最高规格、特殊慢动作模式、后期硬件要求都必须逐项核对。没有同条件素材时，本档案不设画质、散热或稳定性排名。
