# Osmo 360 卖点与用户价值

整理日期：2026-09-07。对象：内容与运营培训团队。默认简体中文、中国大陆环境；一代部分依据来自美国英文官方站，二代后期构图等部分依据来自中国澳门商城。官方说法的适用地区、版本和实际核验日期以各事实卡为准。

本专题将**已读取的官方能力 → 能帮助完成的任务 → 需要付出的条件与投入**连起来。官方能力引用知识卡；用户价值是**编辑解释**，具体使用情境是**假想场景**；人群与心理关联是 **editorial_hypothesis / unvalidated**，不代表消费者调研、购买意愿或真实体验。正文用于培训讲解，需要写消费者评论时再接入共用写手流程。

分类口径：**品类原理**说明全景拍摄与后期的工作方式，不称独家优势；**本机能力**只说明该型号已确认的支持，不据此推定竞品或其他型号没有；**已核验代际差异**需两代都有对应依据。参数只保留解释价值所必需的例子，完整规格和脚注通过事实卡查阅。

## 拍摄视角

<a id="sp01"></a>
### SP01 · 先记录周围，再决定给观众看哪里

- **官方能力与型号｜品类原理＋两代本机能力**：一代全景模式记录球形画面，屏幕拖动只是改变预览；官方已明确一条拍后重新取景的Studio预处理→Resolve插件路径。II全景素材可在后期选择构图，转平面视频时裁切视角。[D1-001](CARDS.md#d1-001)、[D1-031](CARDS.md#d1-031)、[D2-052](CARDS.md#d2-052)
- **用户价值（编辑解释）**：把部分构图决策留到活动结束后；同一段经历可以先看人物，再看当时的环境，帮助组织“人在什么地方做了什么”的叙事。
- **适用人群与心理（待验证假设）**：独行者、构图新手、兼顾多人活动的记录者；关联[A360-H03 怕遗漏](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h03)和[A360-H04 想参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)中经过广场，回去后从同一段素材选出同行者反应与周围建筑。
- **成立条件与投入**：实际以全景模式开拍，保留原素材并安排后期；两代常规拼接均建议主体至少距相机0.75m。具体操作与设备要求按所选路线核对：[SP17](#sp17)列明一代已核验Resolve取景路线及两代一般后期入口，不把该插件要求套成所有取景的必要条件；II导出分辨率以实际软件设置为准。[D1-007](CARDS.md#d1-007)、[D2-017](CARDS.md#d2-017)、[D1-031](CARDS.md#d1-031)、[D2-052](CARDS.md#d2-052)
- **价值不成立的情况**：只需要一个已确定方向，或积压素材一直不处理时，全景的选择余地可能只增加筛选工作；手机或已有相机可能已完成任务。
- **表达边界**：可讲“把部分取景留到后期”；不能讲“永远不会漏拍”。没开录的时刻、被遮住的内容和原素材不足的细节无法凭取景补回；球面8K不等于任意裁切视角8K。

<a id="sp02"></a>
### SP02 · 让拍摄者进入人与环境的同一个画面

- **官方能力与型号｜品类原理＋两代本机能力**：两代全景模式均借助双鱼眼重叠区域与拼接处理消除正确安装的自拍杆；相机与杆要保持直线。一代与II的依据分别见[D1-008](CARDS.md#d1-008)、[D2-018](CARDS.md#d2-018)。
- **用户价值（编辑解释）**：独行或总负责拍摄的人，可以尝试把自己放回旅行记录；把杆体从成片中消除，也让观众更集中地看人物与环境的关系。
- **适用人群与心理（待验证假设）**：独自旅行、情侣结伴、家庭记录者；关联[A360-H01 希望自己也被记录](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h01)和[A360-H05 外部视角](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h05)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)时在允许举杆的开阔位置试拍，取景时同时保留自己的行走状态和街道环境。
- **成立条件与投入**：使用适配的隐形自拍杆、拧紧连接并保持对齐；全景模式下试拍检查杆体与接缝。常规拼接距离建议至少0.75m，复杂遮挡仍可能影响画面。[D1-007](CARDS.md#d1-007)、[D2-017](CARDS.md#d2-017)
- **价值不成立的情况**：不愿携杆、现场不便举杆、主要拍近距离面部，或已有同行者轻松完成所需构图时，这种视角未必带来足够新增价值。
- **表达边界**：可讲“正确安装后获得杆体被消除的全景视角”；不能说整个人、影子或任何转接件都会自动消失，不能把单镜头模式套入同一承诺，也不能称为本机独有原理。

<a id="sp03"></a>
### SP03 · 方向明确时，用单镜头完成常规记录

- **官方能力与型号｜本机能力＋已核验代际差异**：一代单镜头普通视频最高5K/60fps；II最高4K/60fps。两代另有最高4K/120fps的单镜头极广角模式，须按比例和帧率分别查表。两代都可在单镜头录像中不中断切换前后镜头，切换功能均限4K60及以下规格，不是II独有。[D1-003](CARDS.md#d1-003)、[D2-005](CARDS.md#d2-005)、[D2-006](CARDS.md#d2-006)、[D2-054](CARDS.md#d2-054)
- **用户价值（编辑解释）**：同一台相机能在“想保留周围方向”和“只记录眼前明确主体”之间分工；已知构图的片段可直接进入平面素材流程。两代符合切换规格时，都可在连续讲述中切换讲述者与眼前景物。
- **适用人群与心理（待验证假设）**：旅行记录者、已有主相机而补第二机位的人；关联[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)和[A360-H08 后期精力有限](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h08)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)中先录全景步行片段，到固定景点后改拍一个已确定方向的说明镜头。
- **成立条件与投入**：先选普通或极广角模式，再核对比例、帧率与增稳组合；单镜头素材为平面MP4（HEVC），仍可能需要剪辑、调色和声音整理。[D1-012](CARDS.md#d1-012)、[D2-047](CARDS.md#d2-047)
- **价值不成立的情况**：如果几乎全部任务都是单方向拍摄，已有手机或运动相机已满足，未必需要为全景能力增加设备。
- **表达边界**：II不是每项数字都高于一代；不能把一代5K普通视频移植到II，也不能由单镜头最高分辨率直接判定整机画质胜负。单镜头不保留背后完整球面素材；两代切镜头均不等于同时录两路，也不外推至一代5K60或两代4K120。

## 影像表现

<a id="sp04"></a>
### SP04 · 为环境记录和后期取景提供较大原始画面

- **官方能力与型号｜本机能力＋已核验代际差异**：两代均为双1/1.1英寸方形CMOS。一代普通全景最高8K/50fps，II最高8K/60fps；两代全景照片均最高120MP，单镜头照片最高30.72MP。[D1-009](CARDS.md#d1-009)、[D2-001](CARDS.md#d2-001)、[D1-002](CARDS.md#d1-002)、[D2-003](CARDS.md#d2-003)、[D1-005](CARDS.md#d1-005)、[D2-011](CARDS.md#d2-011)
- **用户价值（编辑解释）**：较大的球面原素材用于保留周围环境，并为选择不同方向提供基础；照片和视频可按“留下静态场景”或“记录过程”分工。若运动记录或作品制作需要每秒60帧的时间采样，II提供对应的8K全景输入素材；是否能按目标规格交付，仍需检查后期路径。
- **适用人群与心理（待验证假设）**：旅行创作者、空间纪念者、全景观看爱好者；关联[A360-H02 留住生活](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h02)和[A360-H06 摸索玩法](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h06)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)时用照片保存一处空间的整体环境，再用视频记录人经过的过程；输出前分别检查目标视角的细节。
- **成立条件与投入**：正确选择照片或普通全景视频规格；一代8K48/50需包含相应支持的固件。准备足够存储，并按最终用途试导出、检查细节。[D1-002](CARDS.md#d1-002)、[SP12](#sp12)、[SP17](#sp17)
- **价值不成立的情况**：只看手机小窗口、输出用途没有更高规格需要，或电脑处理能力与时间成为瓶颈时，最高规格未必是最合适的默认设置。
- **表达边界**：120MP是全景照片总像素，8K是全景球面视频规格；不能写成任意平面视角都保留这些数字，也不能只靠数字判定跨品牌清晰度。“1英寸全景影像”属于全景成像面积口径，不能改写为两颗物理1英寸传感器。[D1-009](CARDS.md#d1-009)、[D2-002](CARDS.md#d2-002)

<a id="sp05"></a>
### SP05 · 把夜间活动纳入可选的拍摄安排

- **官方能力与型号｜本机能力＋已核验代际差异**：一代全景超级夜景的8K、6K最高30fps；II对应最高60fps。两代单镜头超级夜景均需另查4K／2.7K、25／30fps规格。[D1-004](CARDS.md#d1-004)、[D2-004](CARDS.md#d2-004)、[D2-007](CARDS.md#d2-007)
- **用户价值（编辑解释）**：夜间散步、灯光街道里的共同经历，也可以纳入记录计划；想保留的不只是白天打卡，还有晚间相处与活动。II增加全景超级夜景的帧率选择，为确有较高帧率需求的拍摄任务提供选项。
- **适用人群与心理（待验证假设）**：城市旅行、晚间结伴记录、夜景创作者；关联[A360-H02 留住生活](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h02)和[A360-H03 怕遗漏](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h03)。
- **具体场景（假想）**：[城市夜景](modules/06-scenarios.md#night)中记录同行者和灯光街区，先拍短片确认人物动作与环境细节是否符合用途。
- **成立条件与投入**：选择全景超级夜景，确认帧率、版本和曝光；需要另投入现场试拍与回看。本库没有同条件噪点、拖影、肤色或热停实测。
- **价值不成立的情况**：极少夜间拍摄，或一代现有夜景规格已满足成片节奏时，II的更高帧率选项未必构成升级理由。
- **表达边界**：可讲“II全景超级夜景可选至8K60”；不能转述为“单镜头夜景也能60fps”“越暗也一定清晰”或“二代夜景全面碾压”。模式支持与成片表现分开讲。

<a id="sp06"></a>
### SP06 · 在成片阶段处理抖动和水平变化

- **官方能力与型号｜两代本机能力**：一代支持RockSteady3.0、HorizonSteady，全景可在Mimo导出时选择增稳；II全景可在Mimo或Studio导出时选择防抖。单镜头HorizonSteady均受模式条件限制。[D1-027](CARDS.md#d1-027)、[D2-019](CARDS.md#d2-019)
- **用户价值（编辑解释）**：运动记录者可以把“选看哪个方向”和“如何处理画面稳定”纳入同一次成片检查，让路线、人物动作更容易被观看。
- **适用人群与心理（待验证假设）**：骑行、步行旅行、滑雪记录者；关联[A360-H04 参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)和[A360-H05 外部视角](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h05)。
- **具体场景（假想）**：[骑行](modules/06-scenarios.md#cycling)结束后，对一小段素材比较取景与增稳设置，再决定整段路线的输出方式。
- **成立条件与投入**：先保证安装方案适配；一代普通单镜头HorizonSteady限标准视野、16:9去畸变、≤60fps；II普通单镜头同样有标准视角、16:9、畸变校正、≤60fps条件，极广角单镜头也限≤60fps。[D1-026](CARDS.md#d1-026)、[D1-027](CARDS.md#d1-027)、[D2-019](CARDS.md#d2-019)
- **价值不成立的情况**：固定机位已足够稳定，或安装和遮挡已使主体不可用时，软件增稳未必解决主要问题。
- **表达边界**：可讲已核验的增稳路径与组合；不能讲任何比例、帧率和运动强度都稳定，也不能把电子增稳描述成机械云台或无需检查成片。

<a id="sp07"></a>
### SP07 · 根据后期习惯选择色彩处理路线

- **官方能力与型号｜两代本机能力**：一代支持10-bit与D-Log M。II视频支持10-bit；智能影调可调节对比度、提亮人脸，效果需导入Mimo查看。II的D-Log M不可用于拍照、静止延时和长续航模式，开启后智能影调、胶片影调均不可用。本项不判断一代是否有同等影调流程。[D1-006](CARDS.md#d1-006)、[D2-012](CARDS.md#d2-012)、[D2-053](CARDS.md#d2-053)
- **用户价值（编辑解释）**：愿意调色的创作者可把D-Log M纳入素材管理，围绕整支作品统一处理色彩；偏向较少手动处理的人，可评估II智能影调的现有路线，查看人物与环境对比是否符合用途。
- **适用人群与心理（待验证假设）**：旅行视频创作者、已有其他机位的人；关联[A360-H06 摸索玩法](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h06)、[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)和[A360-H08 后期精力](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h08)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)短片同时包含全景取景镜头与其他相机镜头，先做一段色彩测试，判断新增素材能否进入现有剪辑流程。
- **成立条件与投入**：按准确型号和拍摄模式确认色彩选项；安排调色、显示和导出检查。D-Log M低饱和、低对比素材需要色彩处理；II智能影调需开启且D-Log M关闭，再将素材导入Mimo查看，不能只按相机预览判断结果。[D1-006](CARDS.md#d1-006)、[D2-053](CARDS.md#d2-053)
- **价值不成立的情况**：主要快速分享且不愿调色时，D-Log M可能增加步骤；并非每位使用者都愿意为后期调色空间投入时间。
- **表达边界**：可讲“为计划调色的人提供路线”；不能称所有模式都有D-Log M、同品牌画面无需处理就完全一致，或所有软件导出都保留10-bit。动态范围等实验室指标不能直接转换成跨机画质排名。

## 创作方式

<a id="sp08"></a>
### SP08 · 把短暂动作变成可以细看的片段

- **官方能力与型号｜本机能力＋已核验代际差异**：一代FAQ列明全景最高4K100的4倍慢动作，单镜头极广角最高4K120的4倍平面慢动作；II全景慢动作模式列有4K100／200／240。II的64倍慢动作需4K240全景素材加Studio后期插帧，不是相机直接记录64倍的完整成片。[D1-028](CARDS.md#d1-028)、[D2-008](CARDS.md#d2-008)、[D2-026](CARDS.md#d2-026)
- **用户价值（编辑解释）**：把转身、滑行或跳跃中的短暂片段展开，供观看动作与安排剪辑节奏；需要极慢效果的人可以进一步评估II已核验的软硬件组合。
- **适用人群与心理（待验证假设）**：滑雪、滑板等运动记录者和创意摄影者；关联[A360-H05 外部视角](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h05)和[A360-H06 摸索玩法](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h06)。
- **具体场景（假想）**：[滑雪](modules/06-scenarios.md#skiing)素材中选出一小段动作放慢，让观众看清自己在那个时刻的姿态；其余片段保持正常叙事节奏。
- **成立条件与投入**：拍摄前选对全景／单镜头和帧率，按实际播放帧率核对慢放倍率，之后检视细节与取景；II的64倍路线仅支持Apple M系列Mac上的DJI Studio，还需要后期处理时间。一代另有不同画幅的Vortex高帧率模式，见[SP09](#sp09)，不能混为普通全景慢动作。[D1-028](CARDS.md#d1-028)、[D2-026](CARDS.md#d2-026)
- **价值不成立的情况**：只需要正常速度记录，或不使用支持的电脑时，64倍效果不会自动转化为实用收益；主任务也可能更需要保留正常环境声和事件时长。
- **表达边界**：原生拍摄帧率、慢放倍率、AI插帧、平面输出四件事分别说明；不能说原生8K480或原生1920fps。动作回看不等于专业动作诊断或保证提高技术。[D2-027](CARDS.md#d2-027)

<a id="sp09"></a>
### SP09 · 用时间变化和环绕视角丰富叙事

- **官方能力与型号｜本机能力＋已核验代际差异**：一代全景Timelapse与Hyperlapse均列有8K25／30；II运动延时最高8K30、静止延时最高16K30。一代Vortex为4:1特殊画幅，列有6K100／120和4K240；II时空凝固（Vortex）列有8K100／120及另一组6K规格，均须与普通全景录像分开。[D1-029](CARDS.md#d1-029)、[D1-030](CARDS.md#d1-030)、[D2-010](CARDS.md#d2-010)、[D2-009](CARDS.md#d2-009)
- **用户价值（编辑解释）**：延时可把行程或场景变化浓缩成过渡段；时空凝固提供另一种时间与视角的表现尝试，让一支记录片有机会在连续记录之外安排变化。
- **适用人群与心理（待验证假设）**：旅行创作者、数码尝鲜者、创意摄影者；关联[A360-H06 摸索玩法](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h06)和[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)中用一段延时交代从出发到抵达的变化，再在合适的空地尝试专用玩法，比较它是否服务于主题。
- **成立条件与投入**：延时与Vortex分开设定；实施前读对应操作说明并确认机位、配件、活动空间和后期路径。一代延时间隔为离散选项，“无限时长”仍受电量、存储与环境限制。II的16K完整导出与设备矩阵仍有待核项，不能据拍摄表给所有手机承诺。[D1-029](CARDS.md#d1-029)、[D2-051](CARDS.md#d2-051)
- **价值不成立的情况**：只想按原速保留日常对话，或不愿安排专门机位和练习时间时，这些玩法未必比常规记录更有用。
- **表达边界**：II的16K属于静止延时规格，8K120属于时空凝固专用模式；一代Vortex的4K240为4:1记录画幅。不能写成普通实时全景16K、普通全景8K120或一代普通2:1全景4K240，也不凭玩法名称保证某个宣传样片效果。

<a id="sp10"></a>
### SP10 · 围绕一个人组织平面画面的主角

- **官方能力与型号｜II已核验本机能力**：II主角跟随可检测周围2m内人脸，经Mimo或Studio输出跟随主角的平面视频，最高4K30；丢失超过5秒后需要手动重新锁定。一代是否有同等模式与流程须另核验，本项不构成“一代不支持”的结论。[D2-024](CARDS.md#d2-024)、[D2-025](CARDS.md#d2-025)
- **用户价值（编辑解释）**：当内容始终围绕同一个人展开时，可以用已核验的跟随路线组织平面视角，再由创作者检查构图，减少逐段手动寻找主角的需要。
- **适用人群与心理（待验证假设）**：独行记录、有人讲述的短片、以人物为核心的旅行创作；关联[A360-H01 被记录](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h01)、[A360-H03 怕遗漏](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h03)和[A360-H08 后期精力](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h08)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)时以一位讲述者为主角，先在检测范围内试拍，再导出一段检查构图是否符合叙事。
- **成立条件与投入**：II主角跟随模式、2m内人脸条件、兼容Mimo或Studio；接受该路径平面最高4K30，并在遮挡、丢失或重新入画后检查是否需要重锁。[D2-024](CARDS.md#d2-024)、[D2-025](CARDS.md#d2-025)
- **价值不成立的情况**：主体经常离开适用范围、希望同时讲多个人、要求该流程输出高于4K30，或已有人工取景足够时，自动围绕一个主角未必满足任务。
- **表达边界**：可讲具体模式下的主体取景帮助；不能说远距离任意对象都跟随、遮挡后必然自动续跟、导出8K60，或把软件取景描述成相机机械转动。

## 使用便利

<a id="sp11"></a>
### SP11 · 让机位更容易纳入实际出行安排

- **官方能力与型号｜本机能力＋已核验安装差异**：两代官方机身重量均为183g。一代可用Osmo Action快拆配件和底部1/4英寸螺孔；II采用双向磁吸快拆及1/4英寸螺纹，底座兼容范围按准确型号核对。[D1-009](CARDS.md#d1-009)、[D1-026](CARDS.md#d1-026)、[D2-048](CARDS.md#d2-048)、[D2-039](CARDS.md#d2-039)
- **用户价值（编辑解释）**：可以围绕一次出行先设计手持、固定或其他已适配机位，判断拿取、安装和收回是否可接受；兼容的快拆路径可用于减少反复调整连接的步骤。
- **适用人群与心理（待验证假设）**：旅行、骑行、摩旅与已有配件的人；关联[A360-H04 参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)和[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)。
- **具体场景（假想）**：[摩旅](modules/06-scenarios.md#motorcycle)出发前，用准确配件组合试装并检查取景；停靠后再转为手持记录，观察携带和转换是否符合节奏。
- **成立条件与投入**：按完整机位而非只按机身核算重量与花费；逐件核验磁吸、快拆、螺纹及运动用途。II底座不能因其他机型物理可插入就推定磁力与适配合格。[D2-039](CARDS.md#d2-039)
- **价值不成立的情况**：最终套装过多、频繁装卸仍打断活动，或已有设备安装方式足够顺手时，机身轻或接口多不一定意味着整套使用更方便。
- **表达边界**：183g是机身参数口径，不是带自拍杆、夹具等整套重量；机械能连接不等于抗振、防水或隐形效果均通过验证，也不称全部DJI配件通用。

### SP12 · 为当天拍摄留出内置存储与扩展选择

- **官方能力与型号｜两代本机能力**：两代均标称内置128GB、约105GB用户可用，并支持最高1TB microSD扩展；选卡应按各型号官方推荐列表。[D1-011](CARDS.md#d1-011)、[D2-015](CARDS.md#d2-015)、[D2-016](CARDS.md#d2-016)
- **用户价值（编辑解释）**：机内留有足够空闲空间并选用内置存储时，可以先录下需要的片段，减少临时补找扩展卡的需要；较长行程再安排扩展卡与定期备份。
- **适用人群与心理（待验证假设）**：旅行、露营、家庭活动记录者；关联[A360-H03 怕遗漏](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h03)和[A360-H08 后期精力](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h08)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)每天出发前检查剩余空间，晚间转存并确认文件可读，再决定次日的录像规格和时长。
- **成立条件与投入**：检查实际剩余容量与准确卡型；把OSV原素材纳入备份，不能只留代理文件。卡、读卡器和备份盘按实际流程计入投入。[D1-012](CARDS.md#d1-012)、[D2-047](CARDS.md#d2-047)
- **价值不成立的情况**：拍摄量很少时无需为最大容量额外投入；如果积压的主要问题是不筛选内容，增加容量只能延后整理，并不自动解决回看困难。
- **表达边界**：可讲内置空间与扩展选项；不能把128GB写成全可用，不承诺任何V30卡兼容，也不能忽略模式而给出固定“能拍几天”。

<a id="sp13"></a>
### SP13 · 按行程规划供电，而不是只记最长分钟数

- **官方能力与型号｜两代本机能力**：两代官方8K30全景均列最长100分钟，长续航模式最长120分钟；一代另列6K24长续航最长190分钟。两代快充FAQ均建议PD3.0、最大PD输出至少30W的USB-C充电器。[D1-013](CARDS.md#d1-013)、[D2-033](CARDS.md#d2-033)、[D1-025](CARDS.md#d1-025)、[D2-043](CARDS.md#d2-043)
- **用户价值（编辑解释）**：把路线分成拍摄、休息和补电阶段，按任务选择拍摄模式与备用电池；对已有兼容电池的人，还可核算新增购置和携带的数量。
- **适用人群与心理（待验证假设）**：长途旅行、滑雪、摩旅记录者；关联[A360-H04 参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)和[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)。
- **具体场景（假想）**：[摩旅](modules/06-scenarios.md#motorcycle)按想记录的路段安排分段拍摄，在停靠点检查电量；[滑雪](modules/06-scenarios.md#skiing)则另考虑低温环境与回到适宜温度后充电。
- **成立条件与投入**：上述续航为25℃、熄屏，关闭Wi-Fi、手势、语音及剪辑助手等功能的实验室参考；120／190分钟需指定长续航模式，190分钟仅对应一代6K24。两代充电温度5～40℃，旧电池不能套用另一容量电池的续航值。[D1-013](CARDS.md#d1-013)、[D2-033](CARDS.md#d2-033)、[D1-014](CARDS.md#d1-014)、[D2-035](CARDS.md#d2-035)、[D2-034](CARDS.md#d2-034)
- **价值不成立的情况**：只拍短片段时，最长续航可能不影响使用；高规格长录和温度条件不同，也不能据标称分钟数确保全程不断录。
- **表达边界**：一代与II的8K30标称数字在上述条件下相同，不能凭容量不同宣称II必然更久；30W是充电器建议，不是相机始终以30W充电；工作温度不是充电温度。

### SP14 · 把镜片维护和使用环境计入长期拥有成本

- **官方能力与型号｜本机能力＋已核验代际差异**：一代机身镜头不支持用户自行更换；II外层镜片可用专用更换套件自行更换。两代裸机标称10m防水仍不建议直接用于水下全景；透明保护镜不能代替防水壳。[D1-024](CARDS.md#d1-024)、[D2-038](CARDS.md#d2-038)、[D1-010](CARDS.md#d1-010)、[D2-036](CARDS.md#d2-036)、[D2-045](CARDS.md#d2-045)
- **用户价值（编辑解释）**：经常携机出行的人，可事先了解划伤后的处理路径与费用；II外层镜片受损时，多了一条使用对应套件自行更换的处理路径。它能改变这类损伤的处理方式，实际费用仍需核算。
- **适用人群与心理（待验证假设）**：户外、摩旅、水上活动与长期持有者；关联[A360-H07 确认新增用途与投入](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)和[A360-H04 参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)。
- **具体场景（假想）**：[水上活动](modules/06-scenarios.md#water)前先区分水面记录与水下全景，再选已适配保护方案；普通旅行则把镜片检查、清洁和收纳加入出发流程。
- **成立条件与投入**：II更换对象是外层镜片，需另购对应套件并按说明操作。两代防水均须电池仓盖、USB-C保护盖可靠闭紧，避开温泉、腐蚀／不明液体及高冲击水流；II的10m数值来自受控水压测试。II适配全隐形防水壳需正确安装，50m是受控水压实验标称，表现受环境与产品状态影响，水下安全拼接距离1m。透明保护镜应避免用于雨雪和水上活动，以免起雾。[D1-010](CARDS.md#d1-010)、[D2-036](CARDS.md#d2-036)、[D2-038](CARDS.md#d2-038)、[D2-037](CARDS.md#d2-037)、[D1-024](CARDS.md#d1-024)、[D2-045](CARDS.md#d2-045)
- **价值不成立的情况**：现有一代镜头状况良好、使用环境温和且无维护困扰时，仅有可换外层镜片未必值得换机；真实总成本仍需核对套件与服务价格。
- **表达边界**：可讲II外层镜片的维护路径；不能称整套镜头模组都能自行修复、怎么摔都不怕，或宣称可换镜片必然更省钱。防水深度不等于水下无缝成像，一代壳体适配不从II推断。

## 完整流程

<a id="sp15"></a>
### SP15 · 把人物讲述与全景画面一起纳入记录

- **官方能力与型号｜两代本机能力**：两代可无线直连最多两个兼容DJI麦克风TX；已列型号为Mic 2、Mic Mini、Mic 3、Mic Mini 2、Mic Mini 2S，不支持经RX接入。一代还可开启机身收音备份，单独保存WAV。[D1-015](CARDS.md#d1-015)、[D1-016](CARDS.md#d1-016)、[D2-030](CARDS.md#d2-030)、[D2-031](CARDS.md#d2-031)
- **用户价值（编辑解释）**：可以围绕人物讲述或双人互动安排收音，减少视频只有环境画面、事后还要补叙述的需要；已有兼容TX的人可评估直接接入这一条路线。
- **适用人群与心理（待验证假设）**：旅行讲述、家庭记录、双人互动和摩旅创作；关联[A360-H02 留住生活](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h02)和[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)时记录两个人边走边介绍所见之物；出发前分别试录、回听，再决定机身与外接麦克风怎样分工。
- **成立条件与投入**：核对准确TX型号、固件和配对入口；一代Mic 3支持有固件基线。另计麦克风携带、电量和音频文件管理；本库没有任意型号混连或高速风噪保证。[D1-015](CARDS.md#d1-015)、[D2-031](CARDS.md#d2-031)
- **价值不成立的情况**：主要拍无人物讲述的环境片段，或不愿佩戴、充电和整理额外麦克风时，直连能力可能只是备用选项。
- **表达边界**：可讲准确兼容TX与最多两发；不能称所有DJI Mic均通用、接收器也可接入或视频音轨自动成为32-bit float。II机身音频参数为48kHz、16-bit；一代相机保存链路同样不能由TX内录能力类推。[D2-029](CARDS.md#d2-029)、[D1-015](CARDS.md#d1-015)

<a id="sp16"></a>
### SP16 · 按现场与回家后的条件选择素材搬运路径

- **官方能力与型号｜两代本机能力；II另有已核验NFC路线**：一代可经Mimo下载或USB向电脑复制素材；II可经Mimo、microSD读卡器或USB-C读取，另有NFC碰一碰连接和选片下载流程。一代有无同等NFC流程本库未确认。[D1-019](CARDS.md#d1-019)、[D2-023](CARDS.md#d2-023)、[D2-022](CARDS.md#d2-022)
- **用户价值（编辑解释）**：临时需要一段素材时走手机路径，回家集中整理时可规划电脑搬运；符合条件时，II可通过NFC进入Mimo连接、下载已选素材，先把要处理的片段送到手机。
- **适用人群与心理（待验证假设）**：边旅行边分享、回家统一整理、易积压素材的人；关联[A360-H04 参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)和[A360-H08 后期精力](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h08)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)途中先把一段候选片传到手机处理，回家后再把整天原素材复制到电脑归档。
- **成立条件与投入**：USB需在相机选择文件传输模式；II的NFC需手机解锁且在主屏幕，蓝牙与NFC开启并已安装Mimo。碰选素材时，全景进入Mimo相册，其他素材进入手机相册；仍须安排下载、编辑与导出。[D1-019](CARDS.md#d1-019)、[D2-022](CARDS.md#d2-022)、[D2-023](CARDS.md#d2-023)
- **价值不成立的情况**：主要固定用读卡器或电脑工作、手机没有NFC，或真正瓶颈在筛选剪辑时，连接入口变化不一定节约整段工作流时间。
- **表达边界**：可讲明确连接和下载步骤；不能称“碰一下即是可发布成片”、所有手机都支持，或没有同条件数据就承诺固定传输速度、比一代快多少。

<a id="sp17"></a>
### SP17 · 先确定成片用途，再选择手机或电脑后期

- **官方能力与型号｜两代本机能力**：一代提供Mimo与电脑后期路径；II可在Mimo／Studio完成已核验的全景处理、主角跟随输出等流程。全景OSV与平面MP4分开管理；II完整导出矩阵仍有缺口。[D1-020](CARDS.md#d1-020)、[D1-012](CARDS.md#d1-012)、[D2-019](CARDS.md#d2-019)、[D2-024](CARDS.md#d2-024)、[D2-047](CARDS.md#d2-047)、[D2-051](CARDS.md#d2-051)
- **用户价值（编辑解释）**：手机可成为现场处理短片的选项，电脑可纳入集中归档和创作流程；先想好“给谁看、看什么、怎么播放”，能使拍摄规格和后期投入有明确目的。
- **适用人群与心理（待验证假设）**：旅行创作、异地分享、已有剪辑习惯和素材积压者；关联[A360-H02 留住生活](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h02)、[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)和[A360-H08 后期精力](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h08)。
- **具体场景（假想）**：[旅行](modules/06-scenarios.md#travel)给家人分享一段平面短片；回家保留OSV原素材，日后如果有需要再做其他取景。
- **成立条件与投入**：核对当前Mimo推荐设备与Studio配置，先用小片段完成取景、增稳、声音和导出验证。II主角跟随最高平面4K30；II的64倍慢动作需4K240全景素材，经Apple M系列Mac上的Studio插帧。一代已核验的Resolve重新取景路线需先Studio预处理、导出Resolve专用格式，再使用Reframe插件；要求Resolve20.0.1+，macOS15+，或Windows10 64-bit 22H2+／Windows11，Studio还须满足自身配置。这是一条已核验路径，不是所有取景的必要条件，也不证明Mimo具体操作。II完整插件兼容矩阵未核验。[D1-021](CARDS.md#d1-021)、[D1-022](CARDS.md#d1-022)、[D1-031](CARDS.md#d1-031)、[D2-024](CARDS.md#d2-024)、[D2-026](CARDS.md#d2-026)、[D2-028](CARDS.md#d2-028)
- **价值不成立的情况**：希望所有片段拍完立即分享、没有处理空间或不愿选择视角时，双端路线不会自动消除后期负担；已有直接成片流程可能更合适。
- **表达边界**：可讲已核验路径与具体限制；不能把软件最低门槛当作流畅保证，不能称Windows／Mac／所有手机功能完全相同，不能用球面记录规格填补平面导出矩阵。

<a id="sp18"></a>
### SP18 · 从已有设备清单判断能复用哪一环

- **官方能力与型号｜按型号核验的配合能力**：两代均有兼容DJI Mic TX和指定Osmo Action电池路径；一代可用Osmo Action快拆配件。II双向底座列明支持Osmo Nano与Osmo Action 6，不能由同品牌推断任意设备可用。[D1-015](CARDS.md#d1-015)、[D1-025](CARDS.md#d1-025)、[D1-026](CARDS.md#d1-026)、[D2-030](CARDS.md#d2-030)、[D2-034](CARDS.md#d2-034)、[D2-039](CARDS.md#d2-039)
- **用户价值（编辑解释）**：把新增全景任务接到已有麦克风、电池或适配安装件上，有机会减少重复购置与多套物件管理；价值取决于手中具体型号和实际分工。
- **适用人群与心理（待验证假设）**：已有DJI设备、主相机加第二机位、重视整套携带成本的人；关联[A360-H07 确认新增用途](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h07)和[A360-H04 参与活动](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md#h04)。
- **具体场景（假想）**：[骑行](modules/06-scenarios.md#cycling)者已用运动相机拍前方路线，新增全景任务是回看骑手与周围方向；先核清是否能复用现有TX、准确电池及适配安装件，再算新增整套投入。
- **成立条件与投入**：列出完整型号与容量，逐项对官方兼容表；1770mAh和1950mAh兼容电池不能沿用II标准2150mAh电池的数字。配件复用仍须检查隐形、固定与实际用途条件。[D2-032](CARDS.md#d2-032)、[D2-034](CARDS.md#d2-034)、[D1-026](CARDS.md#d1-026)
- **价值不成立的情况**：没有明确新增视角，或现有配件不兼容时，同品牌关系本身不能成为购买理由；需新增的软件设备、存储与后期时间也可能超过复用收益。
- **表达边界**：可讲具体清单中哪件可以复用；不能称全生态通用、旧电池续航不变、其他机型都能磁吸或同品牌即可无缝出片。金额与套装报价需单独按日期核验，本专题不预设节省金额。

## 两代选用与升级判断

先写出一个**已经发生、现有拍法未满足的任务**，再比较支持条件。以下为编辑判断框架，不是购买推荐或实测排名；两代共有能力先看是否已经够用。仅II有已核验证据的功能，不反推一代不存在。

| 现有需求或缺口 | 两代证据与取舍 | 什么情况下值得进一步评估II | 什么情况尚无明确升级理由 |
|---|---|---|---|
| 想普通全景8K60，而现有规格达不到需求 | 一代升级至相应固件后普通全景最高8K50；II普通最高8K60。[D1-002](CARDS.md#d1-002)、[D2-003](CARDS.md#d2-003) | 已明确需要8K60素材，且存储、后期与交付流程可处理 | 现有8K帧率与成片已满足；不能仅凭60对50推导所有画质进步 |
| 夜间全景确有60fps拍摄任务 | 一代全景超级夜景最高30fps；II最高60fps。[D1-004](CARDS.md#d1-004)、[D2-004](CARDS.md#d2-004) | 需要该模式与帧率，试拍能确认符合题材需求 | 少拍夜景或30fps已够用；规格本身未证明低光成片全面胜出 |
| 希望更慢地展开动作 | 一代常规全景慢动作最高4K100；II的4K240全景素材可经Apple M系列Mac上的DJI Studio插帧实现64倍。一代Vortex的4:1画幅4K240另论。[D1-028](CARDS.md#d1-028)、[D1-030](CARDS.md#d1-030)、[D2-008](CARDS.md#d2-008)、[D2-026](CARDS.md#d2-026) | 有实际慢动作题材、支持电脑与处理时间 | 只按正常速度留记录，或没有支持的电脑又只为64倍效果换机 |
| 现有后期取景总围绕同一主角，想检查专用跟随方案 | II已核验2m内人脸、最高平面4K30，丢失主角超过5秒需重锁；一代同等流程未确认。[D2-024](CARDS.md#d2-024)、[D2-025](CARDS.md#d2-025) | 题材符合距离、识别与输出条件，且这一流程确实解决工作量 | 主体超出范围、多主体切换频繁，或既有人工取景已足够；不以未核验宣称一代缺失 |
| 主要拍单镜头普通视频 | 一代最高5K60，II最高4K60；两代极广角另查。[D1-003](CARDS.md#d1-003)、[D2-005](CARDS.md#d2-005)、[D2-006](CARDS.md#d2-006) | 还有其他明确任务需要II，不能仅以新代号决定 | 只看该项规格，不能称II分辨率升级；现有设备满足时可继续使用 |
| 想自拍杆隐形、后期换方向，但一代已经能完成 | 两代均有这些全景原理与路径，条件见[SP01](#sp01)、[SP02](#sp02) | 另有经过证据核对的拍摄或维护缺口 | 仅为这些共有能力，尚不能说明换代会解决新问题 |
| 担心长期使用后的外层镜片维护 | 一代机身镜头不支持自行更换；II有专用外层镜片更换套件。[D1-024](CARDS.md#d1-024)、[D2-038](CARDS.md#d2-038) | 使用环境与维护需求使此路径有明确价值，并核算套件与服务成本 | 一代状态良好且无相关困扰；不能未核价就称换机更省钱 |
| 想靠换机延长8K30连续记录 | 两代在25℃、8K30全景、熄屏及关闭Wi-Fi、手势、语音和剪辑助手等指定功能的实验室条件下，均最长100分钟、开启长续航模式最长120分钟。[D1-013](CARDS.md#d1-013)、[D2-033](CARDS.md#d2-033) | 先明确其他实际任务与现场条件，单凭这组数据不足以得出升级收益 | 仅依据II容量数字期待相同模式显著延长；实际续航仍需实测 |
| 已有DJI电池、麦克风和安装件，希望降低新增投入 | 两代都有具体兼容路径，II底座另有准确机型范围，见[SP18](#sp18) | 清单核验后能复用，且新增全景任务真实存在 | 仅因同品牌、配件看似能装上就换机；总投入包括存储、电脑与后期时间 |
| 当前最大问题是素材堆积 | 两代均要安排原素材、取景、剪辑与输出；II新增流程也有设备条件，见[SP16](#sp16)、[SP17](#sp17) | 先用短片验证某条具体流程能解决当前瓶颈 | 没有时间处理、近期无拍摄场景或既有方法够用时，保留一代、少拍或暂缓均是合理选项 |

## 用于讲解和复核

组织一段产品讲解时，先说用户要完成的事，再选1～3个相关SP条目，带上适用型号、模式和最低必要条件。需要产品事实时打开事实卡的实际官方来源；心理编号只支持提出解释假设，不能证明此人一定会购买或满意。

本轮事实复核材料见[一代卖点复核](sources/recheck-selling-first-2026-09-07.md)与[二代卖点复核](sources/recheck-selling-second-2026-09-07.md)。完整待核项目继续查看[缺口清单](GAPS.md)，尤其是II的完整导出矩阵；本专题没有将缺口变成肯定卖点，也未制作竞品胜负结论。
