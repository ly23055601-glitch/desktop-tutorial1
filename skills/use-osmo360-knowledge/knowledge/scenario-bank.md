# Osmo 360 详细使用场景与文案选材库

整理日期：2026-09-07。对象：内容与运营培训团队。**48张场景卡、144个选材角度**，覆盖两代产品。用途是为后续培训文案找到具体事情、使用动机和有条件成立的卖点；不是48类真实消费者、真实反馈或成品评论。

本库与[18项卖点专题](selling-points.md)分工：SP解释能力有什么用，SC把用途放入具体人物和事件；[心理指南](../../.agents/skills/use-osmo360-knowledge/references/audience-guide.md)的H编号提供待验证解释。事实仍由[知识卡](CARDS.md)和实际读取的官方依据支持，场景不扩大产品能力。

## 发散时，改变决定用途的变量

已有场景没有命中时，从真实任务或明确的合成命题出发，改变一个会影响选择的变量，再核对卖点是否仍适用。这是讨论方法，不是机械排列48类人的组合器。

| 变量 | 不同选择如何改变选材 |
|---|---|
| 记录对象 | 自己、一个讲述者、多人回应、宠物或空间；人脸跟随证据不能推给其他对象 |
| 当时最缺什么 | 拍摄者、另一个方向、动作时间采样、声音、存储或交付时间；功能要对应真正缺口 |
| 观看者 | 自己、参与者、未到场家人或作品观众；分别考虑重点、长度和播放条件 |
| 时间结构 | 一次事件、已知仪式、反复练习、缓慢变化或多年留档；普通录像、慢动作、延时分开 |
| 现有设备与习惯 | 手机够用、前向运动录像、已用一代、有兼容TX、熟悉电脑剪辑；不能只用新代号证明必要 |
| 后期意愿 | 乐于调色、只做一段、愿意归档但不剪、暂时没精力；允许不升级或少拍 |
| 使用阶段 | 好奇、试用、常用、积压、维护和送礼；同一个人关注的可能是完全不同的事 |
| 可用空间与环境 | 室内距离、拥挤、低温、水面或水下；不能让场景创意覆盖物理条件和安装核验 |

发散后要能说出一个实际变化：例如SC17让已有前向录像增加本人视角，SC20让停靠讲述交代路线，SC37让原素材以后仍可编辑。只换人物、地名和构图对象，仍反复“多一个角度”的内容，不足以形成新选材。

<a id="use"></a>
## 调用与写手接入

可以直接说：

- “调用Osmo360场景库，给独自旅行者找几个不同的使用动机和卖点”
- “oq：同样是骑行，发散动作回看、朋友关系、停靠讲述和后期整理的选材”
- “调用Osmo360卖点库，把收音卖点展开成不同场景，说明已有设备够用的情况”
- “这个角色适合讲哪些卖点？按具体事件、心理矛盾、条件和可写角度给培训选材”

项目[360技能](../../.agents/skills/use-osmo360-knowledge/SKILL.md)负责检索本库。用户只要发散或分析时交付选材；需要实际消费者评论时继续[共用写手入口](../../.agents/skills/write-consumer-training-comments/SKILL.md)，按当前规则生成培训用假想消费者草稿。人物经历单独设定，SC不是产品事实，也不是原帖证据；不要把技术清单或整张卡直接改写成评论。

本轮[官方依据复读](sources/recheck-scenarios-2026-09-07.md)没有新造参数或改变未读卡的日期。设备／导出矩阵、特定安装组合、播放端兼容及价格等不足继续按[缺口清单](GAPS.md)处理，未知不等于不支持。维护时保留SC编号，受影响的SP、事实卡、培训命题和入口一起检查。[本轮验收](evaluation/scenario-expansion-2026-09-07.md)。
